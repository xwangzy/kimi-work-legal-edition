# Kimi Work 法律行业发行版 · 产品宣传片（v2）

96 秒，1920×1080，30 fps。主题「让法律专业能力，进入 AI 时代。」（Legal Intelligence. Reimagined.）。结尾为中软国际 × KIMI「联袂打造」。

v2（2026-10-24）按 V9.4 第 26 批后的真实产品重做：画面里的客户端**不是另画的界面**，而是从运行中的产品采集的 DOM 快照，用产品自己的样式渲染。v1 成片与源码留在 `archive/v1/`。

## 成片与命令

```bash
npm install
npm run music      # 依时间轴合成配乐与音效 → public/audio/score.wav
npm run studio     # Remotion Studio 逐场预览（每场另有单独合成 S-<场景名>；SnapCheck 逐张检查快照）
npm run render     # → out/kimi-work-legal-film.mp4
```

检查画面：`scripts/sheet.sh <合成ID> <帧…>` 半分辨率渲染整场再抽帧，拼成 3 列联系表放到 `out/sheets/`。

## 界面怎么做到忠实

| 环节 | 做法 |
|---|---|
| 样式 | `scripts/snap-css.mjs` 把 `platform/packages/design-tokens` 与 `platform/apps/desktop/src/styles.css` 快照到 `src/product/`：`:root` 改到 `.kw` 容器上，深色主题改到 `.kw.kw-dark`，vh/vw 按采集视口 1440×900 换成像素。 |
| 界面 | `scripts/capture/` 起一套本机开发栈（Vite + 内核开发桥 + 脚本化模型），灌入虚构案例，用 Playwright 逐步点出每个状态，导出 `body.innerHTML` 到 `snaps-src/*.json`（共 45 张，含深色模式）。 |
| 导入 | `scripts/snap-import.mjs` 生成 `src/snaps/*.ts`：去脚本，把文书预览的 srcdoc 隔离框架展开为带作用域样式的 div。 |
| 渲染 | `src/ui/Snap.tsx`：每帧还原快照，再由场景的 `edit(root, frame)` 写入演示态（打字、显隐、勾选、代号替换、修订线划过）。edit 只按当前帧写全状态，乱序并行渲染结果也一致。滚动一律用位移模拟（单帧渲染时 scrollTop 会丢）。 |
| 对位 | `scripts/measure.mjs <快照> '<选择器>[@文字]'` 量出元素在快照坐标里的位置，镜头焦点、光标落点、聚光圈都按量出来的坐标写。 |

产品更新后重拍：按 `scripts/capture/` 起栈并运行 `seed-film.mjs`、`shoot-film.mjs`、`shoot-x.mjs`、`shoot-dark.mjs`（采集数据放在 `/tmp/kwl-film-capture`），把 JSON 复制到 `snaps-src/`，再跑 `snap-css.mjs` 与 `snap-import.mjs`。

## 案例与说法的出处

- 案例全部虚构：乙投资有限公司受让甲科技有限公司所持丙数据服务有限公司股权；合同里的姓名、证件号、电话为编造。
- 风险意见卡、审查意见书正文由采集用的**脚本化模型**给出（`scripts/capture/script-bridge.ts`），不是 Kimi 模型的真实输出；代号替换、引用核对状态、数据去向统计、修订稿横幅是产品对这些输入的真实处理结果。
- 字幕里的说法都对照过产品：未核对的案号不能签发（`review.approve` 返回 409 `unverified_citations`）；对外版修订稿不带批注、理由、规则号和底线（审查工作台页头说明）；「经过中软，不保存」取自设置 → 数据去向说明。
- 片尾小字：「画面为 Kimi Work 法律行业发行版开发中版本的界面演示 · 案例与数据均为虚构」。

## 配乐

`scripts/make-music.mjs` 零依赖纯 Node 合成，音效（打字、点击、代号出现、步骤完成、提示、转场风声）由 `GLOBAL_CUES` 驱动，与画面逐帧对齐。这是**节拍对齐的临时配乐**，正式发布前建议请作曲按同一速度与段落替换为授权音乐，音效可保留。

## 视觉规范

- 背景只用暖白摄影棚（`StudioBackdrop`）与近黑夜色（`NightBackdrop`）；不用科技线条、粒子、数字雨和地球。
- 窗口为 Electron 默认窗口框（macOS 原生标题栏 + 红绿灯），内容区 1440×900 与采集视口一致。
- 镜头：`ProductStage` 关键帧推拉摇移（焦点、缩放、俯仰、偏航）；`ProductWindow` 的 `focus/blur/dim` 做浅景深，`Spot` 做视线引导。
- 字体：界面与字幕用苹方，文书用宋体（产品 `--font-doc`），英文用 SF Pro Display。
- Logo：`public/logos/` 下 KIMI 官方字标与中软国际印章原样使用。
