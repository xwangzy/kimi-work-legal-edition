### C 质量控制

1. **借鉴上游案例审查“存在高危项时开头写‘修正前不得对外出具’”** → 交付前检查发现重大问题时，成果卡与内部附件首行写“有 n 处须修正，修正前不建议外发”（不进文书正文） → 律师不会误把带硬伤的稿子发出去。
2. **借鉴上游 `util-docx-format`“参数设对≠渲染对了，转 PDF 看图”** → 文书交付前检查加一步渲染页检查：落款位置、孤行、条目误排成标题、版式类别（诉讼 / 仲裁 / 意见书）对不对（**需核对**内核 `docx.render_report` 现有检查） → 律师打开 Word 不再先改格式。
3. **借鉴 Harvey“律师手填值不进入引用与核验轨迹”** → 核验状态区分“法规库核验 / 律师确认 / 未核验”，律师改过的内容不自动沿用工具核验结论 → 核验表不会把未查过的内容显示成“已核验”。
4. **借鉴 Spellbook 每个动作附批注、拒绝也留痕** → `doc-revise` 修订保真规则：每处实质修订带理由批注；撤回修改用新修订恢复原文，不删痕；清洁稿与修订稿逐段对齐自检 → 律师和对方都能追溯每一处改动。
5. **借鉴上游 `util-contract-diff`“风险信号无变化≠无影响”** → 回稿审查和按意见修订的自检：金额、期限、比例、主体的每处变化无论有无风险都进核对清单 → 不会漏掉“总价少了 20 万”这种没有风险特征的改动。
6. **借鉴上游“未能核实≠该案系编造”与 CoCounsel 直说能力边界** → 统一失败与降级文案：先说“没完成什么”，再说“已保留什么”“你可以怎么做”；不出现“系编造”“不存在”等无证据的指控 → 律师看到失败提示知道下一步，不会误判对方材料。
7. **借鉴 Kimi Code 2.4.0 子代理未完成文字“标为未完成”回传** → 分段阅卷、批量审阅中途超时时，部分结果逐份标“已读 / 部分读 / 未读”，回报首句写完成范围（衔接工作准则第 9 条） → 律师知道哪几份材料还没被读过。

- 可改法【推断】：本机没有案例库，但律师常把判决书作为材料导入。对“文中引用了某判决，且该判决在事项材料里”的情形，增加不依赖案例库的两项核对：（a）引述内容出自判决书哪一段（“本院认为”/“原告诉称”/“被告辩称”/“经审理查明”），出自当事人主张段的判“高危：误将当事人主张作法院观点”；（b）判决书为一审的，标“终局性未核实（未见二审文书）”。案例不在材料中的维持现状“未核验”。这一条律师最容易在庭上吃亏、也最难自己发现。

**② 回稿比对按立场判“变好 / 变差 / 有得有失”，并单列“无风险信号的金额期限改动”** — 上游 `skills/utility/util-contract-diff/SKILL.md`
- 上游做法：先看新增与删除的条款（“对方悄悄删掉一条对其不利的条款，很难被注意到”）；实质改动按我方立场分“对我方变差 / 变好 / 有得有失 / 风险信号无变化”；金额、期限、比例类改动“零信号但可能是本次谈判最关键的让步”，单列表格并标“须业务方确认”；对我方变好的改动要确认“无隐藏代价（如以别处让步为交换）”；换立场必须重跑。
- 本产品现状：`redraft-review` 已做得更细的部分——静默改动、受影响定义与互引、我方上一轮修改采纳跟踪；但只有“实质 / 文字”二分，grep “变差/变好/有利/交换”0 命中，没有按立场给方向判断，也没有“交换条件”提示。
- 可改法：在《变更清单》加一列“对我方影响（变差 / 变好 / 有得有失 / 需业务方确认）”，在“比对说明”加两组汇总：“新增与删除（优先看）”“金额、期限、比例改动（需客户确认）”；回报第一句写“实质改动 X 处，其中对我方变差 X 处”。

**③ 站在受益方时提示“有利条款的效力风险”** — 上游 `skills/nonlitigation/nonlit-review-contract/SKILL.md`（第三节“有利条款的效力风险（站甲/乙方时）”与“立场适配的内部逻辑”表）
- 上游做法：同一条款对甲方是“有利”，但如“3 日异议期 + 不得再提出任何异议”可能被认定无效——“条款被判无效，保护就落空了”，建议主动调整到合理期限以增强可执行性；并用“主语身份受益方 / 受损方”表决定条款对哪方不利。
- 本产品现状：`contract-review` 已有 `rule_source`（法律强制 / 本所规则 / 商业）、谈判梯度、`needs_client_decision`，比上游更系统；但风险卡只针对“对我方不利”的条款，没有“对我方有利但可能无效”这一类（grep “有利条款”0 命中）。
- 可改法：风险卡增加一类“有利但效力存疑”（严重程度默认“一般”，性质“建议修改”），报告里单独一节，避免律师把对方会抗辩无效的条款当保护。

**④ 文书版式三套预置 + 生成后“看图”自检** — 上游 `skills/utility/util-docx-format/SKILL.md`
- 上游做法：法院文书（仿宋_GB2312 三号、固定 28 磅、页边距 3.7/3.5/2.8/2.6 cm）、仲裁文书、法律意见书三套规范；“诉讼请求的‘一、二、三、’是条目不是标题”；落款右对齐；**转 PDF 看图检查**（“参数设对不代表渲染出来是对的”）；提示各地立案窗口格式可能不同。

**⑤ 行为时法“双轨呈现 + 差异影响”** — 上游 `conventions/time-effect.md`
- 上游做法：跨修订节点必须同时列【行为时法】【现行法】【衔接规则】【差异影响】，“差异影响不能省”；“2021 年前行为引用合同法不是错误”；刑事、行政处罚检索从旧兼从轻；禁止新旧条号换算。
