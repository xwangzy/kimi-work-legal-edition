## E. 术语

| 术语 | 含义 |
|---|---|
| 事项 | 一个委托或案件的工作边界：材料、任务、成果、成员、权限、处理模式与成本都挂在事项上（对应 Kimi Work 的“项目”） |
| 交付件 | 经律师实质复核并签发的确切文件（DOCX/XLSX/PDF）及其交付记录 |
| 生产档 / Beta / 模板 | 场景成熟度三档；只有生产档纳入 SLA 与首页 |
| 处理模式 | 团队托管、本机原件、离线阅读、专属/私有化；决定数据去向，事项头部常显 |
| 本机能力层 | 客户端在律师电脑上承担的文件挂载、本机原件解析、宿主修订、离线阅读与安全导入 |
| 化名 / 脱敏 | 化名：发往模型前的可逆替换；脱敏：对外交付的不可逆处理；两者分开实现与验收 |
| 引用四态 | 来源已核、版本与元数据已核、支持命题、律师确认；生成方不能写入后两态以外的“已核”状态 |
| 签发 | 律所内部的业务授权记录，绑定确切文件 hash、受众与版本；不等于电子签章 |
| 完整性单 | 签发前的一页清单：材料覆盖、未处理建议、未核引用、未决项、受众检查、标识 |
| 规则包 / Playbook | 合同类型 × 立场 × 尺度的规则集；本所覆盖层叠加其上，经合伙人批准生效 |
| 方法包（Skill） | 工作流方法说明 + 输入输出 schema + 工具权限 + 模板 + 评测的签名制品（SKILL.md 格式） |
| 规则提炼助手 | 从律所历史审查意见与修订稿提出候选规则的工具，人工审定后才发布 |
| 生产席 / 审阅签发席 | 按角色定价的两类具名席位 |
| 点数 | 对外权益单位，不等于 token 或货币；平台失败不扣点 |
| Agent 模式 | 开放任务：计划先行、预算上限、只用法律工具、产物只能是草稿 |
| G0 / G1 / G2 / G3 | 验证、试点建设、商用准备、扩展四个阶段门 |
| 探针 | G0 中验证关键技术假设的最小实验，结果决定范围与路径 |
| Source Registry | 来源登记簿：逐来源记录许可、允许动作、到期与删除义务 |
