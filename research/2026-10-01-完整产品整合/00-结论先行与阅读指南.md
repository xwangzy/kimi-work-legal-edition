# Kimi Work 法律行业发行版 · 完整产品方案 v4.0

定稿 2026-10-01 · 整合 astra（09-22 方案、09-30 v1.1 交付包）、opus（09-23 完整方案、09-28 v3.0 最终方案）、Claude 09-23 独立审计，以及 10-01 四路联网核验 · 面向：中软国际立项评审、联合合作、产品与研发、设计合作律所试点

> 所有价格、指标、人力、周期与收入均为待试点校准的假设，不是报价、预算或收益承诺；“已核验”只指公开官方材料或源码存在相应描述，不代表我方已签约、已实测或已取得供应商承诺。现有 demo 是交互原型，不是能承接真实案件的生产系统。

## 一句话

**中软国际与月之暗面联合推出、中软自建运营的律所法律工作平台。律师在本机安装客户端，用 Kimi Work 的方式交代任务，得到有出处、有版本、经律师复核签发的 Word/Excel 交付件；在 Word/WPS 里就地审合同，在企业微信/钉钉/飞书里收材料、看进度、做审批；律所按席位购买，中软向月之暗面采购 token 计入成本。**

## 十二个关键决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | 产品形态 | 四端一云：Windows 客户端（主工作台，macOS 2027-Q3）、Word/WPS 加载项、企业微信/钉钉/飞书入口、管理后台 + 中软境内法律云 |
| 2 | 执行架构 | **单一云端执行内核 + 本机能力层**：分析、规则、模型、核验、审批都在云端；客户端负责事项文件夹挂载、本机原件模式、在 Word/WPS 宿主内写入原生修订、离线阅读、安全导入；律师电脑上不跑通用 Agent |
| 3 | Kimi Code | 后端“开放任务执行器”：中软 fork 自建锁版的 `kimi-code-sdk` 在每事项隔离 worker 内**进程内嵌入**（ACP 备选），只负责 Agent 循环、上下文压缩、Skills 与事项内子任务；内置 Shell/文件/浏览器工具全部禁用；审批、权威状态、计量、工具全部由中软控制面掌握 |
| 4 | 生产主干 | 确定性法律工作流（Node/TypeScript + Vercel AI SDK 直调 K3/K2.6）+ DBOS 持久编排（规模化迁 Temporal）；生产档场景不经过 Agent |
| 5 | 首发范围 | 生产档：**S1 合同审查与修订、S1b 回稿比对、S2 案卷整理、S3 要素式文书与金额测算、S6 脱敏**；S4 研究与 S5 顾问答复以法源授权签署为升档条件；Beta：批量台账、进展报告与效率证明、Agent 模式 |
| 6 | 合同内容 | 首批 **9 类 × 双立场 = 18 套**规则包：股权转让、买卖/采购、服务、技术开发、软件许可及实施、保密、商业租赁、借款与担保、劳动合同与竞业限制 |
| 7 | Office 路径 | Word：Windows 默认随 exe 安装的 COM 加载项，M365 租户走 Office.js，Mac 走 Office.js，云端直出修订稿兜底；WPS：客户端调用金山官方 publish 方法注册、用户在 WPS 内确认启用 |
| 8 | IM | 首发一家（按设计合作律所实际平台定），其余两家按同一渠道契约分批验收；机器人只做投递、触发、通知与身份跳转，签发必须看到完整文件 |
| 9 | 数据与合规 | 处理模式：团队托管（G1）、本机原件（G2）、**专属云（2027-Q3）**；DPA + ZDR 且排除服务协议“服务优化”使用权是真实案卷进入模型的前提；**当事人拒绝即禁用云端**；**首家付费上线前完成属地应用登记（或书面意见）、电信许可与等保定级备案**；AI 标识按 TC260 实践指南实现；商业法源数据不进训练与评测 |
| 10 | 版本与价格 | 团队版生产席 9,800 元/年（3 席起，**每 3 个生产席含 1 个审阅签发席**，超出部分 1,800 元/年）；律所版 8,800 元 + 平台费按规模分档（20 万元起）与分所加挂；专属云按单报价（2027-Q3）；专业版 3,600 元/年或 399 元/月（2027-07 自助上线，不对个人主推）；渠道版面向律协与区级统一采购（不计基准收入）；私有化按单准入；点数制、无不限次；销售附总成本对比 |
| 11 | 投入与止损 | G0 约 130 万元，至 G2 结束累计约 1,100 万元；基准情景累计现金需求峰值约 4,800 万元（年付预收口径）、累计经营亏损谷底约 7,000 万元，2030 年经营基本打平；每个阶段门设止损线 |
| 12 | 节奏 | G0 2026-10-12～11-20；G1 11-23～2027-01-29；G2 2027-02-15～04-09（3 月起试点转付费）；**2027-04-12 公开销售** |

## 相对两份前序整合稿改了什么

| 相对 astra v1.1（09-30） | 相对 opus v3.0（09-28） |

## 需要领导层拍板的八件事

1. **形态与架构**：单一云端执行内核 + 本机能力层；Kimi Code 作后端隔离执行器（第 4 篇）。
2. **首发范围**：五个生产档 + 两个以授权为条件的升档场景；18 套合同规则包（第 3 篇）。
3. **版本与价格**：团队版 9,800 元（3 席起、每 3 席含 1 个审阅签发席）、加购审阅签发席 1,800 元、律所版 8,800 元 + 分档平台费、专属云按单、专业版 3,600 元（2027-07）、渠道版；试点期价格实验（第 7 篇 §1、§5.4）。
4. **投入与止损**：阶段拨款，至 G2 约 1,100 万元；基准累计现金峰值约 4,800 万元、2030 年经营基本打平（第 7 篇 §3、第 8 篇 §4.2）。
5. **与月之暗面的 P0 条款**：数据条款、专属配额、价格、品牌细则、渠道规则（第 7 篇 §4）。
6. **设计合作律所**：非诉、诉讼、有 IT 团队的区域规模所各一家（第 7 篇 §5.2）。
7. **入口优先级**：IM 首发一家；Word COM + WPS 首发（第 2 篇 §6、§8）。
8. **法源首年预算**：固定约 80 万元 + 按量；G1 中段前签署法律之星 MCP 与法规订阅数据服务书面许可、元典或北大法宝企业合同（含多租户条款）（第 5 篇 §2）。
