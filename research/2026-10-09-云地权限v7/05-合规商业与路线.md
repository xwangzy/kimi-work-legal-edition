## 4. 对外口径（v7）

见第 2 篇 §12。四条红线不变：不说“数据不出律所”；不说“中软不是处理者”；不说“本地化部署”（除非私有模型 + 执行器 + 自有存储 + 私有控制面）；不用绝对化用语。新增两句可以说的话：

1. “**Kimi Code 本地 Agent 能力不打折**：Kimi Work 在电脑上靠 Kimi Code 做的事，发行版都能做；区别是每一步都在事项沙箱和律所策略之内。”（Kimi 闭源云技能如 PPT/建站、深度研究、桌面操控不在其列，见第 3 篇 §1.5）
2. “**AI 写的代码在没有网络的沙箱里运行，每一次联网都有记录。**”

### 5.2 点数
