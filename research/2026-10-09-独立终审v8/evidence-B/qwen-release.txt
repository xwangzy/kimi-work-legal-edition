<Update label="2026年09月23日" description="千问办公 1.2.1">
  **产品功能更新**

  - 会话产物预览新增鼠标悬停行两段式全选：首次选中当前行，再次全选整段文本。
  - 全局搜索纳入定时任务及其历次执行记录，并统一按时间倒序展示。

  **体验优化**

  - 上下文压缩后及时刷新最新用量，右下角圆圈和悬浮卡片不再停留在旧状态。
  - 优化启动与首页欢迎动画的播放与收尾，播放完成后及时停止，减少持续资源占用。
  - 提交反馈时自动附带追踪标识，问题定位更快。

  **问题修复**

  - 修复切换语言后界面未强制刷新的问题。
  - 修复连接器市场超过 100 项时列表未完整加载的问题。
  - 修复 IM 频道群聊会话内 Agent 指令消息未回传到桌面端的问题。
  - 修复沙箱内无法启动 Chrome 的问题，同时优化重试指引与授权文案。
  - 加强鸿蒙 PC 系统接口与 Windows VM 服务的权限边界。
</Update>

<Update label="2026年09月21日" description="千问办公 1.2.0">
  **产品功能更新**

  - 新增「安全中心」入口：在设置中可查看数据加密、关键操作记录、敏感信息识别、文件删除保护、批量删除确认等安全能力状态，并可回看历次审批与文件防护记录。
  - 输入框新增「自动审批模式」：在关键操作前自动识别风险并给出安全提示，累计防护记录可在安全中心查看。
  - 项目管理升级：支持自定义项目图标；一个项目可关联多个工作目录；项目分区支持按创建时间、修改时间等排序；操作菜单同步精简。
  - 定时任务集中管理：任务卡片可直接打开最近一次执行结果；历次执行记录支持重命名、归档、置顶与批量操作。
  - 新增「淘天」官方连接器，可在对话中直接调用淘天相关能力。
  - IM 频道机器人首次配置成功后，会自动向用户发送一条欢迎消息，说明后续使用方式。
  - 设置中新增账号注销入口，可在客户端内直接完成注销申请。

  **体验优化**

  - 数据导入更清晰：来源识别、摘要展示、能力名称与折叠交互全面优化；从 WorkBuddy 等来源迁入的归档任务保留归档状态，可在归档中正常查看。
  - 技能安装更稳妥：安装前会校验安装包，安装过程中若失败可自动回滚，避免影响已装技能。
  - Windows 版更新失败后能可靠清理临时文件，不再重复下载和占用磁盘空间。
  - 项目操作菜单文案统一为「打开工作目录」；任务在项目间移动或移出项目时会给出结果提示并支持一键撤销。
  - 侧边栏各分组默认按最小展开数量呈现，首屏更简洁。

  **问题修复**

  - 修复定时任务在重命名字数、归档展示、搜索排序、快速手动执行以及归档跳转、二次确认交互上的不一致问题。
  - 修复后台任务续跑时消息可能被丢弃、误报「任务异常终止」，以及联网搜索、图片生成结果显示位置错乱的问题。
  - 修复连接器相关问题：飞书连接器在受限网络下的错误提示更清晰；连接器选择弹窗图标补齐；登录刷新失败后连接器状态可正常恢复；钉钉连接器部分工具偶发不可用后无法恢复。
  - 修复「自动审批模式」下偶发「审批超时终止任务」的问题。
  - 修复项目关联多个工作目录时产物文件落到次要目录的问题。
  - 修复会话卡片选择推荐后无响应、输入框「+」面板旋转动画、部分安全拦截场景下报错提示不清晰以及个别页面文字模糊的问题。
  - 修复错误提示不完整、错误页遗留旧品牌文案、设计与 PPT 风格文案的品牌残留，以及积分历史任务名称展示不准确的问题。
</Update>

  - 修复外部链接导入连接器时可能携带本机高权限配置的安全隐患。
  - 修复企业技能重复发布时的错误提示。
  - 修复不同侧边栏分组之间意外共享排序结果的问题。
  - 修复单个异常工作区导致整批数据迁移中止的问题。
  - 修复权限确认过程中反馈提交状态竞态导致的展示异常。
</Update>

<Update label="2026年09月07日" description="千问办公 1.0.4">
  **产品功能更新**

  - 新对话默认使用最近打开的项目：点开新对话可直接沿用上一次的工作目录与上下文，不再需要重新挑选项目；从当前任务新建的任务同样会继承所属项目。
  - 产物文件支持"另存为"：Agent 生成的文件可直接保存到指定目录，保存完成后一键在文件管理器中定位到新文件。
  - 设计、写作、PPT 三种模式移除 "Beta" 标记，作为常态能力对全部用户开放。
  - 首页新增多人工作台等推荐气泡，点击气泡下的案例，一键体验千问办公更多玩法。

  **体验优化**

  - 助手回复的中间过程折叠更合理，能更快聚焦在最终结果上；任务监控面板与本地项目目录展示对齐，创建定时计划时不再自动展开监控面板。
  - 消息频道在断网、休眠、网络切换后的自动恢复能力覆盖到所有渠道，减少手动重连；消息投递失败时会自动尝试更稳定的网络链路。
  - 新建项目直接选择系统目录时自动补齐项目名；新任务输入框状态、消息排版节奏、企业版积分展示统一打磨。
  - 定时计划卡片交互与展示优化，新建时默认使用当前时间。
  - 输入框粘贴体验优化：多行文本与连续粘贴更流畅，粘贴到已有输入时不会覆盖原有内容。
  - 首页推荐加载与刷新体验完善，加载失败时保留兜底展示，分类默认收起、避免首屏过长。
  - 英文界面显示更彻底：清理各页面遗留的中文残留；统一下拉菜单在长列表下的滚动交互与视觉。
  - 技能菜单在长名称下的提示更完整；扩展市场的专家套件、连接器展示与刷新更实时。

  **问题修复**

  - 修复消息频道在部分场景下偶发消息丢失、休眠后无响应的问题。
  - 修复 Windows 端开机启动设置失效，以及 Windows ARM64 平台上的安装与鉴权异常。
  - 修复画布工作台在窄窗口下顶栏重叠、任务切换时界面闪烁的问题。
  - 修复子任务未按预期在前台执行的问题。
  - 修复功能引导浮层与设置面板层级冲突、无法关闭的问题。
  - 修复扩展市场部分场景下同时显示新旧版本、专家套件重复提交提示异常、市场列表分页与总数展示不准确的问题。
  - 修复工作台在部分场景下的异常报错，以及工具名中文缺失导致的展示异常。
  - 修复历史数据迁移过程中登录态可能被误清、工作目录关联异常的问题。
  - 修复交付卡片在部分环境下无法正常呈现的问题。
  - 修复网页发布确认卡片未跟随应用语言，以及粘贴网页链接后无法与后续文本正确续写的问题。
  - 修复企业团队管理员角色映射，以及企业积分配额在部分字段缺失时展示异常的问题。
  - 修复技能菜单 Tooltip 聚焦时闪烁的问题。
</Update>

<Update label="2026年09月04日" description="千问办公 1.0.3">
  **产品功能更新**

  - 支持完整复制用户消息并恢复到输入框重新编辑，附件、引用和长文本一并保留，方便直接复用已有输入。
  - 主输入框支持有序、无序及多级 Markdown 列表，并完善缩进、换行与复制粘贴。
  - 输入框和聊天消息支持网页链接识别与站点图标展示，点击即可打开。
  - 输入框文件卡片支持一键定位文件，目录卡片支持直接打开目录。
  - 图片附件采用缩略图展示，支持点击预览，覆盖纯图片与混合附件场景。
  - 网络错误卡片新增"网络诊断"与"问题反馈"入口，遇到网络异常可就地排查与上报。

  **体验优化**

  - 聊天与侧边栏交互整体打磨：优化消息间距、工具详情、折叠动效、代码块复制、本地文件操作，并完善侧边栏的批量归档二次确认。
  - 内容区宽度与扩展市场响应式布局优化，适配更大与更窄窗口下的长标题展示，macOS 端提供字体平滑设置。
  - 联网搜索更主动：对时效性和不确定信息更倾向发起联网检索，同时保留稳定事实、内部信息和"不联网"要求的处理边界。
  - 定时计划对有限日期内的重复提醒进行聚合，减少同一诉求被拆成多条一次性任务的情况；复杂时间规则的展示更清晰。
  - 模型列表标签的显示优先级调整，模型描述与推荐/限免标呈现更符合预期。
  - 企业微信、微信等 IM 频道策略异常后支持按需恢复，减少手动重连。

  **问题修复**

  - 修复执行失败时已生成回复被清空的问题，网络等异常发生时保留已输出的内容。
  - 修复连续中文输入首字母偶发丢失、粘贴长链接撑开新任务输入区、技能提示文字不可读、输入框控件暗色与悬停显示异常。
  - 修复 Windows 端输入框模糊与附件图标显示、设置窗口关闭按钮在右侧边栏打开时被遮挡无法点击的问题。
  - 修复鸿蒙 PC 端新任务里技能、专家套件、任务、定时任务等子菜单无法通过触屏触发的问题。
  - 修复企业微信被新连接踢下线后卡在"连接中"、断线不自动重连的问题。
  - 修复从旧版本迁移后，定时任务仍会通过历史会话发送消息的问题。
  - 修复媒体生成新建会话时可能与既有会话数据串扰的问题。
  - 修复部分场景下 HTML 组件渲染异常、"我的网页"快捷发布失败的问题。
  - 修复企查查连接器已连接但对话仍提示不可用的问题。
  - 修复扩展市场专家套件数量固定为 20、下拉不滚动只展示前 20 条的问题。
  - 修复 Windows 端开启"安全工作环境"时被安全软件拦截的问题，可选依赖安装失败不再阻断主程序安装。
