# 06 研发路线、上线验收与决策清单

## 1. 范围、进度与团队的关系

此处估算覆盖Windows桌面主入口、C/L共同业务内核、C云执行、L本机标准工具及通过验收的代码沙箱、三条业务链、首家Office深度集成、基础协作/管理/计费/运维。L跨设备E2EE同步作为独立验收增量；未完成时L仅已授权本机，不能用共享网盘临时代替安全承诺。

不含首发强制范围：macOS全面适配、独立双端移动App、所有IM/Office平台、任意电脑操控、法院自动递交、全行业36场景生产化、完整私有交付。架构保留接口；排除这些不影响对已售范围提供完整服务。

现有v7约895人周并非明显离谱；缺陷是范围反复增加却沿用日期。本方案也不宣称双执行路径更省研发费，而是让费用对应客户价值、减少同步密码学与多入口并行风险。

## 4. P0技术验收集

所有“零”指标表示在明确测试集上的零例，不能推广为现实中绝不发生。测试报告记录环境、版本、样本来源、分母、观察时间和失败重现。

| ID | 测试 | 阻断条件 / 通过标准 | 负责人 |
|---|---|---|---|
| T01 | 租户/事项/伦理墙 | 跨租户、跨案、搜索、预签URL、缓存、导出任一越权即阻断；至少覆盖全部对象API和角色组合 | 安全+后端 |
| T02 | 文件隔离 | symlink/junction/reparse/UNC/大小写/长路径/TOCTOU/压缩穿越全部拒绝；不返回内容片段 | 客户端+安全 |
| T03 | 代码出网 | DNS/TCP/UDP/WS/raw socket/自建dispatcher/子进程/回环/云元数据均按策略阻断 | 平台+安全 |
| T04 | 工具策略覆盖 | 每个内置/MCP工具、子Agent、默认放行路径、遥控入口均走宿主政策；故障不得放行高风险动作 | Agent+QA |
| T05 | 提示注入 | 至少300个分层攻击用例覆盖PDF/网页/文件名/技能/图像/OCR/文档外链；无权限扩大、未授权外发/写入 | 独立红队 |

| T07 | 撤权与租约 | 在线目标初始≤60秒停止新操作；高风险提交实时检查；离线承诺按TTL和已持有数据限制展示 | 内核+安全 |
| T08 | 故障终态 | timeout/length/非零exit/流截断/缺artifact不能成功；部分结果明确列出 | Agent+QA |

| T10 | 密钥/恢复 | 设备签名钥不跨设备复制；个人/组织恢复、管理员更换、失窃/离职可演练；L若售E2EE须独立密码评审 | 安全+客户端 |

## 5. 法律质量与文档验收

保留v5的360个任务集结构作为满范围评测目标：合同180（9类×双立场×10）、案卷60、研究60、文书30、顾问答复30；不同用途只作标签，不重复计算分母。首批4类合同可先用80个合同任务，加其余相关业务任务；报告不得声称已经评过9类。至少20%冻结保留集，由独立评审律师盲评；试点新增失败例另列，不删除难例提高成绩。

| 指标 | 初始发布门槛建议 | 解释 |
|---|---|---|
| 严重法律风险漏检 | 关键必查点加权召回≥95%，逐类型/立场报告 | 律师定义严重度；样本置信区间与最差分组必须公开给验收方 |
| 引用真实性/定位 | 正式交付抽查引用100%可追到实际取得的确定版本 | 原文不可得标未核验；搜索标题不是原文 |
| 命题支持度 | 人工盲审≥95%，关键法律结论无已知不支持引用 | 法条真实不代表支持当前命题；法律适用另外审查 |
| 材料覆盖 | 应处理文件/页均有状态；无法解析显式 | 不要求OCR神奇100%，要求不静默遗漏 |
| 事实抽取 | 核心字段准确率≥95%，关键日期/金额出错必须触发复核 | 报告扫描/原生分层与缺失处理，不自动填零 |
| 原生修订与保真 | 至少50份复杂文档、目标宿主往返，无原件覆盖与关键内容丢失 | 编号、表格、脚注、域、签章、外链等单项说明 |
| 计算 | 至少100个边界案例，确定性结果符合已批准公式 | 公式法律适用与数学计算分开验收 |
| 敏感导出 | 关键标识专项+人工复核；已知敏感残留为阻断 | 不能用平均脱敏率宣称匿名化 |
| 总工时改善 | 试点同任务中位数节省≥30%作为价值门槛候选 | 计入复核、改错、排版；无优势则调整场景/定价 |

上述数值为建议目标，尚无本次实测成绩。质量评审采用独立两律师评分和争议裁决；盲测任务来源有合法评测许可，不使用禁止评测的数据商内容。正式发布时附任务范围、分母、置信区间及已知局限；不能把有限样本的零事故包装为百分百可靠。

## 6. 运维与商业上线门禁

| 门禁 | 初始目标/材料 | 失败处理 |
|---|---|---|
| C灾备 | 目标RPO≤15分钟、RTO≤4小时，先做真实恢复演练；签发对象不可丢 | 未过则不得承诺该SLA，缩小试点范围 |
| L恢复 | 本地备份/已售密文备份可恢复；私钥丢失情景结果可解释 | 不售未验证恢复能力 |
| 服务可靠性 | 网关/控制面目标99.9%，容量压测为预计试点峰值2倍；熔断/排队可见 | 小范围限额，不无限扩销 |
| 外部依赖 | 模型、搜索、法源、云、IM的服务条款与故障责任齐全 | 缺哪一项停哪一项，不用模拟数据冒充 |
| 费用 | 重度/无缓存/低价情景不意外失控；预占与对账完整 | 调整额度、算力档或售价 |
| 合规 | 实际适用登记/备案/标识/隐私/安全要求完成并公示 | 未满足对应要求不公开销售 |
| 客户服务 | 负责人、响应时限、升级路径、状态页、培训/退出可执行 | 继续受控试点 |
| 交付清单 | 产品/技术/安全/法律/运营共同签字，销售口径一致 | 不因单方“技术跑通”放行 |
