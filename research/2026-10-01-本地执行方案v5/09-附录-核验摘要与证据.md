## B. 联网核验摘要（V1–V4）

### B.1 V1：token 通道、中软 token 业务、IM 长连接、Electron（一手为主）

| 事实 | 改变了什么 |
|---|---|
| Kimi 的限速、缓存、IP 白名单、余额都在**组织**级；项目级只有月/日预算与 TPM 上限；Key 级无任何控制；企业认证组织最多 50 项目、100 Key；无按 Key/项目查用量的 API；Tier5 并发 100、TPM 500 万 | 月之暗面密钥只能留在 MaaS 服务端；法律分组用独立上游组织并谈专属额度 |
| 服务协议许可“不可再许可”“仅供内部使用或向最终用户提供服务”；账号不得提供他人使用；仍授予“服务优化”使用权；ZDR 不覆盖文件上传的图像视频、托管智能体、连接器 | 嵌入产品服务律所在许可内；转卖裸 Key 不在许可内；企业协议门禁 |
| 自动前缀缓存**按组织隔离**；Anthropic 端点 `cache_control` 只在顶层生效、不传则只读不写；K3 缓存写入 5m ¥20 / 1h ¥40 | 本机代理负责缓存布局；经 MaaS 时基础方法包前缀跨律所命中 |
| 官方请求签名校验（`X-Msh-Request-Nonce`） | “模型真实性校验”：可证明请求到达 Kimi 且模型未被替换，不能证明中转层未留存 |
| `$web_search` 预计 10-20 下线；新搜索与抓取接口在云端执行 | 法律研究不用平台联网搜索 |
| K2.8 未开放 API；K3/K2.6/K2.7 价格未变 | 经济模型沿用公开价 |
| 中软 06-03 公告“token 销售”业务；07-20 协议“Token 消耗收益”分成，未提法律、未披露比例 | 集团协同不进基准 |
| 钉钉 Stream、飞书长连接（仅企业自建应用）、企业微信智能机器人长连接均无需公网 IP；飞书/钉钉多连接随机投递、企业微信单连接；钉钉机器人消息离线即丢；飞书卡片回调须 3 秒内响应；企业微信与飞书外部群的文件限制 | IM 连接器必须是律所侧唯一常驻连接点（所内节点或 IM 主机）；文件转发在单聊完成 |
| Electron 43/44/45 内置 Node 24.21；42 于 10-20 停止支持；`utilityProcess` 固定不开沙箱、无降权选项 | 首发 Electron 44；Agent 与解析进程由原生启动器降权 |

### B.2 V2：合规与法源本地化（一手为主）

| 事实 | 改变了什么 |
|---|---|
| TC260 PG-20266A 7 b)1)（准备阶段）“应选择独立设备安装智能体”；6 c) 注：商业智能体核对满足后续章节“无需重复采取后续安全措施” | 以“内置隔离替代物理隔离”证据包回应；提供虚拟化部署备选；更正 v4.0 的章节位置 |

| PG-20268A 7.4 c)3) 本地服务器的防护要求；7.4 c)4) 终端数据确需外传宜事先同意并做影响评估 | 所内节点部署前提；告知同意与影响评估成为上线前提 |
| 暂行办法第二十二条：经可编程接口提供服务也是提供者；09-14 国家公告：调用已备案模型的应用由地方网信办登记 | 标准端点由中软按产品维度登记；自带密钥/私有模型可主张内部使用排除 |
| 个人信息保护法“传输”即处理；无状态中转仍是受托人；“软件供应商不接触即非受托人”无国内权威解读 | 标准端点签 DPA；自带密钥与私有模型以“零接触”附件支撑 |
| 网络安全法 2025 修正（2026-01-01 施行）：日志留存为**第二十三条第（三）项**；第二十四条第三款收集用户信息须明示同意 | 全部材料改条号；遥测默认关闭 |
| 上海律协居村指引 4.7“本地化部署”定义：系统运行、数据存储和处理完全在本地环境内完成；第十五条五类敏感信息不宜上云 | 对外口径“本地执行，云端推理（大所可选律所内私有模型）”；五类敏感信息默认只走私有模型 |
| 法律之星订阅面向订阅方“全量同步到本地系统”；MCP 协议禁止向第三方分发原始数据集合与系统性镜像 | 离线法规库以官方公报文本自建；订阅数据须单独再分发授权 |
| 著作权法第五条；立法法第六十二、七十八、八十九、九十七条（公报文本为标准文本） | 官方文本可内置；不自动化抓取官方数据库 |
| 联合信任 TSA 提供 RFC 3161 / GB/T 20520 接口（价格不公开）；互联网法院规定第十一条认可可信时间戳与哈希校验；在线诉讼规则第十八条：锚定前真实性另需证明 | 签发即锚定；审计链记录生成机制；对外不夸大证据效力 |
| 标识办法：导出功能的服务提供者须确保显式标识；第九条无显式标识导出留日志 ≥ 6 个月；PG-20258A 仍为 V1.0-202508 | 标准端点下标识义务在中软；隐式标识始终保留 |
