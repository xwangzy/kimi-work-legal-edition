# 运营接口契约（控制面 `/v1/ops/*`，第 44 批）

- 全部请求带运营签名（`apps/ops-console/ops-sign.js` 现有写法，不变）；GET 不带体。
- 应答 JSON；错误 `{error:{code,message}}`，`message` 是可直接显示的中文。
- 金额字段 `*_cny`：元，数字，保留 4 位小数（界面显示 2 位）；未定价为 `null`（界面显示“未定价”，不要显示 0）。
- 比例字段 `*_ratio`：0–1，保留 4 位小数。时间一律 ISO 字符串（UTC），界面按北京时间显示。
- 额度单位 `unit`：`"tokens"` 或 `"cny"`；`used/total` 在 tokens 下是整数 token，在 cny 下是元。
- 权限：所有 GET 要 `tenant.read`；写操作见各行。新增权限名：`account.manage`、`route.manage`、`plan.manage`。

## 1. 总览

`GET /v1/ops/overview?days=30`
```
{ generated_at, period: {kind:"month", key:"2026-11", start, resets_at},
  totals: { requests, tokens_in, tokens_cached, tokens_out, value_cny, cost_cny, revenue_cny, margin_cny, errors, estimated_rows },
  accounts: { total, active_7d, new_7d, disabled }, tenants: { total, active, pending, expiring_30d }, devices: { total, active_7d, flagged },
  daily: [{ day:"2026-11-14", requests, tokens, value_cny, cost_cny, errors }],      // 最近 days 天，含今天，缺的天补 0
  by_model: [{ alias, label, requests, tokens, value_cny, share }],
  attention: [Alert],                                                                // 未确认告警，新的在前，至多 20
  routing: { version, providers: [{ id, label, state, latency_ms, updated_at }] } }
```

## 2. 客户（律所 / 租户）

`GET /v1/ops/tenants` → `{ tenants: TenantRow[] }`
```
TenantRow = { tid, name, edition, plan:{id,label}, seats, seats_used, status:"active"|"pending"|"expired"|"terminated",
  subscription_until, created_at, accounts_required, unit, period:{kind,key,start,resets_at},
  used, total, used_ratio, in_flight_ratio, cap_pct, boost_pct, paused: null|"cap"|"allowance"|"burst",
  forecast_exhaust_at: string|null, accounts, devices, alerts_open, value_cny, cost_cny, legacy_used_ratio }
```
`POST /v1/ops/tenants`（`tenant.manage`）`{tid, name, plan, seats, subscription_days, edition:"team"|"firm", accounts_required?}` → `{tenant: TenantRow}`
`GET /v1/ops/tenants/{tid}` → `{ tenant: TenantRow, members: [{uid, member_slug, role, aid|null, email|null, name|null, seat:{sid, revoked_at}|null, devices:n}], devices: DeviceRow[], activation_codes: [{id, kind, member_slug, status, created_at, expires_at}], usage: TenantUsage, bill: BillRow }`
```
TenantUsage = { unit, period, used, total, used_ratio, burst: {hours, used_ratio}|null,
  history: [{ period, used_ratio, legacy }], daily: [{day, used, requests}], by_model: [{alias, used, requests}],
  by_account: [{ aid|null, uid, email|null, name|null, used, used_ratio_of_firm, own_ratio|null, requests }],
  unreconciled_leases }
```
写操作（沿用现有，体不变）：`POST …/boost {pct}`（`quota.manage`）、`POST …/plan {plan?, seats?}`（`quota.manage`）、`POST …/cap {cap_pct}`（`quota.cap`）、`POST …/seats/{uid}/revoke`、`POST …/devices/{dev}/revoke`（`device.revoke`）、`POST …/activation-codes {member_slug?}`（`activation.issue`，回 `{code, activation_id, expires_at}`，码只显示一次）、`POST …/activation-codes/{id}/revoke`、`POST …/renew {days}`（`tenant.manage`）、`POST …/terminate`（`tenant.terminate`）。
新增：`POST …/accounts-required {required: boolean}`（`tenant.manage`）。

## 3. 账号

`GET /v1/ops/accounts?q=&tid=&status=active|disabled&limit=50&cursor=` → `{ accounts: AccountRow[], next: string|null }`
```
AccountRow = { aid, email, name, status, tid, tenant_name, role, created_at, created_via, last_login_at,
  devices, device_limit, sessions_active, quota_limit, used_ratio|null, locked: boolean }
```
`GET /v1/ops/accounts/{aid}` → `{ account: AccountRow, devices: DeviceRow[], sessions: [{sid, kind, device_id, created_at, last_seen_at, idle_expires_at, client:{version,platform}}], usage: { unit, used, total|null, used_ratio|null, denominator, requests, value_cny, by_model, daily }, alerts: Alert[] }`
写（`account.manage`）：
- `POST /v1/ops/accounts {tid, email, name, role}` → `{ account, setup_code, expires_at }`（设置密码码，只显示一次，24 小时）
- `POST /v1/ops/accounts/{aid}/disable {reason}`、`POST …/enable`
- `POST /v1/ops/accounts/{aid}/reset-code` → `{ reset_code, expires_at }`（30 分钟，只显示一次）
- `POST /v1/ops/accounts/{aid}/sessions/revoke` → `{ revoked: n }`
- `POST /v1/ops/accounts/{aid}/limits {quota_limit: number|null, device_limit: number|null}`

DeviceRow = { tid, tenant_name, device_id, uid, aid|null, email|null, role, client_version, last_seen_on,

## 5. 模型与路由

`GET /v1/ops/routing` → 
```
{ version, updated_at, updated_by, routing_key_id,
  providers: [{ id, label, vendor, base_url, enabled, key_set, key_hint, key_set_at, max_concurrency, header_timeout_ms, idle_timeout_ms,
                health: { state, latency_ms, last_ok_at, last_error, consecutive_failures, probed_at, holder, updated_at } | null }],
  models: [{ alias, label, enabled, is_default, builtin, targets:[{provider, model, priority}], allow_cross_vendor, default_max_tokens }],
  prices: { version, effective_at, items: { [alias]: {input, cached_input, output, cost_input, cost_cached_input, cost_output} } },
  price_history: [{ version, effective_at, by }] }
```
写（`route.manage`）：
- `PUT /v1/ops/routing/providers/{id} {label, vendor, base_url, enabled, max_concurrency?, header_timeout_ms?, idle_timeout_ms?, key_sealed?, key_hint?}`（不带 `key_sealed` = 不改密钥）
- `DELETE /v1/ops/routing/providers/{id}`（仍被模型引用时 409 `provider_in_use`）
- `POST /v1/ops/routing/providers/{id}/probe` → `{ probe_requested_at }`
- `PUT /v1/ops/routing/models/{alias 经 encodeURIComponent} {label, enabled, is_default, targets, allow_cross_vendor, default_max_tokens}`
- `DELETE /v1/ops/routing/models/{alias}`（内置别名 `legal/k3`、`legal/k2.6` 不可删，409 `builtin_alias`）
- `PUT /v1/ops/routing/prices {items}` → `{ version }`（单价：元/百万 token，`null` = 未定价）

`key_sealed` 在浏览器里生成，算法见主文 §3.2；网关公钥取自控制台 `config.json` 的 `routing_public_key`（SPKI base64）与 `routing_key_id`。
