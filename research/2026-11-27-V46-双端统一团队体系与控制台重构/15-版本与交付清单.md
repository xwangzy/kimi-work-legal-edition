## 3. 升级（运维执行，云端先于客户端）

1. 按运维手册 §5 用 **v1.7.0 的** `upgrade.sh`：备份 → 切代码 → 按顺序重启 → 健康检查 → `verify-capabilities.sh`（本版新增核对 5 项：`workspaces`、`team_invites`、`team_member_auto_enroll`、`onboarding_state`、`catalog_epoch`，另有 `device_share_confirm`）。
2. **升级后必看“模型与路由”的告警**：已有部署的路由状态不会自动改 K2.6 的上游。若出现 `routing.same_upstream`（K2.6 与 K3 都调用 `kimi-k3.1-pro`），客户端已把 K2.6 置灰；请在控制台把 `legal/k2.6` 改指 `kimi-k2.6` 并确认价目，告警消失后客户端 K2.6 可选（任务与问答都可选）。
3. **建议把试用套餐“每账号同时登录电脑数”从 1 调到 2**（控制台“套餐”）：新部署缺省已是 2；已有部署的套餐目录保留原值。
4. **存量团队的成员新电脑策略**：升级时读回定型为“须管理员确认”（保持原行为）；1.7.0 起新开通 / 就地升级的团队缺省“直接登录”。律所管理员可在客户端“设置 · 团队 · 团队策略”或控制台“本所 · 成员”改为“直接登录”。
5. 客户端：0.11.0 覆盖安装，本机数据原样保留。

## 4. 数据迁移

- 云端：**无迁移脚本**，读回时就地定型并立即写盘：租户 `kind`（按原 `personal` 判一次，之后不再按形状推断）、路由 `epoch`、存量团队 `member_device_policy:"approve"`、已停用且无来源的账号 `disabled_by:"platform"`（保守：团队侧不能启用）。新字段都有缺省；关联账号（`person`）只在 1.7.0 之后由“加入团队”产生。
- 客户端：**无本机数据库迁移**（下一号仍为 0076）；新增本机文件 `window-state.json`（Electron userData，窗口几何与保存时的显示器缩放比例）、`account-meta.json`（每个档案的工作区里，工作空间类型与上手时间戳）、`share-confirm.json`（团队共享确认状态，无秘密），均已登记写盘面（`docs/privacy/residency.json`）。激活后内核把待激活占位区改名为数据根下隐藏的 `.pending-trash-*` 再在后台删除（Windows 上删不掉时留到下次启动再删，不再阻塞启动）。

## 5. 回滚

- 云端：`rollback.sh` 回到 1.6.x。**若升级后已有人“加入团队”（产生关联账号，邮箱为空），必须用 `rollback.sh --restore <upgrade.sh 记下的备份>` 回到升级前状态**——1.6.x 代码在运营搜索里会对空邮箱调用字符串方法而报错；回滚后升级期间新建的团队身份、邀请、团队共享确认随之丢弃（用量账本与审计链保留）。没有关联账号时直接回滚代码即可。
- 客户端：重装 0.10.0 安装包即可（本批没有改本机数据格式；新增的三个本机文件旧版忽略）。

## 6. 已知限制

- macOS DMG 未经 Apple Developer ID 签名（ad-hoc）：首次打开须“仍要打开”，并会弹钥匙串授权（须本人点“允许”）。
- Windows EXE 尚无代码签名证书：SmartScreen 会提示；对外分发须附 `SHA256SUMS` 及其签名。
- 新的云端能力（工作空间、团队、事后确认、模型真实映射）要等运维把线上升级到 1.7.0 才在线上生效；在那之前 0.11.0 连线上 1.6.0 按降级口径工作。
- Windows 实机只在 GitHub Windows Server 2025 运行器上跑过（150% 为强制缩放参数，非系统真实缩放；未测 125%、多显示器、Windows 10 / 11 桌面版），连的是线上 1.6.0：工作空间、团队、事后确认等 1.7.0 界面没有 Windows 实机截图（两端同一份代码，Mac 真实栈已验）。见 `14-Windows实机联调.md` §5。
- 事项级“团队共享 / 把同事加进事项”在律师端仍没有界面入口（内核与密码学闸门已验证），团队共享还需所内先配置共享中继；列入下一批（13b P1）。
- 离所交接不强制；凭团队邀请注册的人离开团队后没有个人空间（13b P1，沿用）。
- 试用说明“约 10 单常规任务”与实测不符：Windows 实机一单合同审查 + 修订稿占试用月额度约 27%（13b P2）。
