# 95 个预设的语义与优化复核

本轮已逐卡点击全部预设，完整可见编辑器值的摘要与旧台账 95/95 一致。下表是研究者对任务语义和改进重点的原创归纳，不是页面逐字全文，也不是对示例案件给出的法律结论。每个编号的完整优化提示词、输入、方法和验收见本手册对应 H/S 条目。

“保留”表示旧优化方向经过本轮重读仍应采用；“细化”表示在已有优化基础上增补。摘要相同只能证明两次采集内容稳定，不等于提示词本身正确。

## 主站 H01—H36

| 编号 | 任务与关键材料语义 | 复核后的方法要求 |
|---|---|---|
| H01 | 合伙经营与公司主体并存，停业损失及被告范围 | 先核经营主体、权利归属和损失因果，不先认定个体/合伙关系；请求与被告分别论证 |
| H02 | 买卖欠款的合同、签收、对账、质量与退货证据 | 待证命题与正反证据逐项对位，签收缺口和质量抵扣单列 |
| H03 | 分批供货、付款承诺与按日违约金的诉状 | 对账和分段计算先于文书；规则适用、可能调减与草稿状态明确 |
| H04 | 股权交易隐瞒担保税务，与付款违约相互抗辩 | 最强反论和真实未知正面回应，模拟答案不写回事实库 |
| H05 | 未阅卷时首次会见涉嫌资金占有的经理 | 家属说法与指控分开，开放问法、程序与合法取证方向并列 |
| H06 | 醉驾本地类案刑罚分布与从宽因素 | 记录样本、地域、分组与限制；缓刑样本占比不转为个案概率 |
| H07 | 审查起诉阶段核金额、职权及审计材料 | 证据覆盖和备选辩点分层，材料不足不先评成确定辩点 |
| H08 | 支付结算角色、无关流水与退缴情节的辩护意见 | 主从犯、涉案数额和从宽事实分别核实，保留相反材料 |
| H09 | 解除、欠薪、加班和年休假的多请求测算 | 互斥/替代请求分开；基数、工龄、时数、工资支付状态有来源 |
| H10 | 地方不能胜任解除案件与证明路径 | 不将公开样本支持率当本案胜率；训练/调岗、制度与考核分别查 |
| H11 | 预给仲裁金额与工龄工资未自然对应 | 保留原请求并独立复算，报告差异；不从相邻卡继承休假和时数 |
| H12 | 企业绩效解除、制度和工时审批缺口 | 分项评估、情景测算与补证整改；不为抗辩虚构审批或签收 |
| H13 | 收购方完整尽调方案与管理层访谈 | 交易目标决定范围，资料清单、核查、风险和交易保护对应 |
| H14 | 指定上市主体转债全周期公告 | 以正式披露原文、版本和事项链整理；研究截止日和缺失公告明示 |
| H15 | 投资方特殊权利、治理、回购及交割条件 | 法律可行与商业选择分开，义务主体和执行约束不能由偏好代替 |
| H16 | 多主体并购节点、90日窗口及后续业绩期 | 每个相对日绑定事件；内部制作、审批、登记按不同完成证据记 |
| H17 | 多种担保及在先顺位的授信审查 | 权属、权限、设立、登记、顺位、价值及实现条件逐项检查 |
| H18 | 网络风险保险责任与多渠道销售 | 可保性、免责说明、渠道准入和服务边界独立；不据合同承诺认定合规 |
| H19 | 新管理人、国资和个人出资的基金设立 | 主体、募资/登记/备案和国资决策分轨，路线依真实资格条件 |
| H20 | 手机银行代销、线下推介及自动跟投 | 实际流程、测评匹配、告知留痕和费用核查，不只生成免责清单 |
| H21 | 上市公司关联采购与参股担保程序 | 核交易所板块、章程、回避、累计口径与披露，补正不抹历史责任 |
| H22 | 董事对回购、资产转让与预付款的履职 | 分角色义务、冲突、知情与实际履职证据，不以反对/弃权概括免责 |
| H23 | 控制权收购及营业额门槛 | 控制、计算范围、上一年度、申报与简易条件分别核验 |
| H24 | 零售会员、人脸、广告回传、总部HR和泄露 | 真实字段、目的、角色及流向决定义务，历史事件独立处置 |
| H25 | 股权收购与核心团队服务/竞业安排 | 劳动、股东、出让方义务分型；不照抄统一三年离职竞业 |
| H26 | 软件采购中的知产、验收、违约与单方解除 | 明确片段审查范围；替代文本检验定义、价款和其他附件影响 |
| H27 | 设备延期、安装停滞和继续/解除方案 | 区分到货与安装责任、催告与损失，条件化测算和保权草稿 |
| H28 | 企业合同台账、预警及汇总表 | 字段口径、校验、公式与汇总闭合；签署/生效/到期分列 |
| H29 | 员工收款线索与违纪解除、追偿/报案 | 资金性质、制度程序、调查权益及证据门槛分别核，不代作处分决定 |
| H30 | 群体减员、均值与特殊保护人群 | 均值只做预算情景，逐人结果须逐人参数；不把N+1当统一法定义务 |
| H31 | 企业用工证据与员工聊天、照片、录音 | 先核解除理由与实际材料，质证不模板化否认真实性或加班 |
| H32 | 集团关联交易、优惠与异常发票 | 按真实交易和具体税种核规则，税务师交接与应答材料分开 |
| H33 | 广告投诉、询问/整改文件与处罚风险 | 先识文种、送达和回应期限；统计处罚与本案法定裁量分开 |
| H34 | 储值促销、推荐奖励和不可退条款 | 真实资金/服务流程及地方规则前置，法律障碍与可改方案对应 |
| H35 | 商场退租成本与商业环境变化 | 合同分配、事实因果、赔偿/履约及谈判选择分开，不保证解除 |
| H36 | 季度重大案件与管理层PPT | 在办、结案、执行、回款与计提口径分别对齐，图表不补造数字 |

## 工作台 S01—S59

| 编号 | 任务语义 | 复核后的方法要求 |
|---|---|---|
| S01 | 设备质量争议的庭前多角色推演 | 逐问演练，承认材料限制；不以回避不利事实为技巧 |
| S02 | 现金交付借贷的地方裁判倾向 | 现金来源、交付证据和裁判全文分组，样本边界与反例可查 |
| S03 | 生产线延误、产能和损失的案件体检 | 要件/证据/因果分开，示例甲乙方角色有歧义不猜义务主体 |
| S04 | 解除设备合同的诉状初稿 | 待补主体/金额/日期用占位；各请求和重复赔偿关系独立核对 |
| S05 | 微信、流水截图、录音和收款单的目录 | 证明命题与原始载体对应，不统一要求公证或将偷录一概排除 |
| S06 | 保全至执行的作战地图 | 保留旧稿先核法院级别要求；细化地域/级别/协议/专属，法定与经验排期分开 |
| S07 | 门锁用户数据合作的老板一页纸 | 数据性质和角色按实核，不将去标识化或不外传承诺当当然合法 |
| S08 | 门店突击检查首小时行动 | 依法配合、范围核对和记录留存，不销毁改造材料；具体机关规则分别核 |
| S09 | 合同分级审签、模板偏离与抽检 | 内部红线、法定限制与可例外标准分列，授权不按金额一维判断 |
| S10 | 硬件企业多业务模板体系 | 商流、货流、数据/知产决定主附件，优先级以真实风险敞口判断 |
| S11 | 销售合同风险培训 | 真实事件脱敏改编与虚构练习明确，培训效果连回具体行为 |
| S12 | 增员与年度法务预算论证 | 工时、需求和现金价值假设可复算，节省与创收不重复计 |
| S13 | 不胜任解除风险和协商备选 | 制度/考核/前置程序分别分析，保护条件按员工本人事实核 |
| S14 | HR劳动仲裁演练 | 面对不利事实如实说明，未核问题列核查动作，不教不正面回答 |
| S15 | 事业部减员与派遣、实习、保护人员 | 逐人条件与三种路径分开，情景预算不作逐人法定金额 |
| S16 | 员工手册与民主/公示程序 | 具体行为、比例、程序与证据链完整，新制度不追溯修补既往处分 |
| S17 | 算法企业分层保密与竞业 | 接触秘密、限制范围、补偿和启动分型，避免过宽限制与统一人员名单 |
| S18 | 平台、派遣和外包用工模式 | 保留旧稿按实际关系判断；目标是合法匹配模式和责任，不能仅换标签规避 |
| S19 | 股权、资产与分步交易沙盘 | 税费、资产转移、债务及人员依真实结构分析，跨专业缺口明确 |
| S20 | 创始人对赌回购的谈判分档 | 底线和交换须有商业授权，所谓隔离安排不用于逃避现有债务 |
| S21 | SaaS尽调及技术/数据/收入问题 | 行业专项目标明确，证据、访谈、风险和条款保护闭环 |
| S22 | 目标公司公开信息扫描 | 先主体消歧；线索不等于责任，公开无记录不等于无风险 |
| S23 | SPA保证、先决条件与赔偿弹性 | 既知风险与一般保证分开，赔偿机制算例检验、参数不自定 |
| S24 | 交割清单、负责人和相对日 | D的基准一致；股权收购不自动等于资产过户，条件完成与准备分开 |
| S25 | 跨境电商合规义务和组织 | 业务活动→适用规则→动作→责任人→证据→验证；不全企业一套矩阵 |
| S26 | 总部ERP与远程运维的出境路线 | 字段、敏感性、人数口径、豁免及真实目的重新核实，不沿用示例断言 |
| S27 | App处理活动、PIA与隐私交互 | 场景化合法性基础、必要性和实际技术流程，政策不代替产品改造 |
| S28 | 回扣举报与内部调查 | 原始线索、合法取证、权益与反报复分开，未定性不作公开指控 |
| S29 | 经营者集中及日常垄断风险 | 主体控制与营业额范围先核；交易申报与行为自查两条交付线 |
| S30 | 中东订单、美国技术和代付红旗 | 交易方/物项/用途/目的地及版本独立查，不能只做名单名称匹配 |
| S31 | IPO企业常法提案和服务报价 | 公开/客户已知与假设需求分开，报价明确范围、排除和响应条件 |
| S32 | 律师内容排期与短视频 | 客户事实最少化、合成示例标注，不承诺结果，营销与发布授权分开 |
| S33 | 计时、固定、风险和混合收费比较 | 工时缺项与回款情景明确，监管边界按案件/地区核，不补造市场价 |
| S34 | 储能行业法律需求与获客切入 | 一手行业/监管证据支持排序，不按个人印象给客单与容量数字 |
| S35 | 执业经历与专业定位 | 自述能力与市场证据分开，评分权重可调，不承诺创收 |
| S36 | 律师费催收与客户关系沟通 | 既有服务证据、支付方案和升级路径，避免不当停代理威胁 |
| S37 | 诈骗指控的量刑情节与缓刑条件 | 罪名金额和地域规则核验，避免折扣相加及样本转个案预测 |
| S38 | 采购经理收款的罪名边界 | 构成要件与具体证据逐项，不从金额、职务或无损失直接出罪 |
| S39 | 未阅卷首次会见与权利告知 | 中国具体程序规则，不照搬境外一般沉默权；转述指控不作确认事实 |
| S40 | 长时讯问、笔录及电子数据程序线索 | 瑕疵、非法证据和排除后果分别核，不从缺一手续自动判排除 |
| S41 | 实际经营、资金用途与诈骗辩护 | 真实履行与目的/金额分别论证，部分履行不能当然排除犯罪 |
| S42 | 工程企业高风险岗位与刑事内控 | 行政/民事/刑事门槛分型，整改不销毁证据、不概括公司或老板必然有罪 |
| S43 | 知产平台、行政、民事、刑事救济比较 | 标题三与实际四路径冲突依任务自行厘清，关键适用性不足才追问 |
| S44 | 技术分解、专利布局和FTO | 可保护性、新颖性与自由实施分开，不凭技术介绍保证创新或无侵权 |
| S45 | 新品牌品类、类似群和出海注册 | 分类版本、真实商品和检索日期明确，不把防御需求无限扩张 |
| S46 | 专利赔偿的多条计算路径 | 销量期间、利润口径、许可可比、重复与惩罚条件有依据 |
| S47 | 配方、客户信息和离职泄密 | 秘密点、非公知、价值与措施具体核，缺证不概括已构成侵权 |
| S48 | 竞品IP情报、技术地图和FTO计划 | 区分检索覆盖与可实施结论，权利要求/法律状态/地域逐项核 |
| S49 | 家庭资产与多种传承工具组合 | 权属、处分份额、控制和经营连续性分开，不承诺绝对隔离 |
| S50 | 公私混同、担保和家庭风险体检 | 责任要件、财务事实与合规整改分开，不用补文书掩盖资金事实 |
| S51 | 再婚夫妻的财产约定 | 权属证据、意愿、第三人及人格身份边界分别审，双方立场不混同 |
| S52 | 离婚资产、股权稀释、抚养与紧急措施 | 线索不先定转移，主体资格及合法取证；儿童权益不作谈判筹码 |
| S53 | 遗嘱份额、宅基地房屋与形式 | 多分金额先解释真实意愿；处分权、形式与实际订立过程分开 |
| S54 | 境内遗嘱与香港/美国资产 | 被继承人和继承人、domicile和税务身份分别核，当地法税转接 |
| S55 | 预付退款的国家与地方规则 | 经营地、行业、时间和赠额口径明确，不跨地区套地方规则 |
| S56 | 上诉、再审、执行及费用期限 | 缺年份和生效信息不猜；不同程序和起算事件分开核验 |
| S57 | 给经营者解释情势变更 | 通俗表达保留必要条件与商业风险边界，虚构例子明确标注 |
| S58 | 潜在客户谈判陪练 | 不替用户说话；逐轮反馈不编造真实报价、服务或沟通已发生 |
| S59 | 软件开发款代理观点的逻辑体检 | 隐含前提、备位主张、最强反论和补证先于润色，不把实际使用等同验收 |
