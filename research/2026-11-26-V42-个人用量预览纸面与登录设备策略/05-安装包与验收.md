同一份代码的完整链路已在本机全链路栈上验过（`00` 报告 §6.2：A→B→A 换账号、电脑数已满就地移除、当前电脑在云端已被移除时换账号）。

## 3. Windows EXE（未构建，需要你决定）

与第 52～67 批相同：Windows 运行时的原生包只锁在 Windows 构建机上，EXE 一律走桌面仓库 `xwangzy/kimi-work-legal-desktop`（公开仓库）的 windows-e2e（构建、安装、注册、登录、任务、预览、导出、断网、卸载）。需要：

- 把第 68 批推到桌面仓库分支、建预发布放 `release.json` 与 `kwl-signed-content.tar.gz`、发起 windows-e2e——推送属对外动作，等你同意；
- windows-e2e 连线上云端注册要手机号与短信验证码（线上要求手机号）。

## 4. 建议的安装包验收清单（你点过钥匙串“允许”后，或云端升级后）

1. 覆盖安装 0.8.0（保留 0.7.0 的数据）：原账号仍在、已登录或停在重新登录页；
2. 退出登录 → 用另一个账号（验证码或密码）登录：不再出现“这台电脑已登记为本所另一位成员”，进入那个账号自己的工作空间，看不到原账号的事项；
3. 再退出 → 用原账号登录：回到原工作空间，事项、成果都在；
4. 设置 → 套餐与用量：只显示本人用量；成果页预览：暖灰画布与白纸；下载的 Word / Excel 与以前一致。
