## 3. 法律质量与文档验收

沿用 v5 的 360 任务集结构作为满范围评测目标：合同 180（9 类 × 双立场 × 10）、案卷 60、研究 60、文书 30、顾问答复 30；首批 4 类合同先用 80 个合同任务；至少 20% 冻结保留集，由独立评审律师盲评；试点新增失败例另列，不删难例。

| 指标 | 初始发布门槛（建议） | 说明 |
|---|---|---|
| 严重法律风险漏检 | 关键必查点加权召回 ≥ 95%，逐类型与立场报告 | 律师定义严重度；公开置信区间与最差分组 |
| 引用真实性与定位 | 正式交付抽查 100% 可追到实际取得的确定版本 | 原文不可得标未核验 |
| 命题支持度 | 人工盲审 ≥ 95%；关键结论无已知不支持引用 | 法条真实 ≠ 支持命题 |
| 材料覆盖 | 应处理文件与页均有状态；无法解析显式 | 不静默遗漏 |
| 事实抽取 | 核心字段准确率 ≥ 95%；关键日期与金额出错必须触发复核 | 扫描件与原生分层报告 |
| 原生修订与保真 | ≥ 50 份复杂文档目标宿主往返，无原件覆盖与关键内容丢失 | 编号、表格、脚注、域、签章、外链逐项说明 |
| 计算 | ≥ 100 个边界案例与已批准公式一致 | 公式法律适用与数学计算分开验收 |
| 执行域数据任务 | 20 类典型任务结果与人工核对一致 | Agent 草稿须经确定性组件复算才进正式文书 |
| 总工时改善 | 试点同任务中位数节省 ≥ 30% | 计入复核、改错、排版 |

数值为建议目标，尚无实测成绩；正式发布附任务范围、分母、置信区间与已知局限。

## 4. 运营与商业上线门禁

| 门禁 | 目标与材料 | 失败处理 |
|---|---|---|
| 灾备 | 控制面与账单 RPO ≤ 15 分钟、RTO ≤ 4 小时，真实恢复演练 | 不承诺该 SLA，缩小试点 |
| 本地事项恢复 | 恢复码与律所恢复演练通过；每周增量导出默认开启 | 不售未验证的恢复能力 |

| 外部依赖 | 模型、检索、法源、云、IM 的条款与故障责任齐全 | 缺哪项停哪项，不用模拟数据冒充 |
| 费用 | 重度、无缓存、低价情景不失控；预占与对账完整 | 调整额度或售价 |
| 合规 | 登记与公示、标识、隐私、DPA 与次处理者清单完成 | 不公开销售 |
| 客户服务 | 负责人、响应时限、升级路径、状态页、培训与退出流程可执行 | 继续受控试点 |
| 销售口径 | 产品、技术、安全、法务、运营共同签字的能力清单与禁用词 | 不放行 |
