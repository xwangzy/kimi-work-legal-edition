## Page1 我们的建议：先冲量立位，再降本增利

**一、销售策略：短期以规模为先**
现阶段核心目标是做大 Kimi 消耗量，以实打实的销售规模向月之暗面证明我司的渠道与交付能力，为推动合资公司设立争取主动。

**二、报价体系：两类 Key 分档报价，随行就市**

| 产品 | 基础折扣 | 阶梯折扣（按客户月消耗） | 底价 |
|---|---|---|---|
| Kimi K3.1 官方 API Key | 9.4～9.5 折（≤150 万） | 9.3 折（>150 万） | 9.3 折 |
| Kimi K3.1 MaaS 平台原厂 Key | 8.8 折（≤50 万） | 8.7 折（>50 万）／8.6 折（>100 万）／8.5 折（>200 万） | 8.5 折 |

- 折扣已含公司分摊；10 月 25 日前已报价客户维持原折扣。
- 建立动态调价机制：按市场渠道价定期复盘，区间内销售自主报价，低于底价逐级审批。

**三、成本优化：引入 Coding Plan 资源池**
我司作为 Kimi“登月计划”合作伙伴已获授权。资源池已开发完成并通过初期测试，接入 Coding Plan 后即可在授权范围内承接部分调用，降低单位 token 成本，打开利润空间。

**四、销售激励：利润共享 + 消耗奖励 + 季度冲刺**
- 有利润部分：毛利按公司 6 : 销售 4 分配。
- 无利润部分：按客户实际消耗额设消耗激励奖（建议每百万元消耗奖励【X】元）。
- 设季度 token 冲刺目标，达成另行奖励。
- 激励以客户回款或预充值到账为计提依据。
