## 1. 第一性原理判断（每条工作线一句话）

- **A 论点确认**：律师在这一步只做三件事——“这条论点要不要”“依据靠不靠得住”“哪些事实我认”。卡片要先回答“要我定什么、为什么”，其余是证据，按需展开。
- **B 功能卡片**：律师点开一张卡时已经知道要做什么。面板只负责“给材料、定关键事项、开工”；交付件、用量、数据去向是**确认信息**而不是**输入**，不该占半屏。不同业务的输入重心不同（起草看请求与当事人、审查看那份合同与立场、比对看两稿的先后、研究看问题、整理看材料），卡片按形态排序和命名。
- **C 套餐与用量**：用户只想知道“我用了多少、还剩多少、什么时候重置、会不会被卡住”。一个主数字 + 一根条 + 一句状态，其余是明细。
- **D 成果**：律师在这里“找到 → 看一眼 → 决定下一步（复核 / 导出 / 改）”。文件是主角，任务与事项是归属信息。
- **E 预览**：预览要让律师相信“这就是那份文件”。米黄纸面把 Word 与 Excel 都弄成仿古信纸，Excel 还套了衬线大字号——表格本身被压坏。
- **F 登录注册**：两页是同一个“入口”，切换时不能跳。
- **G 上传菜单**：上传是首页最频繁的动作之一，菜单要一眼看清“传到哪里、传了什么、还能选什么”。

## 2. 统一设计规范（V41，本批全部页面遵守）

### 2.1 容器
- 一个视图里**最多一层带边框的容器**。容器内用间距与 1px 分隔线分组，不再套第二层边框卡片。
- 容器：白底（`--bg-surface`）、1px `--border-subtle`、圆角 14px（弹层 16px、按钮 / 输入框 10px、胶囊 999px）、阴影只用于浮层（`--shadow-md`），平铺内容不加阴影。
- 浮层（菜单、弹出说明）：圆角 14px、`--shadow-md`、内边距 6px、条目高 36px、条目圆角 8px、悬停 `--bg-hover`。

### 2.2 字号与字重（只用已有令牌）
- 页标题 20px / 600（`--fs-pagetitle`）；区块标题 15px / 600；正文 14px；说明 13px `--text-secondary`；元信息 12px。
- 数字一律 `font-variant-numeric: tabular-nums`；大数字（用量主数字）28px / 600。
- 一屏只有一个 600 以上的视觉焦点；标签、计数、说明不加粗。

### 2.3 颜色
- 中性灰阶为主；主按钮黑底白字（全视图唯一）；蓝色只用于链接与“已选中”；状态用**色点 + 文字**：草稿灰、待复核橙、已签发绿、退回 / 错误红。
- 浅橙底块只用于“需要你判断 / 需要你处理”，同一视图最多一处。
- 不新增色值，全部取 `packages/design-tokens/src/tokens.css` 的语义令牌；深色模式随令牌自动适配。

### 2.4 间距
- 4 / 8 / 12 / 16 / 24 / 32 / 48。区块之间 24～32，区块内条目 8～12，标题与内容 8～12。

### 2.5 信息分层（渐进披露）
1. 结论 / 要你定的事（默认可见）
2. 一行概况（默认可见、次要色）
3. 细节与依据（展开、悬停或弹出）

固定不变、与本次操作无关的说明不默认展示；**必要的隐私与授权告知**保留，但同一信息同一视图只出现一次，放在它起作用的节点（开工按钮旁、导出时、发送前）。

### 2.6 文案
- 律师视角、动词开头；不出现研发术语（令牌、内核、路由、token、上游、点数）。
- 状态如实：没取到就写没取到，不写“正常”。

### 2.7 动效
- 浮层出现 140ms ease-out（透明度 + 2px 位移），收起 100ms；尊重 `prefers-reduced-motion`（`styles-motion.css` 已有开关）。

### 2.8 文档预览（工作线 E 的规范，其他预览入口同样遵守）
- 画布：中性浅灰（亮色取 `--bg-muted`），纸面纯白、细描边 + 轻阴影；**取消米黄纸色**（`--p-paper`）。
- Word：A4 比例版心（宽 794px 内按可用宽度缩放），页边距约 72px；正文衬线（`--font-doc`），16px / 1.8；标题按原文层级；修订绿插红删，批注编号上标 + 文末列出。
- Excel：表格是表格——无衬线（等线 / 微软雅黑 / PingFang）13px、按原文列宽、行高、合并单元格、对齐、换行、加粗、底色、边框、数字格式；列号（A B C）与行号固定在边上；多个工作表用表签切换；可横向滚动，不压缩列宽。
- 预览框架永远是浅色纸面（打印件的样子），画布随主题。
