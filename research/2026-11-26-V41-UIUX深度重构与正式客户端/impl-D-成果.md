## 2. 设计判断

律师在这页做三件事：**找到 → 看一眼 → 决定下一步（提交复核 / 去签发 / 下载）**。文件是主角，事项、任务、版本是归属信息。照此：

1. **文档工作区，两栏各自滚动。** 页头（标题 + 一句话 + 搜索）横跨两栏；下面左栏列表、右栏预览，主区不再整页滚，两栏顶边、底边都对齐（D7）。宽度：列表 `clamp(340px, 36%, 440px)`，其余给预览——预览是读文书的地方，应该更宽。工作区左右内边距 32px（其他页 48px）：工作区页要把横向空间让给文书，1280 宽时预览仍有约 580px。
2. **一层容器。** 只有右侧预览是带边框的容器；列表不套卡片、行间不画分隔线，靠留白与悬停 / 选中的圆角色块分组（D4、D5 的错位问题因此不存在了）。
3. **复核流程收成一条安静的分段筛选**（与侧栏 Work / Chat 切换同一种样子）：`全部 11 | ● 草稿 11 › ● 待复核 0 › ● 已签发 0`，有退回时多一段。顺序与细箭头保留先后关系（上轮评审要求“恢复流程信息”），含义放悬停提示。高度从约 80px 降到 36px（D3）。
4. **名称去噪（D1、D2）。** 新增纯函数 `taskTitles`：把名称拆成“是什么文书”（标题）与“针对哪份文件”（对象）。同族文件取括号里的差异（“修订稿”“清洁稿”“修订稿·对外版”“修改对照表”），“文书-对象”取连接符前的文书名；与事项名重复的对象不写；一次任务里各份都针对同一份合同时，对象只在任务那一行说一次（“审合同 · 设备买卖合同（RC-XS-2025-118）· 59 分钟前”）；各不相同时留在各自那一行，开头和事项名重复的当事人简称去掉（“验收款违约金-截至2026-11-30”与“验收款-截至2026-11-30”一眼分得开）。合同号这类事项名里没有的编号不算重复，不丢。完整名称在悬停提示与预览头。
5. **两行文件行**：折角小纸片图形（W 蓝 / X 绿 / PDF 红 / 文 灰）+ 短名（14px）/ 对象 · 第 N 版 · 给谁 · 时间（12px 次要色）；状态是色点 + 文字靠右，只在“全部”里显示（按某一段筛选时都一样，省掉）。操作（提交复核、下载、更多）悬停或键盘聚焦时浮在行尾，盖住状态、左缘渐隐，不占常驻宽度，标题不会因悬停重新截断。
6. **预览头两行（D6）**：第一行“图形 + 完整名称 | 一个主操作 + 下载图标 + 更多”；主操作按状态只给一个（草稿“提交复核”、待复核 / 退回“去复核签发”、已签发“下载”；看旧版时给“回到第 N 版（最新）”而不给黑按钮；过程文件、重新运行前的文件、已被取代的版本不给，D11）。第二行“● 状态 · 第 N 版 ▾ · 给谁 · 时间 · N 处待填 · 事项 › 任务”：版本切换收成下拉，事项与任务是可点的面包屑；整句说明进状态的悬停提示。“打开复核页 / 查看签发记录”“看这次任务”“打开事项”进“更多”。
7. **“N 处待填”**：预览内容里还留着几处“【待填】”就在预览头写几处（橙色，签发前要补上）——上轮评审建议的“复核时最该先看的”；文中高亮属于预览内部（工作线 E），本线只计数。
8. **预览常驻**：去掉关闭按钮（D10）；没有选中时右栏说清为什么空（“没有匹配的文件可以预览”“这一类里没有文件”）；搜索、筛选后选中的不在列表里就自动换到第一份。
9. **键盘**：上下键在文件行之间移动（宽窗口同时换预览）；Enter / 空格打开；搜索框 Esc 清空；菜单上下键移动、Esc 关闭并回到触发按钮、点外面关闭。
10. **窄窗口（< 1100px）**不变：单栏，点一行直达复核页；旧版在列表里“第 N 版 ▾”展开。
