## 3. 新的问题清单

### P0

无。本轮未发现阻断交付的缺陷。

### P1

1. **65.0–92.8 中段仍约 28 秒、五句字幕。** 这是甲方“叙事停留在功能、内容细碎”的最后残留。改：删第 10a 站（68–71“你只说一句要做什么”，首页 59–65 已交代），或把 10e 并入 10d，压到约 22 秒；省下的时间给开场的大意象或晨光段。
2. **0–13 开场：4–7 秒字幕压在背景大字上；光波只照亮中部一片。** 改：第一句字幕移到背景大字之外的留白区（或背景大字在字幕出现前 1 拍虚化压暗到 30%）；光波扩散到全画幅，波前经过之处法条整体亮起再回落，形成一次“读完一切”的尺度瞬间。
3. **109.8–116.2 签发卡。** 卡片上沿裁断半行字（112.5、115.9）；签发人一行字高约 2%；“完成签发”只有按钮变灰。改：裁切线落在两行之间的空白处；签发人一行放大到 ≥ 3% 并单独停 1.5 秒；点击“确认签发”后给一拍落定（状态卡“已签发”点亮配一声收束音，或签发人一行逐字写出）。
4. **122.2–124.6 晨光段第一句字幕压在纸面正文上。** 改：此时纸页还在微距后拉中，字幕放到纸页外的桌面暗区，或等后拉完成（约 125 秒）再出字。
5. **61.1–63.5 方法库数字读不出。** 页签字高约 1.3%，窗口被下缘和右缘大幅裁切。改：要么在画面上叠一行排版字“53 个方法｜诉讼仲裁 22｜非诉 12｜企业法务 12｜通用 7”（字高 ≥ 3%，停 ≥ 2 秒），要么推近到页签行，让它占画宽 60% 以上。
6. **52.7–55.0 揭幕的静没对准蓝点。** 最静处（−61.6）在三问还在屏时，蓝点独处黑场的 54.4–55.0 音乐回到 −24～−27。改：把约 1 秒的静整体后移到 54.2–55.0，暖白光晕展开的同一帧落和弦。

### P2

1. 54.0 第三问“谁来负责？”先于前两问退场，读起来像把它删掉了；改为三问一起压暗、只留蓝点。
2. 87 秒底部进度线标签“确认 / 成果”与界面“重大”标签相撞；进度线在界面密集时降不透明度或上移。
3. 93.0、101.0、118.0 三次压黑可接受；若有余力，93.0 可做“Word 页面抬起、背景先暗”的材质过渡。
4. 英文副标 “Intelligence for the complexity. Time for judgment.” 中 “for the complexity” 不地道，建议 “Intelligence for complexity. Time for judgment.” 或删去。
5. 76.1–78.0 飞行中蓝点约 0.8% 画宽，在白底上偏小；可放大到 1.2% 并带一条淡尾迹。
6. 台灯亮约 2.1 秒，建议延到 2.5–3 秒，让观众认出“同一盏灯”。

## 4. 与前两轮及 V1～V4 的对比

- **叙事格局：** 三轮持续上升。R3 新增的“打开的钢笔→合帽的钢笔”和窗格晨光，让“把时间留给判断”有了可见的物证；相对 V1～V4 是本质提升。
- **视觉美学：** R3 清掉了灰色光晕、窗口硬边、溶解换物，整体不再有“故障感”的帧。上限仍受程序化 2.5D 质感限制。
- **节奏控制：** 收尾与晨光段的呼吸到位；开场与中段两处“长而平”的段落三轮未动。
- **品牌表达：** 主题句、落版、无声收尾都已成熟；英文副标还需一改。
- **商业价值：** 三答证据完整、律师主导讲透；规模证据与行动号召仍缺。
