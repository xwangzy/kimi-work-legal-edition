# 03 逐镜头评审与验收（V5）

> 评审方式：两组独立评审，各自只看渲染出的成片（960×540 预览 + 关键帧放大），逐帧抽样、联系表、切点 0.1～0.2 秒密集取样、EBU R128 响度，并对照 `01-产品事实核查.md` 逐句核对字幕。评审人不参与制作，每轮重新打分，原始报告在 `docs/review/`（R1、R2 各 5 轮）。
> - **R1 品牌创意总监 / 商业广告导演**（Apple、Anthropic、Linear 一档的标准）
> - **R2 执业律师 / 律所管理合伙人 / 普通观众**（三种身份分别打分后取综合）
> 5 分制；甲方标准为每个维度 ≥ 4.5。**下表如实记录，没有调整任何分数。**

## 一、结论（先说）

- **甲方“每个维度 ≥ 4.5”的标准，本版没有全部达到。** R1 终评 12 项中 1 项达标（交互真实性 4.5），综合约 4.0；R2 终评 12 项中 3 项达标（叙事格局、品牌美学、交互真实性 4.5），综合 4.39。两位评审都没有 P0、P1 遗留（行动号召待客户提供除外），字幕 28 句逐句对照事实核查全部准确。
- **两位评审对“为什么到不了”的判断一致**：差距不在哪一帧没修好，而在素材与材质——全片是真实产品界面 + 程序化 2.5D 的纸、桌、光与合成配乐，没有人、没有真实材质与光学景深、没有一个第一次见到的开场大意象。R1 估计程序化工艺的上限约 4.0～4.2，后几轮每轮只能 +0.05～0.1。
- **要让每项到 4.5，需要甲方决定投入（见第七节）**：实拍“手和物”（1 天棚拍或授权素材，6～10 个镜头，替换第二、六幕桌面）、第二与第六幕改真三维、开场换一个有纵深的大意象、请作曲重写配乐并人耳评审、提供行动号召文字。
- 相对 V1～V4：叙事格局、节奏、商业价值是**本质提升**；视觉美学**小幅提升**（光的叙事、字体与色彩系统、无故障帧），但质感与 V4 同档。V5 解决了甲方对 V4 五条不满中的四条（功能化叙事、节奏过快、内容细碎、没回答“为什么需要”），第五条“质感不整体”只解决一半。

## 四、全片综合评审

- **叙事**：V1～V4 是“纸 → 标识 → 十几张功能卡 → 主题句”；V5 是“时代 → 痛点 → 通用 AI 答不出的三个问题 → 产品从问号里登场 → 一件真实的工作 → 逐一作答 → 晨光里把时间留给判断”。功能只作为答案的证据出现（屏上产品能力约 10 项，V4 约 20 项）。
- **真实性**：全部产品画面是真实运行时 DOM 快照，审查意见、提问卡、修订稿由真实 Kimi 模型在真实任务中生成；律师的三个动作（选拟签、不采纳第 9.1 条、确认签发）都是本次真实任务的记录；28 句字幕逐句对照事实核查，片中没有“不能说”清单里的说法，没有任何效率数字；演示手机号、身份证号全片打码。
- **节奏**：五版统一口径实测——V5 接近静止的画面占 23%（V4 18%），平均镜头长度约 8.8 秒（算法口径），主句在屏约 3～5 秒（V4 正文约 2.8 秒）；有两处真正的静（揭幕前约 −60 dB、熄灯前），价值宣言、主题句、落版都有停留。
- **视觉**：一盏台灯、一扇窗、一颗蓝点构成光的叙事（夜 → 暖光摄影棚 → 夜 → 晨光 → 暖白）；宋体是“时代之声”、黑体是“产品之声”；无故障帧（单帧突变扫描只余熄灯、窗口同时熄灭两处有意的硬光变化）。上限在于程序化材质。
- **声音**：程序合成配乐按六幕情绪曲线与画面逐帧对齐（逐站加层、两处静、品牌动机、余音到无声），交付 −16 LUFS / ≤ −1.5 dBTP，另出 −23 LUFS 广播版音轨。未经人耳评审。

## 五、每轮改了什么

**p1 → p2（结构与事实）**：引用核验改为“核出处、核版本；撑不撑得住论点，由你判断”；签发改为“由负责的律师亲自完成”；“一次真实的运行”；手机号、身份证号打码；一镜到底改写为律师视角并加入真实的“不采纳”；清洁稿与 Word 第七条修订入画；问句处星海退暗留白；光波；虚焦匹配剪辑替代压黑；“？”的点在原位变蓝；第六幕晨光；主题句“把时间留给判断”；片尾静止、淡出、余音；全片字号放大；方法库与第五百八十五条引用卡；签发人与时间。
**p2 → p3（工艺与可读性）**：片尾衰减到无声；揭幕前屏息；签发段改为受光裁切卡；方法库横移不叠化；晨光段与第二幕开场同景别、窗格光斑、合帽的钢笔；第二幕桌上打开的钢笔与荧光笔；一镜到底三种不同过渡（横移跟拍 / 蓝点带路 / 后拉）；问答顺序统一；痛点改宋体。
**p3 → p4**：一镜到底压到 25 秒；AI 复核人入片（真实时间线原文）；方法库重构图；英文副标改为“Intelligence for complexity. Time for judgment.”；第二幕字幕避开纸面。
**p4 → p5**：价值宣言两句分别停约 3 秒、4 秒，第二句退场后才转白；签发三卡同位依次出现；开场标题期间窗口让位；落版静止约 5 秒；总长回到 150 秒。
**成片渲染时（p5 之后）**：第一幕景深改用 text-shadow 与“离焦文字行”软条实现（4K 下原实现单帧超过 60 秒、部分帧卡死），与 p5 预览逐帧对比观感一致（对比图 `out/t/blurBD.png`）；未请评审复看。
**p5 之后（成片前）**：两位评审的 P2——提问卡离场前字幕提前退场、复核卡在数据去向退场后才进、复核卡与签发卡衔接收紧、问句背后第 585 条再压暗、熄灯前垫约 −50 LUFS 房间底噪（避免平台把近乎数字静音听成掉音）。
