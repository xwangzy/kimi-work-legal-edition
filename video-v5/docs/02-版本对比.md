# V1～V5 横向对比

> 对比基于成片：V1 `video/archive/v1/kimi-work-legal-film.mp4`、V2 `video/archive/v2/kimi-work-legal-film-v2.mp4`、V3 `video/out/kimi-work-legal-film.mp4`、V4 `video-v4/out/final/KimiWorkLegal-V4-正片-4K60.mp4`、V5 `out/final/KimiWorkLegal-V5-正片-4K60.mp4`。
> V1～V4 的镜头数、字幕时长、功能数等人工口径数字取自独立复盘 `00a-历史版本复盘.md`；“接近静止 / 明暗 / 响度”五版统一用 `scripts/metrics.py` 与 ffmpeg ebur128 重新测量（同一口径）。

## 二、定性

| 维度 | V1～V4 的共同骨架 | V5 |
|---|---|---|
| 叙事格局 | 纸张序幕 → 标识 → 一个功能一张字幕卡 → 主题句 → 落版。讲“它能做什么” | 时代（法律是写下来的秩序，智能开始读懂文字）→ 痛点（深夜、碎片、只剩最疲惫的时间）→ 通用 AI 答不出的三个问题 → 产品从问号里登场 → 一件真实的工作 → 逐一回答三问 → 晨光里“把时间留给判断”。讲“律师的时间应该用在哪里” |
| 主线 | V4 有第 7.1 条贯穿，但在 74 秒断开 | 第 7.1 条“违约金”从第一幕的第五百八十五条（匹配剪辑）贯穿到第六幕晨光里的那一页修订，没有断开；“三个问题”是全片的叙事装置 |
| 形式与内容 | 每个功能一种转场 | 第二幕碎片化用多窗口跳动表现，第四幕完整工作流用一镜到底表现——形式本身就是论点 |
| 视觉 | 白底界面截屏为主 | 夜色法条星海（真实条文）、台灯与晨光的同一张桌子、暖光摄影棚里的真实界面、夜色里像被一束光照亮的证据卡 |
| 律师的位置 | 字幕说“由你决定”，画面是点一下“接受” | 画面里律师接受第 7.1 条、不采纳第 9.1 条（均为本次真实任务的记录）、亲自签发（签发人与时间特写） |
| 差异化 | 功能清单 | “通用 AI 会写，但法律工作还要回答：依据在哪里？谁来负责？案卷去了哪里？”——把差异讲成律所采购时真实的三个顾虑，并逐一用真实产品作答 |
| 落版 | 并排或模板化 | 主题句延续 → 蓝点落下成标识 → 中软国际（左）× Kimi（右）以“×”为中轴对称、落印 → 静止 → 淡出与余音 |

## 三、V5 保留了 V1、V4 的什么

- V1：夜色与实体纸张的触感、左侧大字（产品之声）、暖白摄影棚、克制的配色。
- V4：真实界面与真实模型输出、第 7.1 条这一条主线、蓝点母题、对称落版与落印、4K60 工艺。

## 四、V5 舍弃了什么

- “一个功能一张字幕卡”的结构；章节标签；功能清单式的副句。
- 硬边圆形遮罩、整屏虚化过桥、白↔黑开关式的明暗翻转。
- 没有依据的效率数字与“全部、自动、保证”一类说法（逐句对照 `01-产品事实核查.md`）。

## 五、独立评审的对比结论（终评，摘自 `docs/review/*-pass5.md`）

| 维度 | 结论 |
|---|---|
| 叙事格局 | **本质提升**：从功能串讲变为“问题—答案—把时间留给判断”的品牌叙事，正面回答“为什么需要” |
| 视觉美学 | **小幅提升**：光的叙事、字体与色彩系统、无故障帧；质感仍是程序化 2.5D，与 V4 同档 |
| 节奏控制 | **明确提升**：主句在屏 3～5 秒，两处真正的静，价值宣言、主题、落版都有停留；开场约 13 秒偏平 |
| 品牌表达 | **提升**：主题句与全片论点咬合；联合落版规范，收尾干净 |
| 商业价值 | **明确提升**：三问对应律所采购的三个真实顾虑，三答都有真实产品证据；仍缺行动号召 |

评审分数：R1 综合 V5 约 4.0、R2 综合 4.39（V4 自评 4.44～4.57 为 V4 制作方组织的评审，评审标准与人员不同，不宜直接比较；本轮两位评审都看过 V4 并判断 V5 在叙事、节奏、商业价值上实质更好，美学同档）。
