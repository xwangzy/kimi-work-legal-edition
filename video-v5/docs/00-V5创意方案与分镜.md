# Kimi Work 法律行业发行版 · 品牌广告片 V5 — 创意重构方案、文案与分镜

> 本文是 V5 的设计依据。历史版本的独立复盘见 `00a-历史版本复盘.md`；片中每句说法的产品出处见 `01-产品事实核查.md`；逐镜头评审与验收见 `03-逐镜头评审与验收.md`。
> 时间单位：秒（合成 60 fps）。音乐网格 72 BPM，1 拍 = 50 帧（0.833 秒），1 小节 = 200 帧（3.333 秒）；所有场景切点落在小节或半小节上，唯一出处是 `src/timeline.ts`。

## 一、为什么要推倒重来（结论先行）

V1～V4 是同一副骨架的四次迭代：**纸张序幕 → 标识 → 首页 → 一个功能一张字幕卡（十几张） → 主题句 → 落版**。V4 把每一张卡做得更精致（真实界面、真实模型、运镜、配乐），但骨架没变，所以用户指出的五个问题——叙事停留在功能、节奏快、内容碎、质感不整体、没回答“为什么需要”——都是骨架的问题，不是工艺的问题。在这副骨架上继续打磨，评分可以再涨，但上限就在“精致的功能介绍片”。

V5 换骨架：**不讲“它能做什么”，讲“法律工作的时间应该用在哪里”。** 功能只在回答这个问题时出现。

## 二、从第一性原理出发的七个回答

| 问题 | 我们的回答（也是片子的论点） |
|---|---|
| 1 AI 时代法律行业在变什么 | 阅读、检索、起草的成本正在快速下降；稀缺的不再是“处理信息”，而是**判断、负责与信任**。客户会要求更快、更透明的服务，常规工作的定价压力随之而来。 |
| 2 传统工作方式的根本瓶颈 | 律师最贵的时间被消耗在阅读、检索、核对、誊写上；工具碎片化，上下文在十几个窗口之间一次次断开；质量靠个人的勤勉兜底；真正需要判断的时刻，常常只剩最疲惫的时间。 |
| 3 通用大模型与通用 Agent 为什么不够 | 它们能写，但答不出法律工作必须回答的三个问题：**依据在哪里**（引用能不能对照原文与版本核验）、**谁来负责**（谁在关键处做决定、谁签发）、**案卷去了哪里**（当事人信息发给了谁、有没有记录）。 |
| 4 法律行业真正需要的 AI | 有专业方法（按业务线、按办案阶段）；按完整工作流执行，并在关键处停下来交给律师；成果可核验（引用对照原文、修订写进 Word）；数据去向可知、发出前先脱敏；**最后一步永远是律师签发**。 |
| 5 Kimi Work 法律行业发行版的差异化 | 不是一个更会写的聊天框，而是一套**律师主导的工作方式**：方法库（诉讼仲裁 / 非诉 / 企业法务）+ 执行完整事项的 AI + 律师确认点 + 可核验成果 + 本机优先的数据处理 + 律师签发。 |
| 6 为什么值得改变工作方式 | 因为改变的不是“写得更快”，而是**一件事从交代到成果在同一个地方连续完成，每一步可核、可控，律师始终说了算**。 |
| 7 释放而不是替代 | AI 承担阅读、检索、初稿与一致性检查；律师保留理解复杂、作出判断、守护信任；签发只由律师完成。 |

这七个回答压成全片的一条主线：

> **当智能可以读完一切，律师的时间，应该留给什么？——留给判断。**

## 三、三个创意方向与取舍

| 方向 | 构想 | 品牌价值 | 情绪 | 视觉 | 商业说服 | 结论 |
|---|---|---|---|---|---|---|
| A **判断的时间**（采用） | 法律是写下来的秩序 → 智能开始读懂文字 → 律师的时间被繁复吞没 → 通用 AI 答不出三个问题 → 产品登场 → 一件真实的事从交代到成果（一镜到底）→ 逐一回答三个问题 → 把时间还给判断 | 高：讲行业变革与律师价值，产品是答案 | 起承转合完整：思考 → 共鸣 → 期待 → 信任 → 回味 | 法条星海、深夜台灯、碎片窗口、一镜到底的工作空间、夜色问答、晨光 | 高：三个问题就是律所采购时真实的三个顾虑 | **采用** |
| B 一页纸的旅程 | 跟随一份合同从纸到界面再回到纸（V4 的延伸） | 中 | 中 | 已用过 | 中 | 舍弃：仍是功能串讲，V4 已做到头 |
| C 法律的千年文字 | 竹简—刻本—打字机—屏幕—AI 的历史蒙太奇 | 中 | 高 | 素材难以程序化做出质感，易流于俗套 | 低：与产品连接弱 | 舍弃：只取“文字”这一意象放进第一幕 |

## 四、V5 创意核心

**一句话概念：** 把律师的时间还给判断。

**叙事装置：三个问题。** 第二幕结尾，通用 AI 流畅地写出一段“根据相关法律规定……”的文字，然后画面停住，提出法律工作必须回答的三个问题——依据在哪里？案卷去了哪里？谁来负责？最后一个问号的那一点，变成 Kimi 的蓝点，产品由此登场。第四幕用一件真实的工作展示律师在每个关键处作决定；第五幕在夜色里按同样顺序逐一回答三个问题，以律师签发收束。功能不再是清单，而是答案。

**形式即内容：碎片 vs 连续。** 第二幕的“碎片化”用多窗口、跳切表现；第四幕的“完整工作流”用**一镜到底**表现——镜头在一个三维工作空间里连续穿行，从交代到成果不切一刀，底部一条细线上的蓝点随之前进。观众不用读字也能感到差别。

**唯一的母题：蓝点。** Kimi 标识右上角的蓝点 = 智能的注意力。它在法条星海里阅读、从问号里诞生、展开成产品、沿着工作流前进、落在风险条款上；最后回到标识里。全片只有这一个“特效”。

**时间。** 第二幕的台灯与小字时间戳（23:47 → 01:12 → 02:08）让观众感到“深夜”；第六幕同一张桌面，台灯熄灭，晨光照进来，桌上只剩一页清洁稿——不说“效率提升多少”，而是让观众看见时间回来了。

## 五、视觉系统

| 项 | 规范 |
|---|---|
| 画幅与规格 | 16:9；合成 1920×1080 @ 60 fps，渲染 `--scale=2` 输出 3840×2160（界面与文字按 2 倍像素真实栅格化） |
| 两种光 | **夜色**（近黑 #07080A + 一盏暖色台灯 / 顶光）用于时代、痛点、问答；**暖白摄影棚**（#F4F2EE，中心柔光）用于产品登场与一镜到底；第六幕从台灯过渡到晨光 |
| 强调色 | 只有 Kimi 蓝 #1783FF，用于蓝点、工作流细线与焦点描边；荧光笔黄只在痛点段作为道具出现；红删绿增只在修订稿里 |
| 两种声音（字体） | **时代之声**：思源宋体（Noto Serif SC）600，居中、慢显影、逐字晕开，用于宣言与问题；**产品之声**：思源黑体（Noto Sans SC）700 / 400，左对齐两行大字（继承 V1），自遮罩中升起，用于产品段；小标签与时间戳用 Inter |
| 字幕节奏 | 每张字幕最短在屏 3.5 秒（宣言类 ≥ 4.5 秒）；同屏只有一句主句；全片主句不超过 22 句 |
| 产品呈现 | 真实界面快照悬浮在摄影棚光里，带投影与一道玻璃高光；一镜到底段五个工作站排在同一个三维空间里，镜头连续穿行；特写用同一快照两层渲染做浅景深 |
| 运镜 | 每个镜头只有一个运动意图：推（Dolly In）、拉（Dolly Out）、横移跟随（Tracking）、焦点转移（Focus Pull）、微距（Macro）、分层视差（Parallax）；推拉在对数空间插值，速度连续，首尾缓入缓出 |
| 转场 | 只用有叙事理由的转场：微距→后拉（字到星海）、潜入一行字→桌面上的条款（匹配剪辑）、窗口熄灭（碎片→寂静）、问号的点→蓝点（共享元素）、蓝点→光（遮罩揭示）、字标→首页字标（匹配剪辑）、成果的纸→夜色（材质过渡）、台灯→晨光（光影过渡）、标识交接（落版） |
| 禁用 | 廉价科技蓝光效、粒子、线框地球、数字雨、快速闪切、模板化弹跳、滥用模糊 |
