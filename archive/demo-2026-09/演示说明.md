# Kimi Work 法律行业发行版 · V4 交互演示

更新日期：2026-09-22。

本版保留 Kimi Work 的项目、统一任务输入和成果工作区，围绕 36 个法律场景、45 个预置 Skills、109 份默认成果结构完善交互。首页突出任务输入；专业场景、继续工作与完整案例形成次级层次。场景按“事项—材料—指令—能力”四步展开，避免把所有配置同时堆在首页。

这些数字表示预置配置及工作结构，不表示真实模型分析或外部工具已经运行。

## 打开、打包与回退

- 直接展示：双击 `Kimi-Work-Legal-交互演示.html`，资源内嵌，无需安装前端依赖。
- 本地预览：运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 [本地演示](http://127.0.0.1:8765/)。
- 修改源码后运行 `python3 scripts/build_demo.py`，更新入口资源版本与独立 HTML。
- 本轮改动前备份：`backups/before-full-demo-20260921-231911/`，包含 34 个原始文件及 SHA256 清单。
- 检查备份：`python3 scripts/restore_before_full_demo.py`，默认仅核验，不改动文件。
- 回退：`python3 scripts/restore_before_full_demo.py --apply`。先将当前版本存成新的 ZIP，再按清单恢复原文件。

`restore_pre_upgrade.py` 和 `restore_baseline.py` 分别指向更早的升级前版本和最初基线。本轮回退应使用 `restore_before_full_demo.py`。新增模块可能保留在目录中，但恢复后的入口不会加载它们。

源码回退与浏览器数据重置相互独立。项目、配置、摘录、草稿和进度使用 localStorage；重置前可从工作空间设置导出快照，并单独导出需要保留的技能、连接及成果。工作空间 JSON 当前不支持一键整体恢复。

## 建议演示路线

1. 首页先描述任务，或按业务选择专业场景。完整场景库支持搜索、分类和收藏；首页只展示当前领域的四个场景。
2. 在“事项”中填写具体参数，可补充法域、委托立场、事实与核验时间、交付对象。演示示例明确标为虚构。
3. 进入“材料”，查看建议收集清单、下载收集单或添加项目材料。文本、图片可以本地预览；为材料标记我方／对方／参考，填写人工摘录和页码定位。
4. 在“指令”中核对自动生成的预设，可复制、下载或编辑全文。手改版不会被事项修改静默覆盖；“重新生成”显式同步最新事项信息。不同场景各自保存草稿。
5. 在“能力”中检查专业方法、输出、质量要求和工具依赖。可进入 MCP 配置，再返回原场景。
6. 带入工作台并开始，确认计划后建立可编辑成果。新任务保存当时的事项口径、材料摘录、Skill 和工具配置快照；之后改配置不重写历史成果。
7. Skills 页面可搜索、分批展开、编辑、复制成本所版本、创建、启停、恢复预置默认，支持 Markdown 和版本化 JSON 导出。JSON 导入先校验预览，再创建停用的独立副本；本所副本可以归档恢复。
8. MCP 页面配置名称、说明、传输、鉴权引用、资料范围、工具白名单和输入 Schema。新工具需要主动勾选，关键配置变更后重新进行本地检查；导入连接保持停用。
9. 从任务中心恢复成果，在项目交付中心查看、编辑、核对与下载。首页仍保留合同审查、批量尽调和诉讼文书的完整固定案例。

| 项目与任务 | 新建项目、材料归属、关联任务、独立成果、配置与材料快照、本地保存 | 后端队列、多人协作、机构权限和审计 |
| 原有专业工作流 | 合同、矩阵、证据、研究、起诉状及脱敏固定案例的交互、复核与下载 | 根据新输入重新生成固定案例分析、真实批量抽取和全文件脱敏 |

文本单文件上限 2 MB，最多预览前 128 KB / 80,000 字符；图片上限 12 MB；PDF/DOCX 仅记录文件信息，上限 50 MB；每项目最多 20 份。人工摘录上限 8,000 字符。原文与图片 URL 只在页面内存中保留，刷新后重新选择原文件恢复预览，文件元信息、用途和人工摘录仍保留。

MCP 检查只确认本地结构，不访问服务器、不执行命令、不读取环境变量。鉴权记录方案及环境变量名称，不收集真实 token、密码或密钥。没有真实工具发现的 Schema 为演示契约。导入拒绝凭据字段，未知工具不会自动加入白名单；缺失依赖在技能和任务中保留明确提示。

人工核对只记录用户动作，不代表系统核验了法律依据或案件结论。首次会见和证据质证支持可恢复的虚构演示底稿，其他场景提供原创可编辑结构；不能把这些结构当作已生成的专业分析。

## 调研与设计依据

本轮使用 Computer Use 登录后逐一打开 [智合 AI](https://www.zhiexa.com/agents/home) 的 36 个场景，核对可见预设、技能挂载方式、Skill 市场描述及 MCP 表单。受保护的 Skill 内部指令和参考文件未读取；本项目的步骤、质检、材料要求与成果规则为原创改写。逐项记录见 `research/2026-09-22-V4-研究与验收.md`。

独立子任务核实了 Kimi Work、Legora、Harvey、CoCounsel 及 MCP 官方资料，见 `research/2026-09-21-independent-product-research.md`。设计选择是让项目与任务保持连续，将专业方法和连接配置按需展开，使材料、方法和成果有可追溯关系。

本网页是法律行业发行版的交互演示，不代表 Kimi 原厂已上线本演示中的机构集成。
