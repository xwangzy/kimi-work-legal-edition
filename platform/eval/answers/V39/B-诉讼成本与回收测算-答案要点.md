# 答案要点 · V39 新卡“诉讼成本与回收测算”（B1 原告、B2 被告）

评分依据：《质量评估标准》+ 本文。本卡的特殊否决口径写在每卡末尾。**所有数字以本单任务里 `calc.litigation_budget` 的返回值为准**——评分人核对“文书里的数是否与本单测算表一致、测算表的参数是否与材料一致”，不要求与下面的参考数逐分相同（情景设计、担保费估算、是否计入违约金暂计额不同，结果会不同）。

## 通用要求（两张卡都适用）

1. **不给胜诉率、概率、期望值、加权平均**，不写“大概率”“胜算”。情景是“如果法院支持这些”的并列测算。出现概率或期望值 → 维度 1、4 记 0 分（工作准则第 7 条）。
2. **情景对应真实争点**：每个情景写明是哪个争点怎样认定时出现（如“违约金被调减”“3 号机减价成立”“外协加工损失因证据不足不被支持”），不是机械的“支持 60%”。两端（全部支持、全部驳回）都在。
3. **费用由工具算、依据写清**：受理费、保全费按《诉讼费用交纳办法》（第十三、十四条）；部分胜诉受理费按比例分担写明是测算口径、实际由法院决定（第二十九条第二款）；已立案的撤诉或调解受理费减半（第十五条）。
4. **律师费、担保费、回收比例写明来源**（委托合同、律师告知、估算），缺的列出。
5. **和不和解由客户决定**：写清“和解金额达到多少与哪个情景持平”“28 万（15 万）比各情景多得或少付多少”，可以写利弊，不写“建议接受 / 拒绝”。写了“建议接受和解”的扣维度 1 一分（替客户决定），不否决。
6. 交付：《诉讼成本与回收测算》.xlsx（工具生成，含情景测算、费用明细、和解持平点）+《测算说明》.docx（结论在前）。

## B1 原告（锐川诉禾丰，尚未起诉，分析时点 2026-11-09）

事实口径见 `eval/answers/V14/答案要点-诉讼与劳动.md` “L1 母案”。本卡要点：

- **请求金额**：货款（验收款余额）310,000（2025-12-03 到期）＋逾期付款违约金（日万分之五，至 2026-11-30 暂计 69,010.00；至 11-09 约 6.6 万左右，口径写清即可）＋律师费 30,000（合同 6.3 条约定违约方承担律师费、诉讼费、保全费、保全担保费、鉴定费）。
- **质保金 135,000 截至分析时点未到期**（任何口径都在 11-13 之后，按顺延约 12-14）：不得作为已到期请求计入“全部支持”情景而不提示；正确做法是不计入，或单列为“到期后增加请求”的情景并写明前提。把质保金当已到期计入且不提示 → V3/V8 否决（与 V14 m03/m06 同口径）。
- **28 万和解提议含质保金**：比较时要说明 28 万是“含尚未到期的 13.5 万质保金”的一揽子数——与只算已到期部分的诉讼情景比较时，这个口径差要写出来（这是本卡的关键分析点，漏写扣维度 4）。
- **保全**：禾丰拟 2027-01 搬厂（微信）→ 保全有必要；保全费按 409,010 约 2,565.05（第十四条），保全担保费为估算须写明；回收比例并列（全部 / 一半）。
- **参考数**（请求 409,010、受理费 7,435.15、保全费 2,565.05、担保费按千分之二估 818.02、一审律师费 30,000、保全费列入请求）：全部支持且全额收回，净回收约 37.8 万；违约金调减一半约 34.3 万；只支持货款约 27.7 万；全部驳回净支出约 4.1 万。28 万一揽子和解（未立案，和解只发生已付成本）约等于“只支持货款、全额收回”的情景，但 28 万里含了 13.5 万未到期质保金——这一点必须指出。
- **必须提示**：违约金调减风险（合同编通则解释第六十五条“超过损失百分之三十”的参照）；3 号机质量异议与维修拖延是对方抗辩点；对方先诉与搬厂风险（宜尽快在协议法院立案并保全）。
