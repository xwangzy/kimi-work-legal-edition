## 二、逐项应对结论与算式

基础数据（03表，2025-09～2026-08共12个月）：应发合计**170,735.65元**，其中加班费16,735.65元，剔除加班费后**154,000.00元**。

### 请求一：违法解除赔偿金（员工请求168,000元）

- 工作年限：2021-03-01至2026-09-15，共5年6个月又15日；第47条第1款“六个月以上不满一年的，按一年计算” → **N=6**。
- 月平均工资（含加班费、年终奖）：170,735.65÷12 = **14,227.97元**；2N = 14,227.97×6×2 = **170,735.65元**（按月平均取整计为170,735.64元）。
- 剔除加班费的口径：154,000.00÷12 = 12,833.33元；2N = **154,000.00元**（地方口径存在差异，作为单位的抗辩口径）。
- 月工资远低于“上年度职工月平均工资三倍”（材料中没有苏州的数据，需核实），不触发封顶。
- 结论：违法解除风险高（埋点2、3、4）。仲裁一般不超出请求金额裁决，**单位风险敞口以168,000元为上限**；答辩策略是：主张解除合法（旷工事实、员工签收手册）；退一步主张月平均工资应剔除加班费（154,000元）；同时补正工会程序。不得在答辩中主张“员工计算的月平均工资过高”——按法定口径员工的数字反而偏低。

### 请求二：未休年休假工资（员工请求25,747.13元）

- 应休天数：首次参加工作2012-07，累计工作满10年不满20年 → 每年10天（条例第3条，库内未收录）。
  - 2024年：10−5 = 5天；2025年：10−0 = 10天；
  - 2026年离职折算：(258÷365)×10 = 7.07 → 7天（不足1整天的部分不计），已休2天 → 5天；
  - 合计**20天**（员工的天数正确）。
- 日工资：剔除加班费后的月平均工资12,833.33÷21.75 = **590.04元**。
- 应付：590.04×20×200% = **23,601.53元**（以未取整的日工资计；以590.04元计为23,601.60元）。
- 员工以14,000元作基数（含加班费，且不是实际数）计算，偏高2,145.60元左右 → 答辩应主张按23,601.53元计算；“未休视为自动放弃”条款不能作为抗辩理由。

### 请求三：加班费差额（员工主张以全部月工资为基数，未写金额）

- 已付加班费：8,000÷21.75÷8 = 45.98元/小时 ×（1.5×136小时 + 2×80小时）= **16,735.65元**。
- 风险口径一（基数为基本工资加固定岗位津贴9,500元）：差额 = 1,500÷21.75÷8×（1.5×136 + 2×80）= 8.62×364 = **3,137.93元**。
- 员工口径（基数含岗位津贴和当月绩效）：差额 **7,172.41元**。
- 结论：主张合同第4.2款约定有效、已足额支付（差额为0）；风险值为3,137.93元～7,172.41元。须标注《劳动法》第44条和地方规定库内未收录。

### 请求四：2026年9月1日至15日工资（员工请求4,804.60元）

- 已付：(8,000+1,500)÷21.75×8 = **3,494.25元**（10-15发放）。
- 争议仅3日：9,500÷21.75×3 = **1,310.34元**。如认定为病假，应按当地病假工资标准支付（库内未收录，需核验），而不是全额。
- 结论：员工请求中已付的3,494.25元应予驳回，答辩要附上银行发放记录。

### 风险合计（供调解参考）

- 高风险口径：168,000 + 23,601.53 + 7,172.41 + 1,310.34 = **200,084.28元**
- 单位抗辩口径：154,000（如解除被认定违法）+ 23,601.53 + 0 + 1,310.34 = 178,911.87元。若解除被认定合法：23,601.53 + 0～1,310.34元。
