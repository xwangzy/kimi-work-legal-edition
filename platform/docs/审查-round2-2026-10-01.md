## 五、本轮审查发现并已修复

1. **修订手术嵌套 run 标签**（最初实现把替换内容插进未闭合的 `<w:t>` 内，产出非法 XML）→ 改为以 run 为最小切除单位，前后缀继承 rPr 重发。
2. **w:del 内判定错误**（正则把 del 之后的所有 run 误判为已删除）→ 改为比较最近开/闭标记位置。
3. **LCS 比对漏配 modified**（守卫条件在末行失效）→ 重写为相似度优先配对。
4. **事件 seq 冲突**（多成果同 seq 被唯一约束吞掉）→ 成果事件递序号。
5. **脱敏件未净化文档属性** → 补 scrubDocProps。
6. **清洁稿 manifest 措辞越界**（"同一批准内容派生"在批准流未接入前不成立）→ 改为如实标注"预览派生"。
7. **测试自身笔误**（括号错配被 Node 剥离器报为语法错误）→ 修复；两个文件的 url.pathname 空格编码问题（fileURLToPath）。
