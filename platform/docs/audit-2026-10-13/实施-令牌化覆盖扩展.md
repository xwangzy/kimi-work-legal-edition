## 2. 规则、正例与反例

### 2.1 案号 `case_no`（〔案号·……〕，**缺省关闭**）
- 开关：`new MatterTokenizer({ caseNumbers: true })`；`findIdentifiers(text, skip, { caseNumbers })`、`residualIdentifiers(text, { caseNumbers })`。
- 规则：年份括号（全角/半角/六角〔〕/方头【】/［］，括号内外可有空白）+ 中间段 + 可选“字第/第”+ 数字 +“号”+ 可选“之一”；中间段**必须含案件类型字**（民/刑/行/执/赔/破/知/商/海/仲/认/督/催/监/清/强/特/协/请/保/救/惩/移/调）。另认仲裁文号“京劳人仲字〔2023〕第123号”（“仲”前缀最多 6 字）。
- 正例：（2026）京0105民初1234号、(2025)最高法民终12号、（2024）沪74民初5号之一、〔2023〕粤03执456号、（2015）朝民初字第12345号、京劳人仲字〔2023〕第123号、［2022］浙0102刑初45号。
- 规范化：括号统一为半角 `()`、去空白 →（2026）/(2026)/〔2026〕/（ 2026 ）同一代号。
- 反例（开启时也不识别）：法释〔2020〕17号、国发〔2020〕5号、京政发〔2021〕12号、（2024）年度第3号公告、《民法典》第五百七十七条、合同编号HT-2024-000123、第（2）项。缺省（L2）时案号原样保留（原 `tokenizer.test.ts` “不误伤”用例不变）。

### 2.2 出生日期 `birth_date`（〔出生日期·……〕，默认开启）
- 规则 A（提示词在前）：出生日期 / 出生年月日 / 出生年月 / 出生时间 / 出生于 / 生于 / 生日： + 日期；“生于”前不得是“发/产/先/学/医/考/师/新/诞……”（排除“发生于”“王先生于”“学生于”）。
- 规则 B（判决书当事人段）：日期 +“出生”（排除出生率/出生人口/出生证明）或日期 +“生”后紧跟标点（“1990年12月生，汉族”；“生效”不算）。
- 日期写法：1985年3月2日、1985年3月、1985-03-02、1985.3.2、1985/3/2、1985.03（年月）；全角数字经折叠后同样识别。
- 规范化：YYYY-MM-DD（只有年月时 YYYY-MM）；多种写法同一代号。还原按事项内首次出现的写法（与其他类别一致）。
- 反例：双方于2026年3月2日签订、自2026年3月2日生效、事故发生于2026年3月2日、王先生于2020年3月2日签订合同、学生于2021年9月1日入学、截止日期：2026-03-02、2024年出生人口统计、金额 1,234,567.89 元。

### 2.4 自然人姓名补充（`names.ts`）
- **音译名**：分隔点 `· • ‧ ・ ･ ∙ ⋅ ⸱ ᛫ ·(U+0387)` 与全角句点；每段 1–8 字、2–4 段。锚定：①角色词之后（优先于普通姓名读取，否则“阿卜杜拉·买买提”会被截成“阿卜杜”）；②其后紧跟称谓或言语动词（第一段 ≤4 字，或取最后一个功能字之后；第一段内含角色词时从角色词后起算）。最后一段在言语动词、称谓、“出庭/作证”及“向/于/在/与/和/的/为/是……”处截断；含机构词或后接“（律师）事务所/有限/公司……”的不算；最后一段未被截断且后面仍连着汉字（被 8 字上限截断）的不算。分隔点写法不同得同一代号（`shapeFold` 去分隔符）；词典命中照常。
  - 正例：原告阿卜杜拉·买买提诉称、证人约翰·史密斯先生到庭、据约翰•史密斯回忆、词典“热依拉·吐尔逊”命中“热依拉・吐尔逊”。
  - 反例：第一章·总则、被告：阿里·巴巴有限公司、被告：约翰·史密斯贸易有限公司、中国·上海国际会展中心。
- **拉丁字母姓名**：只在角色词之后；2–4 个词，每词首字母大写（含连字符、O'Brien 形）或全大写、或单字母缩写加点；任何一词或紧随其后的词属于机构/通用词表（Inc/Ltd/LLC/Group/Bank/Law/Firm/Company/Trading/Party/Name……）即不算。词典传播按拉丁字母词边界（“Li Na”不命中“South Carolina”“LINAS”）。
  - 正例：原告：John Smith、委托代理人：Li Ming、被申请人 ZHANG SAN。
  - 反例：John Smith signed the contract（无角色词）、姓名 Full Name、被告 Apple Inc.、被告：Goldman Sachs Group、代理人 King Law Firm、原告 PRC、甲方 Party A。
- **昵称与职务称呼**（独立的值、独立的代号）：
  - 姓氏来源：当事人词典中的自然人全名、令牌表中的自然人全名、本段识别出的全名。昵称形态的值（“王总”）**不提供姓氏**，只允许这个写法本身再识别（避免一个“王总”带出“老王/王总经理”）。
  - “老/小 + 姓”：前为句首、标点、功能字或“联系/致电/拜访/通知/告诉……”的尾字；后为标点或动词、介词、助词首字（说称表在和与跟……确承拒负主参通核审查看……）；排除小区、小于、小时、小白、小米、小车、老师等。
  - “姓 + 称呼”：称呼表（最长匹配）副总经理、总经理、副董事长、董事长、副总裁、总裁、副总、经理、主任、局长、处长、科长、厂长、行长、院长、所长、部长、校长、书记、队长、主管、老师、师傅、总、董、工、律、姐、哥。单字称呼要求同上左边界（角色词之后、或该写法已识别过时可免）；排除法律、纪律、员工、施工、车工、古董、空姐、高工等。
  - **“王总经理”的规则（保守、一致）**：称呼取称呼表中的最长匹配，“王总经理”整体是一个值；“总监”不在称呼表中，且称呼后紧跟会改变词义的字（监、是、裁、程、师、部、结、额……不在允许表中）时**整段不识别**——所以“王总监”“王总是”“李工程师”“张律师”既不整体替换，也不会被截成“王总/李工/张律”。
  - 正例：原告：王明。王总表示同意，老王说没问题，小王也在场。王总经理签字确认（王明、王总、老王、小王、王总经理各有代号）；词典陈晓东 → “请陈经理”；词典张伟/刘洋/李强 → “联系张律，和刘董、李工确认”。
  - 反例：姓氏未知时“王总到场，老王没来，李工也到场了”不变；已知王/李/时/法姓时“王总监负责”“他王总是迟到”“李工程师出具”“老板说”“该小区5栋”“2小时后”“根据法律”“员工工资”“小李子”不变。
- 既有规则的行为说明（未改）：言语动词规则会把“王总监表示”的“王总监”当作 3 字姓名；称谓规则会把“史密斯律师事务所”的“史密斯”当作姓名（个人所以律师姓名命名，偏向召回）。

### 2.5 地址补充
- **村组（无门牌）**：起点在句首、标点或“住/住址/住所地/户籍地/位于/家住/系/在/于……”之后；[省][市][区/县/旗][镇/乡/街道/苏木] + 村名（≥2 字）+ 村/嘎查/屯 + 可选“三组/3社/2队”；须有区/县/旗或乡/镇级；起点被句首放宽后从最后一个强引导词（住、系、位于、户籍……）之后起算，不吞“被告系”“原告王某住”。排除村委会、村民、村庄、村里、城中村、各/该/本……村。
