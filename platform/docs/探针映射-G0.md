# 探针映射（G0 总验收自查）

依据：方案 v5.0 第 4 篇 §16.3 十四项探针（G0 退出条件）。本表把每项探针逐条映射到四类状态：

- **已自动化**：有测试/脚本锚点，CI 可复跑（锚点即证据）；
- **需 Windows**：依赖 Windows 安装形态/原生启动器/真机办公套件，本机 macOS 开发环境无法替代；
- **需真平台**：依赖真实 IM 平台/Office 宿主/真机卡片联调；
- **需真 MaaS**：依赖中软 MaaS 法律分组真实通道（含探针 10 前置确认）。

如实声明：标「已自动化」仅代表 v0 语义有自动化证据，**不等于该探针已验收**；G0 退出以探针全量实测为准。
