# 云端服务生产入口（第 13 批）

`scripts/cloud-serve.mjs` 是七个云端服务的生产启动方式（开发联调仍用 `scripts/dev-cloud-v0.mjs`）。每个服务一个进程、一个配置文件：

```bash
node scripts/cloud-serve.mjs --config /etc/kwl/control-plane.json
```

## 与开发脚本的区别

| 项 | 开发脚本 dev-cloud-v0 | 生产入口 cloud-serve |
|---|---|---|
| 传输 | http 回环 | 只接受 HTTPS（TLS ≥ 1.2）；`insecure_loopback_for_test` 只许 127.0.0.1 |
| 签名密钥 | 每次启动随机生成 | 从文件读（KMS / 密钥管理服务挂载为只读文件），不生成、不打印 |
| 吊销订阅 | 可选 | 网关、检索、分发、支持、通知、中继必须订阅；首次取到并核验签名后才对外服务 |
| 控制面状态 | 可不落盘 | 必须封装（state_key_file）、运营审计必须落盘 |
| 上游 | 缺省 mock | 网关、检索只接真实上游（api_key_file） |

## 配置样例

控制面：

```json
{
  "role": "control-plane",
  "listen": { "host": "0.0.0.0", "port": 8443 },
  "tls": { "cert_file": "/run/secrets/cp.crt", "key_file": "/run/secrets/cp.key" },
  "service_secret_file": "/run/secrets/service-secret",
  "data_dir": "/var/lib/kwl",
  "envelope_key": { "kid": "cp-prod-1", "private_key_file": "/run/secrets/cp-envelope.pem" },
  "seat_key": { "kid": "seat-prod-1", "private_key_file": "/run/secrets/seat.pem" },
  "state_key_file": "/run/secrets/cp-state.key",
  "code_pepper_file": "/run/secrets/cp-code-pepper.key"
}
```

网关（检索把 role 改为 search；分发 dist、通知 notify 不需要 upstream；支持 support 另需 ops_secret_file 与 meter_key_file；中继 relay 另需 ops_secret_file）：

```json
{
  "role": "gateway",
  "listen": { "host": "0.0.0.0", "port": 8443 },
  "tls": { "cert_file": "/run/secrets/gw.crt", "key_file": "/run/secrets/gw.key" },
  "service_secret_file": "/run/secrets/service-secret",
  "control_plane": { "url": "https://cp.internal:8443", "keys_file": "/etc/kwl/cp-public-keys.json" },
  "seat_keys_file": "/etc/kwl/seat-public-keys.json",
  "data_dir": "/var/lib/kwl",
  "upstream": { "base_url": "https://api.moonshot.cn/v1", "api_key_file": "/run/secrets/moonshot.key" },
  "content_safety_policy_file": "/etc/kwl/content-safety.json"
}
```

## 密钥文件格式与网络前置（复核 A-15）

- `state_key_file`、`code_pepper_file`（开通码 HMAC 的胡椒，控制面必填，与签名密钥分开）：32 字节十六进制；
- `service_secret_file`：至少 32 字节随机（64 位以上十六进制或 43 位以上 base64url），太弱即拒绝启动；
- 服务器级参数：请求头 20 秒、整请求 60 秒（中继、分发、支持 300 秒）、keep-alive 5 秒、并发连接缺省 10,000（`max_connections` 可调）；畸形请求回 400 并断开、不记内容；
- 网络前置：TLS 必须终止在本进程，前面只能是四层负载均衡，且**必须保留客户端源地址**（直通或 PROXY 协议）——控制面的兑换限速按来源地址计；
  放在七层代理或做源地址转换的负载均衡之后，每来源 10 次/分钟会变成全平台合计 10 次/分钟。

## 与客户端钉住的关系

客户端按 `release.json` 钉住各服务证书的 SPKI（至少两把：当前 + 备份）。证书续期须复用密钥对或预置备用钉住；服务前不得放解密型 WAF/CDN（调研 Y2 §2）。
