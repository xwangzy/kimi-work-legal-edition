# 按案件类型的建议材料收集清单

> 用法：选出与事项相符的类型（可多选），合并去重后对照 `materials.list` 标注状态。“我方 / 对方 / 参考”按我方立场填写；优先级：必需（缺失将影响起诉、应诉或结论）、重要、补充。
> 清单是建议，不是穷尽；律师可增删。

## 通用（所有争议类事项）
| 材料 | 用途 | 优先级 |
|---|---|---|
| 我方主体资格证明（营业执照或身份证明，代号原样） | 确认当事人适格 | 必需 |
| 对方主体信息（名称、住所、统一社会信用代码或身份信息） | 确定被告、管辖与送达 | 必需 |
| 授权委托与内部决策文件 | 确认委托权限 | 必需 |
| 全部合同、补充协议、附件 | 确定权利义务与争议解决条款 | 必需 |
| 往来函件、邮件、即时通讯记录（导出原始记录） | 证明履行、催告、对方表态 | 重要 |
| 已有的律师函、对方回复、诉讼或仲裁文书 | 了解程序进展与时效中断 | 重要 |
| 财产线索（对方银行账户、不动产、车辆、应收款等） | 评估保全与执行可能性 | 补充 |

## 买卖合同纠纷
| 材料 | 用途 | 优先级 |
|---|---|---|
| 订单、报价确认、框架协议 | 证明合同关系与价格 | 必需 |
| 送货单、签收单、物流记录、验收单 | 证明交付与验收 | 必需 |
| 发票开具与交接记录 | 证明价款与开票义务履行 | 重要 |
| 对账单、确认函 | 证明欠款金额、可能构成时效中断 | 必需 |
| 付款记录（银行流水） | 计算已付与未付金额 | 必需 |
| 质量异议记录、检测报告 | 应对或主张质量问题 | 重要 |

## 借款与担保纠纷
| 材料 | 用途 | 优先级 |
|---|---|---|
| 借款合同或借条 | 证明借贷合意与利息约定 | 必需 |
| 出借款项的转账凭证 | 证明款项实际交付 | 必需 |
| 还款记录 | 计算本息余额 | 必需 |
| 保证合同、担保函、抵押或质押合同及登记证明 | 主张担保责任 | 必需 |
| 公司担保的股东会或董事会决议 | 判断担保效力 | 重要 |
| 催收记录（向借款人、保证人） | 时效与保证期间 | 重要 |

## 股权转让纠纷
| 材料 | 用途 | 优先级 |
|---|---|---|
| 股权转让协议及补充协议 | 确定权利义务 | 必需 |
| 目标公司章程、股东名册、工商登记信息 | 核对股权状态与转让限制 | 必需 |
| 其他股东的通知与放弃优先购买权文件 | 判断转让程序 | 重要 |
| 价款支付凭证 | 证明付款情况 | 必需 |
| 交割文件（变更登记材料、移交清单） | 证明交割履行 | 重要 |
| 出资证明、验资或出资凭证 | 判断出资责任 | 重要 |

## 服务 / 技术服务合同纠纷
| 材料 | 用途 | 优先级 |
|---|---|---|
| 服务合同、工作说明书、变更记录 | 确定服务范围 | 必需 |
| 交付记录、验收文件、上线或使用记录 | 证明履行与验收 | 必需 |
| 服务水平考核记录、工单 | 应对或主张服务质量问题 | 重要 |
| 发票与付款记录 | 计算未付费用 | 必需 |

## 劳动争议（用人单位一方）
| 材料 | 用途 | 优先级 |
|---|---|---|
| 劳动合同、岗位说明、入职登记 | 确定劳动关系与约定 | 必需 |
| 规章制度及其民主程序、公示或告知记录 | 判断制度能否作为处理依据 | 必需 |
| 考勤、工资发放与社保缴纳记录 | 计算各项请求、应对加班费等主张 | 必需 |
| 违纪或绩效相关证据、处理通知与送达记录 | 判断解除合法性 | 必需 |
| 解除或终止通知、工会通知记录 | 判断解除程序 | 重要 |

## 劳动争议（劳动者一方）
| 材料 | 用途 | 优先级 |
|---|---|---|
| 劳动合同或能证明劳动关系的材料（工牌、工资流水、工作记录） | 证明劳动关系 | 必需 |
| 工资条、银行流水、社保记录 | 计算请求金额 | 必需 |
| 解除通知、聊天记录、录音（附文字稿） | 证明解除事实与理由 | 必需 |
| 加班记录、考勤截图 | 主张加班费 | 重要 |

## 非诉：合同审查准备
| 材料 | 用途 | 优先级 |
|---|---|---|
| 待审合同（可编辑的 DOCX）及全部附件 | 审查对象 | 必需 |
| 交易背景说明、商务条件摘要 | 判断商业条款是否符合交易安排 | 重要 |
| 客户的标准文本或内部审查标准 | 对照审查 | 补充 |
| 对方主体信息与资质 | 核对主体与履约能力 | 重要 |

## 企业法务：合规咨询准备
| 材料 | 用途 | 优先级 |
|---|---|---|
| 具体业务方案或问题描述 | 明确咨询问题 | 必需 |
| 相关内部制度与流程 | 判断现状差距 | 重要 |
| 监管机构的通知、问询或检查材料 | 确定答复要求与期限 | 重要 |
