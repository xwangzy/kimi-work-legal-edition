# 四类常见合同 × 双方立场 加查要点

> 先过 `rubric.md` 的通用必查点，再按本文件对应类型与立场加查。
> “检索线索”须经 `law.search` / `law.get_version` / `citations.verify` 核验后方可写入风险卡；核验不通过的写“依据待核实”。
> 合同类型不在本文件内的，只用通用必查点，并在意见书首页写明“本类型无加查要点”。

---

## 一、股权转让协议

### 共同必查
- **标的股权**：目标公司、转让比例、对应认缴出资额与实缴出资额；是否存在质押、冻结、代持；章程对转让有无限制。
- **出资责任**：转让未届出资期限的股权，受让人承担缴纳义务，受让人未按期足额缴纳的，转让人可能承担补充责任；转让存在出资瑕疵（未按章程规定的出资日期缴纳，或非货币出资的实际价额显著低于认缴出资额）的股权，转让人与受让人可能在出资不足范围内承担连带责任，受让人不知道且不应当知道的除外（检索线索：公司法（2023 年修订）关于股权转让后出资责任的条文）。
- **其他股东优先购买权**（有限责任公司对外转让）：书面通知其他股东转让的数量、价格、支付方式和期限；同等条件；章程另有规定的从其规定（检索线索：公司法（2023 年修订）有限责任公司股权转让条文）。审查协议是否约定通知义务由谁履行、放弃声明是否作为交割先决条件。
- **审批与登记**：国有产权、外商投资、上市公司、金融等特殊主体的审批或备案；变更登记的办理义务与期限。
- **先决条件与交割**：先决条件清单、满足方式与最晚期限；交割日定义；交割文件（股东名册、出资证明书、章程修正案、变更登记、印章证照、财务资料移交）。
- **过渡期**：签约至交割期间的经营限制、损益归属、重大事项通知。
- **价款**：定价依据、调整机制（净资产、营运资金调整）、分期节点与交割挂钩、共管账户、税费承担与代扣代缴义务。
- **估值调整与回购**（若有）：与目标公司约定的回购或补偿，履行受公司资本维持规则限制，提示效力与可履行性须另行研究（依据待核实）。
- **陈述与保证、披露函**：范围、时点（签约日 / 交割日）、知悉限定、存续期限、违反后果。
- **自然人出让方**：配偶对处分共同财产的同意（以代号出现的姓名原样使用）。

### 受让方立场（我方买股权）
1. 陈述与保证覆盖：出资真实到位、无未披露债务与担保、无重大诉讼与行政处罚、资产权属、劳动用工与社保、税务合规、关键资质有效。
2. 或有负债兜底：交割日前原因产生的债务、罚款、税款由出让方承担，并约定补偿方式与期限。
3. 价款分期且与交割、先决条件、登记完成挂钩；尾款作为陈述保证违约的保证金或可抵扣。
4. 出资瑕疵：要求出让方在交割前补足或在价款中扣减；约定受让后被追缴时的追偿。
5. 交割失败的解除权与已付款返还（含资金占用费），返还义务的担保。
6. 出让方及其关联方的竞业限制、关键人员留任、不招揽。

### 出让方立场（我方卖股权）
1. 价款支付保障：首付款比例、尾款期限、逾期违约金、未付清前的股权质押或所有权保留式安排、解除权。
2. 陈述与保证范围限定：知悉限定、重要性门槛、披露函豁免、索赔时限与金额上限、单项起赔额。
3. 交割后出资责任风险：转让未届期股权后，受让人不缴纳时出让方可能承担补充责任；要求受让方承诺按期缴纳并提供担保或反担保。
4. 交割后不再承担目标公司经营责任；过渡期限制不宜过宽。
5. 税费：个人所得税申报与代扣代缴的口径与承担方，避免价款被认定为含税。

## 二、买卖合同（含采购合同）

### 共同必查
- 标的规格、数量、质量标准（国家 / 行业标准、样品、技术协议附件）。
- 交付方式、地点、期限；运输与保险；分批交付。
- 风险转移时点（一般随交付转移；在途货物、买方迟延受领时的风险）、所有权转移与所有权保留。
- 检验期与质量异议：约定检验期的，买方应在期限内通知；未约定的，在合理期限内通知，并有最长期限限制（检索线索：民法典买卖合同检验期与异议期条文）。检验期过短（如“到货 3 日内”）对买方不利，需区分外观瑕疵与隐蔽瑕疵。
- 质保期、质量保证金比例与返还条件。
- 价款、发票、付款节点；逾期付款违约金或资金占用损失的计算基数与标准。
- 知识产权侵权担保（标的不侵犯第三方权利）。

### 买方立场（我方采购）
1. 检验期足够，隐蔽瑕疵的异议期单独约定；验收以书面验收单为准，排除“使用即视为验收”。
2. 质量不合格的救济：退货、换货、修理、减价、赔偿，以及因此产生的停工损失（可预见范围内）。
3. 迟延交付违约金、超过一定期限的解除权；替代采购差价由卖方承担。
4. 质保金不低于合理比例，质保期从最终验收起算。
5. 付款以验收合格和合规发票为前提；预付款的担保（银行保函等）。
6. 卖方责任上限不宜过低；排除间接损失的条款要保留“故意或重大过失除外”。

### 卖方立场（我方销售）
1. 付款保障：预付款、分期、所有权保留、担保；逾期付款违约金与解除权；货款未付清前停止供货的权利。
2. 检验期明确且较短，逾期未提异议视为合格；质量异议须书面并附检测报告。
3. 责任上限（如不超过合同总价）、排除间接损失与预期利益。
4. 买方迟延受领、迟延提货的风险转移与仓储费用承担。
5. “背靠背”付款条款若由买方提出：限制触发条件与最长等待期，到期后无论第三方是否付款均应付款。

## 三、服务合同 / 技术服务合同

### 共同必查
- 服务内容与范围（工作说明书 SOW）、交付物清单、服务期限。
- 服务水平（SLA）、考核、扣款或服务费抵扣机制。
- 验收标准与程序；里程碑付款与验收挂钩。
- 人员配置、关键人员替换、分包与转包限制。
- 知识产权：交付成果、背景技术、改进成果归属与许可；技术服务中产生的新成果归属（检索线索：民法典技术合同章关于技术服务、技术开发成果归属的条文）。
- 保密与数据：涉及个人信息的，是否构成委托处理并约定处理目的、方式、安全义务、事件通知、终止后返还或删除（检索线索：个人信息保护法委托处理条文）。
- 合同性质识别：以完成工作成果为目的可能属承揽，以处理事务为目的可能属委托——两者的任意解除权与赔偿规则不同，影响解除条款的审查。
- 用工风险：服务方人员长期在委托方场所接受管理，存在被认定为劳务派遣或劳动关系的风险。

### 委托方 / 客户立场（我方购买服务）
1. 交付物与验收标准可量化；未通过验收的整改次数与期限，多次不合格的解除与退款。
2. SLA 与扣款、迟延违约金；关键人员变更须经同意。
3. 知识产权：为我方定制开发的成果归我方，或至少取得永久、不可撤销、可转许可的使用权；提供源代码与文档。
4. 数据安全、保密、合规义务及违约责任不受责任上限限制。
5. 终止后的交接与过渡协助、数据返还删除并出具证明。

### 服务方立场（我方提供服务）
1. 范围外需求须书面变更并另行计费；客户配合义务（提供资料、环境、接口）及迟延的后果（工期顺延、费用补偿）。
2. 验收期限与默示验收；里程碑款不因后续阶段争议而扣留。
3. 背景知识产权保留在我方，客户只取得交付成果所需的许可。
4. 责任上限（如一定期间内已收服务费）、排除间接损失；对客户提供材料的侵权不负责。
5. 客户任意解除时的已完成工作结算、预期利益或固定解约费（效力与金额合理性依据待核实）。

## 四、借款合同与担保合同

### 共同必查
- **主体性质**：出借人是否为持牌金融机构。民间借贷与金融借款适用的利率规则不同；民间借贷利率的司法保护上限以合同成立时一年期贷款市场报价利率（LPR）的四倍为限（检索线索：最高人民法院关于审理民间借贷案件适用法律若干问题的规定中利率上限的条文），**该上限不适用于金融借款，也不得当作通用默认口径**。
- 借款金额与交付：以实际交付为准；预先在本金中扣除利息的，按实际出借金额认定本金（检索线索：民法典借款合同条文）。
- 利率、逾期利率、违约金、服务费 / 咨询费等其他费用：民间借贷中这些费用合并计算时可能受总额上限约束（依据待核实）。
- 期限、提前还款、分期还款与加速到期条件。
- 用途约定及违反用途的后果。
- 送达地址与诉讼文书送达约定；赋予强制执行效力的公证（如有）。
- 夫妻共同债务风险：自然人借款人配偶是否共同签字（代号原样使用）。

### 担保部分
- **保证**：保证方式（未约定或约定不明的推定为一般保证）、保证期间（未约定的为主债务履行期届满之日起六个月）、保证范围（本金、利息、违约金、损害赔偿、实现债权费用）、最高额保证的额度与期间（检索线索：民法典保证合同章）。未经保证人书面同意变更主合同、加重债务的，保证人对加重部分不承担责任；未经书面同意变更履行期限（展期）的，保证期间不受影响——增额、展期都应取得保证人书面同意。
- **公司提供担保**：须依公司章程由董事会或股东会决议；为股东或实际控制人提供担保须经股东会决议（检索线索：公司法（2023 年修订）公司对外担保条文；最高人民法院关于适用民法典有关担保制度的解释中越权担保的条文）。出借方应审查并留存决议。
- **抵押 / 质押**：抵押物或质物的权属、登记（不动产抵押自登记时设立）、流押流质条款（约定到期不还即归债权人所有的，只能依法就担保财产优先受偿，检索线索：民法典抵押、质押条文）。
- **债务加入与共同借款人**：区分保证与债务加入，避免名为担保实为债务加入（或反之）的约定不清。

### 出借方立场（我方出借）
1. 借款交付凭证（银行转账、收据）及借款人确认；避免现金交付。
2. 利率在法定上限以内，逾期利率与违约金、费用合计不超限，避免被调减。
3. 加速到期、交叉违约、财务恶化时的提前收回。
4. 连带责任保证、保证期间写足、保证范围含实现债权费用；公司担保有有效决议。
5. 抵押登记完成作为放款先决条件；送达地址条款覆盖诉讼阶段。

### 借款方立场（我方借款）
1. 利率与各项费用的合计是否超出法定上限，超出部分可主张不予支持（依据待核实）。
2. 提前还款权及是否收取违约金；分期还款的宽限期。
3. 加速到期触发条件具体、限缩，给予补救期。
4. 担保范围与担保物价值相称，避免超额担保；最高额担保的额度与期间。
5. 用途约定灵活，避免因用途变更即构成违约。

### 担保人立场（我方为保证人或抵押人）
1. 明确为一般保证或限定保证范围、金额与期间。
2. 明确主合同加重债务、展期须经我方书面同意；未经同意的，我方对加重部分不承担责任，保证期间仍按原履行期限计算。
3. 求偿权与反担保安排。
