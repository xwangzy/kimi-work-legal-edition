# 本所覆盖层样例（格式说明，不是规则）

> 这是**格式样例**：下面的规则编号与内容都是为说明格式而写的示例，不是任何律所或客户的真实标准，不得直接用于审查。
> 律所把自己的标准按本格式写成 `firm-overlay.md`，经合伙人审定、签名后随方法包分发到可信区；`contract-review` 发现可信区有 `firm-overlay.md` 时先读它、优先适用（方法第 2 节第 4 条）。签名分发的路径待定（V9.4 主文偏离登记 D-118）。

## 1. 四栏的含义与在风险卡上的写法

| 栏目 | 含义 | 谁能放宽 | 风险卡写法 |
|---|---|---|---|
| 法律强制 | 违反即无效、可撤销或违法的要求（写明法律依据的检索线索，条号以核验为准） | 不能放宽 | `kind: risk`（或 `missing`），`rule_source: law`，依据交 `citations.verify` 核验 |
| 本所红线 | 本所出具意见时一律坚持的立场 | 承办合伙人书面同意 | `kind: deviation`，`rule_source: firm_rule`，`rule_ref` 写“规则编号 + 一句要点 + 版本” |
| 客户底线 | 某个客户授权的谈判底线（按客户分开写，写明客户代号与授权日期） | 客户 | `kind: deviation`，`rule_source: firm_rule`；底线写进 `bottom_line`，标“待客户定” |
| 可批准例外 | 偏离规则但事先列明可以接受的情形 | 按例外写明的条件 | 符合例外的不出卡；不确定是否符合的出卡并在 `assumptions` 写明 |

覆盖层与法律强制规定冲突时，一律按法律处理，并在卡的 `assumptions` 写“本所规则与法定要求冲突，已按法定要求处理”。

## 2. 每条规则的格式

```
### R-<编号> <一句话标题>
- 栏目：法律强制 / 本所红线 / 客户底线（客户代号） / 可批准例外
- 适用：合同类型；我方立场；金额或期限门槛（没有写“全部”）
- 标准立场：……（首选写法，可直接作为 suggestion）
- 可退让：……（fallback；没有写“无”）
- 底线：……（bottom_line，只展示不写入修订稿；没有写“无”）
- 缺失时：是否出缺失卡；查哪些说法（searched_terms）
- 依据：法律依据的检索线索或“商业立场，无法律强制要求”
- 版本：v<n>（<审定日期>，<审定人>）
```

## 3. 示例（虚构，只说明格式）

### R-12 付款期限
- 栏目：本所红线
- 适用：买卖、服务合同；我方为买方；全部
- 标准立场：验收合格后三十日内付款
- 可退让：验收合格后六十日内付款
- 底线：六十日，逾期付款不计违约金（待客户定）
- 缺失时：出缺失卡；查“付款期限、支付期限、付款时间、结算周期”
- 依据：商业立场，无法律强制要求
- 版本：v3（示例日期，示例审定人）

### R-20 争议解决
- 栏目：客户底线（客户甲）
- 适用：全部合同类型；全部立场
- 标准立场：提交我方所在地有管辖权的人民法院
- 可退让：提交双方认可的仲裁委员会仲裁
- 底线：被告所在地人民法院
- 缺失时：出缺失卡；查“争议解决、管辖、仲裁、诉讼”
- 依据：协议管辖须与争议有实际联系（检索线索：民事诉讼法关于协议管辖的规定，条号以核验为准）
- 版本：v1（示例日期，客户授权书示例）

### R-31 违约金上限
- 栏目：法律强制
- 适用：全部合同类型；我方为违约可能性较大的一方
- 标准立场：违约金约定明确计算方法，并约定过高时可请求调整的口径
- 可退让：无
- 底线：无
- 缺失时：不出缺失卡
- 依据：民法典关于违约金调整的规定（检索线索：民法典合同编违约责任章，条号以核验为准）
- 版本：v2（示例日期，示例审定人）

### E-03 可批准例外：集团内关联交易
- 栏目：可批准例外
- 适用：对方为我方集团内公司时，R-12 付款期限可放宽至九十日
- 条件：合同首部或鉴于条款写明双方为同一集团成员；不确定时出卡并在 assumptions 写明
- 版本：v1（示例日期，示例审定人）
