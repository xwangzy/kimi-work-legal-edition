# 合同审查通用必查点（rubric）

> 用法：每份合同都要过一遍本表；按类型与立场的加查要点见 `contract-types.md`。
> 表中“检索线索”只是帮助你用 `law.search` / `citations.verify` 定位法源的起点，**条号必须经核验后才可写入风险卡 basis**；核验不通过或法规库未收录的，写“依据待核实”。
> 我方立场决定同一条款是“风险”还是“有利”：先想清楚该条款在哪种情形下被触发、谁受益，再出卡。

## 一、主体与签约
- 主体名称、统一社会信用代码（或代号）、住所在首部、正文、签署页是否一致；签约主体是否为实际履约方（关联公司代签、分支机构签约）。
- 签约权限：法定代表人 / 授权代表签字；授权委托书是否作为附件；需要内部决议的事项（公司对外担保、关联交易、重大资产处置）是否约定由对方提供决议文件。
- 资质许可：标的涉及特许经营、行政许可的，是否约定对方资质及失效后果。
- 自然人一方：婚姻状况与配偶同意（涉及共同财产处分或共同债务时），以代号出现的姓名原样使用。

## 二、标的、价款与支付
- 标的描述是否特定、可验收；数量、规格、质量标准是否引用可识别的标准或附件。
- 价款构成：含税或不含税、税率变化的承担、币种、是否包含运费 / 安装 / 培训等。
- 支付条件：节点是否与可证明的事实挂钩（验收合格、发票开具、对方收到某款项）；“背靠背”付款（以第三方付款为前提）对收款方风险大，审查其触发条件、最长期限与举证。
- 发票：开票时间、类型、未开票能否拒付（拒付抗辩须约定明确）。

## 三、履行、交付与验收
- 交付地点、方式、期限；迟延交付的宽限期与后果。
- 验收：标准、期限、程序、异议方式；“逾期未提出异议视为验收合格”的默示验收条款对买方 / 委托方不利，对卖方 / 服务方有利。
- 风险转移与所有权转移时点；所有权保留是否需要登记对抗第三人（检索线索：民法典所有权保留相关条文）。

## 四、违约责任与违约金（必查争点）
审查时逐项回答：
1. **形式**：固定金额、比例（基数是合同总价、未付款还是逾期部分）、按日计（日万分之几 / 千分之几）。按日计的，折算成年化比例，与可能的实际损失对照。
2. **是否双向**：只约定对方违约金、不约定我方的，对我方有利；反之要补齐或设上限。
3. **与其他救济的关系**：违约金与损失赔偿能否并用（是否约定“违约金不足以弥补损失的，另行赔偿”）；违约金与定金一般只能择一主张（检索线索：民法典违约金与定金并存的规定）；逾期付款同时约定利息和违约金的，可能被视为重复，提示择一或明确各自性质。
4. **实现债权费用**：律师费、诉讼费、保全费、保全担保费、公证鉴定费、差旅费等，只有合同明确约定由违约方承担时，主张才有较明确的依据；守约方立场要写全。
5. **调整风险**：约定违约金过分高于造成的损失的，违约方可以请求适当减少；低于损失的，守约方可以请求增加（检索线索：民法典违约金条款；最高人民法院关于适用民法典合同编通则若干问题的解释中关于违约金调整、“过分高于”认定标准与释明的条文）。审查要点：
   - 我方可能是守约方：违约金不宜明显脱离可预见损失；在合同中写明违约金计算依据与损失构成（预期利益、替代交易成本、融资成本），为将来抗辩调整留证据；
   - 我方可能是违约方：要求设总额上限（如合同总价的一定比例），排除间接损失与预期利益；
   - “双方放弃请求调整违约金的权利”之类约定，效力可能不被支持，不要把它当作可靠保护（依据待核实）。
6. **解除后的违约金**：合同因违约解除后，守约方仍可主张违约责任；结算和清理条款的效力不受解除影响（检索线索：民法典合同解除效力相关条文）。约定违约金时写明“合同解除不影响本条适用”。

## 五、责任限制与免责
- 责任上限的口径（单次 / 累计、是否含违约金）；是否排除间接损失、预期利益。
- 免责条款不能排除造成对方人身损害的责任，也不能排除因故意或者重大过失造成对方财产损失的责任（检索线索：民法典免责条款无效的规定）。
- 格式条款：一方提供的格式条款中免除或减轻己方责任、加重对方责任、限制对方主要权利的，须以合理方式提示说明，否则对方可主张不成为合同内容；不合理地排除对方主要权利的无效（检索线索：民法典格式条款相关条文）。我方提供格式文本时，提示律师保留提示说明的证据（加粗、单独确认）。

## 六、期限、变更与解除（必查争点）
1. **约定解除事由**：是否具体、可证明（“严重违约”“重大不利变化”须定义或列举）；以数量、天数表达的触发条件更可执行（“逾期付款超过 30 日”）。
2. **催告与补救期**：解除前是否须书面催告、给予补救期；守约方立场宜写“经催告后 X 日内仍未履行的，可解除”，与法定解除中“经催告后在合理期限内仍未履行”的路径相衔接（检索线索：民法典法定解除条文）。
3. **解除权行使期限**：约定期限；未约定的，法律对行使期限有规定（自知道或应当知道解除事由之日起一定期限内不行使或经催告后合理期限内不行使则消灭——检索线索：民法典解除权消灭的规定）。守约方立场提醒及时行使。
4. **解除方式与生效**：通知解除自通知到达对方时生效；通知载明宽限期的，期限届满时解除；对方有异议的处理路径（检索线索：民法典解除通知与异议的规定；合同编通则解释关于通知解除审查的条文）。审查送达条款能否支撑“到达”的证明。
5. **任意解除权**：服务类合同若被认定为委托合同，双方可能享有任意解除权（须赔偿损失）；承揽合同定作人也有任意解除权。需要排除或限制时，提示效力存在不确定性（依据待核实）。
6. **继续性合同**：不定期的持续履行合同，当事人可随时解除但应在合理期限之前通知（检索线索：民法典法定解除条文第二款）。
7. **解除后果**：返还、折价补偿、已履行部分结算、违约金与损失赔偿、存续条款（保密、知识产权、争议解决、结算清理）。
8. **情势变更与不可抗力**：不可抗力定义与通知、证明义务；情势变更下的再协商与变更解除（检索线索：民法典不可抗力、情势变更条文）；不要把正常商业风险写进不可抗力。

## 七、争议解决（必查争点）
1. **诉讼还是仲裁，只能选一**：同时约定“可以向仲裁委员会申请仲裁，也可以向人民法院起诉”的，仲裁约定可能无效（依据待核实，检索线索：仲裁法及其司法解释关于仲裁协议效力的规定）。
2. **仲裁条款**：仲裁机构名称准确、唯一（写全称）；约定两个以上机构的须能选定；仲裁规则、地点、语言（涉外）。
3. **协议管辖**：只能书面选择被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地等**与争议有实际联系**的地点的法院，且不得违反级别管辖和专属管辖（检索线索：民事诉讼法协议管辖条文；条号以核验结果为准）。
   - “甲方所在地法院”在住所变更后存在不确定性，建议写“合同签订时甲方住所地”或具体法院名称；
   - 约定“合同签订地”的，签订地须在合同中明确写出，电子签约时尤其要写明；
   - 专属管辖（不动产纠纷等）不能协议排除。
4. **未约定或约定无效时的法定管辖**：合同纠纷一般由被告住所地或合同履行地法院管辖；履行地未约定或约定不明时按争议标的认定（给付货币的，以接收货币一方所在地为履行地等，检索线索：民事诉讼法司法解释关于合同履行地的条文）。审查我方作为原告时将在哪里起诉、成本如何。
5. **格式条款中的管辖约定**：经营者以格式条款与消费者约定管辖，未以合理方式提请注意的，消费者可主张无效（依据待核实）。
6. **立场建议**：我方宜争取我方住所地法院；对方坚持对方所在地时，可考虑约定中立地仲裁；涉外合同的管辖、法律适用与执行问题提示律师另行研究（→ legal-research-memo）。

## 八、通知与送达
- 是否约定各方送达地址、电子邮箱及其变更通知义务；约定“上述地址同时适用于诉讼、仲裁阶段的司法文书送达”，可显著降低送达难度。
- 通知生效时点（交邮后第 X 日视为送达、邮件发出即送达）对守约方有利与否，视立场判断。

## 九、保密、知识产权与数据
- 保密范围、期限（合同终止后仍存续）、例外、违约责任。
- 工作成果、背景知识产权、改进成果的归属与许可范围；第三方侵权担保与赔偿。
- 涉及个人信息或重要数据的：处理目的、方式、范围、安全措施、委托处理约定、跨境提供、事件通知与终止后的返还删除（检索线索：个人信息保护法、数据安全法相关条文）。

## 十、担保与保证金
- 保证方式（一般 / 连带）是否明确；未约定或约定不明的推定为一般保证（检索线索：民法典保证方式条文）。保证期间、保证范围是否写明。
- 公司提供担保的，须审查决议文件；保证金的性质、退还条件与抵扣顺序。

## 十一、生效、附件与文本
- 生效条件（签字盖章、审批、先决条件）；“签字并盖章”与“签字或盖章”的差异。
- 附件与正文冲突时的优先顺序；补充协议与主合同的关系。
- 份数、语言版本冲突时以何为准。
- 空白处、手写改动、骑缝章（扫描件中能看到的）提示律师核对。
