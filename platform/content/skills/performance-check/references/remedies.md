# 合同履约体检 · 救济路径与期限对照

本表的条号于 2026-11-24 编写时逐条对照本机法规库原文核对：《中华人民共和国民法典》（2021-01-01 施行）；《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（下称“合同编通则解释”，2023-12-05 施行）；《最高人民法院关于审理买卖合同纠纷案件适用法律问题的解释》（下称“买卖合同解释”，2020 年修正，2021-01-01 施行）；《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（下称“建设工程解释（一）”，2021-01-01 施行）。它们只是检索线索：写进意见书前仍按工作准则第 2 条批量核验，判断是否支持论点时取原文对照。本表没有列的条文，查到并核过原文再写，查不到的不写条号。

## 一、期间与送达
| 事项 | 要点 | 依据 |
|---|---|---|
| 期间起算 | 按年、月、日计算的，开始的当日不计入，自下一日开始计算 | 民法典第二百零一条第一款 |
| 按月、年计算 | 到期月的对应日为最后一日；没有对应日的，月末日为最后一日 | 民法典第二百零二条 |
| 末日顺延与截止时间 | 最后一日是法定休假日的，以休假日结束的次日为最后一日；截止时间为二十四时，有业务时间的为停止业务活动的时间 | 民法典第二百零三条 |
| 约定优先 | 期间计算法律另有规定或当事人另有约定的除外 | 民法典第二百零四条 |
| “超过”“届满” | “以上、以下、以内、届满”包括本数；“不满、超过、以外”不包括本数 | 民法典第一千二百五十九条 |
| 电子邮件通知的到达 | 相对人指定特定系统接收数据电文的，进入该系统时生效；对生效时间另有约定的按约定 | 民法典第一百三十七条第二款 |
| 电子邮件是书面形式 | 能有形表现所载内容并可随时调取查用的数据电文视为书面形式 | 民法典第四百六十九条第三款 |
| 诉讼时效 | 三年，自知道或应当知道权利受到损害以及义务人之日起计算；自权利受到损害之日起超过二十年不予保护 | 民法典第一百八十八条 |
| 时效中断 | 权利人向义务人提出履行请求、义务人同意履行、提起诉讼或申请仲裁等，从中断时起重新计算 | 民法典第一百九十五条 |

## 二、救济路径条件对照
| 路径 | 条件 | 要不要先催告 | 期限与时点 | 依据 |
|---|---|---|---|---|
| 继续履行 | 对方不履行或履行不符合约定；非金钱债务有法律或事实上不能履行、不适于强制履行或费用过高、债权人在合理期限内未请求履行的除外 | 不需要（但请求本身就是催告与时效中断的证据） | 债权人在合理期限内未请求履行的，失去请求继续履行非金钱债务的权利 | 民法典第五百七十七条、第五百八十条 |
| 迟延违约金并继续履行 | 约定了迟延违约金 | 不需要 | 违约方支付迟延违约金后还应当履行债务 | 民法典第五百八十五条第三款 |
| 约定解除 | 合同约定的解除事由发生（逐字核对条款要件：逾期天数门槛、是否须先书面催告、催告后的纠正期、解除范围是整份合同还是相应订单） | 按约定 | 解除通知到达对方时解除；对方有异议的，任何一方可请求确认解除效力 | 民法典第五百六十二条第二款、第五百六十五条第一款 |
| 法定解除·预期违约 | 履行期限届满前，对方明确表示或以自己的行为表明不履行**主要债务** | 不需要 | 同上 | 民法典第五百六十三条第一款第（二）项、第五百七十八条 |
| 法定解除·迟延后催告 | 对方迟延履行主要债务，经催告后在合理期限内仍未履行 | **需要** | 合理期限届满仍未履行的，次日起可以通知解除 | 民法典第五百六十三条第一款第（三）项 |
| 法定解除·合同目的不能实现 | 迟延履行或其他违约行为致使不能实现合同目的（标的可替代采购、对方已承诺短期内交付的，通常难以成立） | 不需要，但前提争议大 | 同上 | 民法典第五百六十三条第一款第（四）项 |
| 买卖·质量不符的解除 | 标的物质量不符合要求致使不能实现合同目的的，买受人可以拒绝接受或解除，毁损、灭失风险由出卖人承担 | 不需要，但须证明合同目的不能实现 | 同上 | 民法典第六百一十条 |
| 买卖·部分解除 | 数物中一物不符合约定的，可就该物解除（分离使价值显受损害的可就数物解除）；分批交付的，可就该批解除，影响之后各批的可就该批及之后各批解除，相互依存的可就全部解除 | 视所依据的解除事由 | 同上 | 民法典第六百三十二条、第六百三十三条 |
| 解除权行使期限 | 法律规定或约定了期限的，届满不行使即消灭；都没有的，自知道或应当知道解除事由之日起一年内不行使，或经对方催告后在合理期限内不行使的，消灭 | — | 用期限工具按“知道解除事由之日 + 一年”算；对方催告的另写合理期限 | 民法典第五百六十四条 |
| 以对方未异议主张已解除 | 法院仍审查通知方是否享有解除权；不享有的，不发生解除效力 | — | 不能靠“对方没在异议期内异议”补足解除权 | 合同编通则解释第五十三条 |
| 解除后果 | 尚未履行的终止履行；已履行的可请求恢复原状、采取补救措施并赔偿损失；因违约解除的，解除权人可请求违约方承担违约责任（另有约定除外） | — | — | 民法典第五百六十六条第一款、第二款 |
| 解除后违约金 | 买卖合同因违约解除后，守约方可主张继续适用违约金条款；过分高于损失的可参照第五百八十五条第二款处理 | — | — | 买卖合同解释第二十条 |
| 中止履行（不安抗辩） | 我方是**先履行**一方，有确切证据证明对方经营状况严重恶化、转移财产或抽逃资金逃债、丧失商业信誉或有丧失履行能力的其他情形；没有确切证据中止的，我方担违约责任 | 须及时通知对方 | 对方提供适当担保的应恢复履行；合理期限内未恢复履行能力且未提供担保的，视为以行为表明不履行主要债务，可以解除并请求违约责任 | 民法典第五百二十七条、第五百二十八条 |
| 同时履行抗辩 | 互负债务、没有先后顺序；对方履行前或履行不符合约定时，可拒绝其（相应的）履行请求 | 不需要 | — | 民法典第五百二十五条 |
| 先履行抗辩 | 有先后顺序，先履行一方未履行或履行不符合约定的，后履行一方可拒绝其（相应的）履行请求 | 不需要 | 只能拒绝“相应的”请求，不能拒付已合格部分的价款 | 民法典第五百二十六条 |
| 抵销 | 互负债务、标的物种类品质相同、对方债务已到期；依性质、约定或法律不得抵销的除外 | 须通知，到达时生效；不得附条件或期限 | 数额有争议的抵销会引发对方“拒付”的抗辩，作为选项交律师 | 民法典第五百六十八条；顺序见合同编通则解释第五十六条 |

## 三、违约金与损失
| 事项 | 要点 | 依据 |
|---|---|---|
| 违约责任的一般规定 | 不履行或履行不符合约定的，承担继续履行、补救措施或赔偿损失等责任 | 民法典第五百七十七条 |
| 质量不符的补救 | 按约定承担；没有约定或约定不明的，受损害方可合理选择修理、重作、更换、退货、减少价款等 | 民法典第五百八十二条、第六百一十七条 |
| 补救后的其他损失 | 履行义务或采取补救措施后对方还有其他损失的，应当赔偿 | 民法典第五百八十三条 |
| 损失范围 | 相当于因违约所造成的损失，含合同履行后可以获得的利益；以违约方订约时预见到或应当预见到的为限 | 民法典第五百八十四条；可预见的认定、对第三人违约责任的额外费用、扣除扩大损失与获益见合同编通则解释第六十三条 |
| 替代交易差价 | 依法解除并实施替代交易的，可按替代交易价格与合同价格的差额确定可得利益；替代价格明显偏离当时当地市场价的，按市场价与合同价的差额；解除但未替代交易的，按违约行为发生后合理期间内履行地市场价与合同价的差额 | 合同编通则解释第六十条第二款、第三款 |
| 难以确定的可得利益 | 综合违约方因违约获得的利益、过错程度、其他违约情节，按公平、诚信原则确定 | 合同编通则解释第六十二条 |
| 违约金的增减 | 低于损失的可请求增加；过分高于损失的可请求适当减少 | 民法典第五百八十五条第二款 |
| 调整的程序与举证 | 可以反诉或抗辩方式请求调整；违约方主张过高的负举证责任，非违约方主张合理的也应举证；仅以“约定不得调整”为由主张不调整的不予支持 | 合同编通则解释第六十四条 |
| 过高的判断标准 | 以民法典第五百八十四条的**损失**为基础，兼顾合同主体、交易类型、履行情况、过错程度、履约背景；超过**造成损失**的 30% 一般可认定过分高于损失；恶意违约方请求减少的一般不予支持。**不是合同金额的 30%** | 合同编通则解释第六十五条 |
| 减损 | 一方违约后，对方应采取适当措施防止损失扩大，扩大部分不得请求赔偿；防止扩大的合理费用由违约方负担 | 民法典第五百九十一条 |
| 双方违约与过错相抵 | 双方都违约的各自担责；对损失发生有过错的可减少赔偿额 | 民法典第五百九十二条 |
| 损益相抵 | 买卖合同一方因对方违约而获有利益，违约方可主张从损失赔偿额中扣除 | 买卖合同解释第二十三条；可得利益的认定另见第二十二条 |
| 质量不符的减价 | 可按符合约定的标的物与实际交付的标的物在交付时的市场价值计算差价 | 买卖合同解释第十七条 |
| 自行修理的费用 | 买受人在检验期限、质保期、合理期限内提出质量异议，出卖人未按要求修理或情况紧急，买受人自行或通过第三人修理的合理费用由出卖人负担 | 买卖合同解释第十六条 |

## 四、对方常见抗辩：先核对什么、怎么应对
| 对方抗辩 | 先核对 | 应对思路 | 依据线索 |
|---|---|---|---|
| 检验或异议期已过 | 约定的检验期限与起算（到货日、签收日）；异议的发出与**到达**（约定邮箱看进入系统之日，快递看签收日）；签收单是否写明只清点件数 | 期内以约定方式到达即为及时；对方回复中承认收到的，作为到达的佐证；约定期限过短、难以全面检验的，该期限只视为外观瑕疵的异议期 | 民法典第六百二十条、第六百二十一条、第六百二十二条、第一百三十七条第二款；买卖合同解释第十二条、第十四条 |
| 我方签收即已验收 | 合同是否约定签收不视为质量验收；签收单的备注 | 约定了检验期限的，签收不影响期内异议；未约定检验期限的，签收载明数量型号规格的只推定已检验数量和外观瑕疵，且可以推翻 | 民法典第六百二十三条 |
| 我方付款、使用即放弃异议 | 异议是否在合理期限内提出 | 期内已提异议的，付款、确认欠款、使用标的物不当然视为放弃（另有约定除外） | 买卖合同解释第十三条 |
| 质量其实合格（对方自检结论不同、抽检程序有问题） | 约定的检验主体、方法、抽样标准与判定阈值；我方检验记录、样品与原始数据是否保存；是否有独立于抽检结论的不合格事实（如色差实测值超标） | 按约定的方法与阈值逐项对照；保全样品与原始记录；提议共同复检或第三方检测；质量结论有争议的，依赖它的解除列为备选 | 合同的检验条款；民法典第五百八十二条 |
| 我方的异议或退货超出约定范围 | 约定可以退货的对象（整批、该产品批次、该件）与我方通知的范围 | 承认超出部分、发更正通知把范围限定在约定之内；约定范围内的部分不受影响 | 合同的检验条款 |
| 先付款再履行（同时履行或先履行抗辩） | 付款条件与先后顺序（是否以验收合格、收到发票为前提）；对方是否先履行一方 | 付款条件未成就、对方是先履行一方的，对方没有拒绝履行的权利，反而我方可拒绝其相应的履行请求；对方把履行附上合同没有的条件，可评价为预期违约或拒绝履行 | 民法典第五百二十五条、第五百二十六条、第五百七十八条 |
| 轻微违约，不构成解除事由 | 解除依据是约定还是法定；约定解除的要件是否逐项满足；法定解除是否属于“主要债务” | 约定解除按约定要件判断，不以根本违约为必要；法定解除写清是哪一项、要件是否齐备，不齐备的先催告 | 民法典第五百六十二条第二款、第五百六十三条 |
| 我方先违约 | 我方的付款、协助、通知、检验、保管义务是否按期履行 | 台账里我方义务逐项核对；有瑕疵的写明影响范围与补救办法，不回避 | 民法典第五百九十二条 |
| 我方曾同意延期 | 有无协商一致的书面变更；我方的回复是“同意”还是“请告知交货日期”“保留追究责任的权利” | 合同变更须协商一致；询问交期、未表示同意的不构成变更；有保留权利表示的，更不构成放弃 | 民法典第五百四十三条 |
| 原材料涨价、产能紧张（情势变更） | 合同有无价格不调整的约定；涨价是否属商业风险；标的或原料是否属价格长期波动较大的大宗商品 | 正常的价格波动属商业风险；合同涉及市场属性活跃、长期以来价格波动较大的大宗商品的，不认定为重大变化；固定价格的约定照常适用 | 民法典第五百三十三条；合同编通则解释第三十二条 |
| 不可抗力 | 事件是否不能预见、不能避免、不能克服；是否及时通知、合理期限内提供证明；是否迟延之后才发生 | 原料到货延迟、涨价通常不是不可抗力；迟延履行后发生的不可抗力不免责 | 民法典第五百九十条 |
| 违约金过高 | 我方已发生、有证据的损失（替代采购差价、停工、对下游的违约责任） | 先算损失基数，违约金低于损失的不存在“过高”；对方主张过高须举证；恶意违约方请求减少一般不予支持 | 民法典第五百八十五条第二款；合同编通则解释第六十四条、第六十五条 |
| 替代交易不合理（时间太早、价格太高） | 替代交易发生时对方是否已明确拒绝或附条件；替代价格与同期市场价（报价单、其他供应商价格） | 对方在期满前明确拒绝或附条件的，属预期违约，及时替代是减损措施；收集同期市场价格证据；替代数量不超过对方未履行的数量 | 民法典第五百七十八条、第五百九十一条；合同编通则解释第六十条第二款 |
| 损失扩大、我方获益 | 我方有无拖延替代、有无因违约省下的费用 | 写明已采取的减损措施与时间；如有获益主动扣除 | 民法典第五百九十一条；买卖合同解释第二十三条；合同编通则解释第六十三条第三款 |

## 五、几类合同的常见期限与判定要点
- **买卖**：约定检验期限的，期内通知，怠于通知视为符合约定；没有约定的，在发现或应当发现后的合理期限内通知，最长自收到标的物之日起二年（有质保期的适用质保期），二年为不变期间；出卖人知道或应当知道不符合约定的，不受通知期限限制（民法典第六百二十一条；买卖合同解释第十二条）。付款按约定的时间与条件（民法典第六百二十六条、第六百二十八条）。风险：交付前由出卖人、交付后由买受人承担，另有约定的除外；买受人违约未收取的风险自违约时起转移；风险由买受人承担的，不影响其因出卖人违约请求违约责任（民法典第六百零四条、第六百零八条、第六百一十一条）。质量保证金：出卖人在质保期内未及时解决质量问题、影响价值或使用效果的，不得请求支付该部分价款（买卖合同解释第十五条）。
- **建设工程施工**：竣工日期有争议的，按竣工验收合格之日、承包人提交验收报告之日（发包人拖延验收的）、转移占有之日（未经验收擅自使用的）认定（建设工程解释（一）第九条）；工期顺延须经签证等方式确认，未取得确认但能证明在约定期限内申请过且事由符合约定的可以顺延，约定逾期未申请视为不顺延的按约定（第十条）；未经竣工验收擅自使用后又以使用部分质量不符合约定主张权利的不予支持，地基基础与主体结构除外（第十四条）；质量保证金返还的三种时点（第十七条）。发包人未按约定付款的，承包人可催告在合理期限内支付，逾期不付的可协议折价或申请拍卖并优先受偿（民法典第八百零七条）；发包人、承包人各自的法定解除情形（民法典第八百零六条）。
- **租赁**：承租人无正当理由未付或迟延支付租金的，出租人可以请求在合理期限内支付，逾期不付的可以解除（民法典第七百二十二条）——这是“先催告、后解除”；非因承租人原因租赁物无法使用、毁损灭失致使不能实现合同目的的，承租人可以解除（民法典第七百二十四条、第七百二十九条）。
- 其他类型（服务、技术、委托、借款等）：按合同约定抽期限，法定期限查到并核过原文再写。

## 六、合同效力有疑问时
本方法不下效力结论。材料显示合同或条款可能违反法律、行政法规的强制性规定的，只在意见书“需律师决定的事项”里提示，并写明分析框架：按合同编通则解释第十六条，从强制性规定的规范目的、由行为人承担行政或刑事责任能否实现立法目的、对方有无能力或义务审查、违法一方能否补正等因素判断；规制合同订立后履行行为的强制性规定，一般不导致合同无效。**不再以“管理性 / 效力性强制性规定”的二分作为结论理由。**需要深入研究的转“法律研究备忘录”。
