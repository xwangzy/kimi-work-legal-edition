# 管辖与时效核查规则详表

> 用法：procedure-check 第 3 节。条号是**检索线索**，写进核查表前须经 `law.search` / `law.get_version` / `citations.verify` 核验；标“待核”的条号拿不准，核验前写法规名称与要点即可。本机法规库可能未收录民事诉讼法、民诉法解释与仲裁法及其解释，查不到时条号标“【待律师核对】”。

## 一、仲裁条款检查

| 检查项 | 看什么 | 检索线索 |
|---|---|---|
| 有效性要件 | 有请求仲裁的意思表示；有仲裁事项；有选定的仲裁机构（或依法可确定） | 仲裁法（2025 修订，2026-03-01 施行）关于仲裁协议内容的条文（条号待核） |
| 或裁或审 | 约定“既可仲裁也可起诉”的，仲裁协议一般无效；但一方申请仲裁、另一方未在法定期间内提出异议的除外 | 最高人民法院关于适用仲裁法若干问题的解释（关于或裁或审的条文，待核；新法施行后是否调整待核） |
| 机构约定 | 名称不准确但能确定具体机构的视为已选定；约定两个以上机构的，当事人可协议选择其一，不能达成一致的无效；只约定仲裁地且该地只有一个机构的视为选定 | 同上解释（条号待核） |
| 不可仲裁事项 | 婚姻、收养、监护、扶养、继承纠纷；依法应当由行政机关处理的行政争议；劳动争议走劳动争议仲裁，不适用商事仲裁 | 仲裁法相关条文（条号待核） |
| 时间效力 | 仲裁协议签订、仲裁程序启动、撤销或执行申请分别发生在 2026-03-01 前后时，适用新法还是旧法 | 仲裁法（2025 修订）附则；写“待核” |
| 异议时点 | 仲裁协议有效而一方向法院起诉的，另一方须在首次开庭前提交仲裁协议，否则视为放弃仲裁 | 仲裁法相关条文（条号待核） |

## 二、协议管辖检查（诉讼）

| 检查项 | 看什么 | 检索线索 |
|---|---|---|
| 书面形式 | 合同中的管辖条款或诉前书面协议 | 民诉法解释关于“书面协议”的条文（待核） |
| 实际联系 | 被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地等与争议有实际联系的地点 | 民事诉讼法（2023 修正）协议管辖条文（条号待核） |
| 不违反级别与专属管辖 | 约定的法院级别与标的额、案件类型是否相符；是否落入专属管辖 | 同上 |
| 能否确定 | 起诉时能确定具体法院的从其约定；约定两个以上有实际联系地点的，原告可选其一；“守约方所在地”等表述能否在起诉时确定，各地处理不一，写“存疑” | 民诉法解释关于管辖协议确定性的条文（待核） |
| 格式条款 | 经营者用格式条款与消费者约定管辖、未以合理方式提请注意的，消费者可主张无效；非消费者合同中的格式条款，看提示说明义务 | 民诉法解释关于消费者管辖协议的条文（待核）；民法典第 496 条 |
| 主体变化 | 合同转让、债权转让后管辖协议对受让人是否有效（受让人不知道有管辖协议等情形另有规则） | 民诉法解释相关条文（待核） |

## 三、法定连接点

| 纠纷 | 连接点 | 检索线索 |
|---|---|---|
| 一般 | 被告住所地（法人以主要办事机构所在地为住所）；被告住所地与经常居住地不一致的，由经常居住地法院管辖 | 民事诉讼法地域管辖条文（条号待核） |
| 合同 | 被告住所地或合同履行地 | 同上 |
| 合同履行地的认定 | 约定履行地点的以约定为准；未约定或约定不明：争议标的为给付货币的，接收货币一方所在地；交付不动产的，不动产所在地；其他标的，履行义务一方所在地；即时结清的，交易行为地；合同没有实际履行、双方住所地都不在约定履行地的，由被告住所地法院管辖 | 民诉法解释关于合同履行地的条文（待核） |
| 侵权 | 侵权行为地（含实施地、结果发生地）或被告住所地 | 民事诉讼法、民诉法解释相关条文（待核） |
| 专属 | 不动产纠纷（不动产所在地）、港口作业纠纷（港口所在地）、继承遗产纠纷（被继承人死亡时住所地或主要遗产所在地） | 民事诉讼法专属管辖条文；民诉法解释关于不动产纠纷范围的条文（待核） |
| 其他特殊地域 | 保险、票据、公司诉讼、运输、海事等 | 按纠纷类型检索，条号待核 |

## 四、诉讼时效与期间

| 项目 | 规则 | 依据 |
|---|---|---|
| 一般时效 | 三年，自权利人知道或者应当知道权利受到损害以及义务人之日起计算 | 民法典第 188 条 |
| 最长期间 | 自权利受到损害之日起超过二十年的不予保护；有特殊情况的，法院可以根据权利人的申请决定延长 | 民法典第 188 条第 2 款 |
| 分期履行 | 自最后一期履行期限届满之日起计算 | 民法典第 189 条 |
| 未约定履行期限 | 能确定履行期限的，自履行期限届满之日起算；不能确定的，自债权人要求履行的宽限期届满之日起算，但债务人在债权人第一次主张权利时明确表示不履行的，自该表示之日起算 | 最高人民法院关于审理民事案件适用诉讼时效制度若干问题的规定（2020 修正）相关条文（条号待核） |
| 中止 | 时效期间最后六个月内，因不可抗力等障碍不能行使请求权的中止；自中止原因消除之日起满六个月，时效期间届满 | 民法典第 194 条 |
| 中断 | 权利人向义务人提出履行请求；义务人同意履行；权利人提起诉讼或申请仲裁；与提起诉讼或申请仲裁具有同等效力的其他情形。自中断、有关程序终结时起重新计算 | 民法典第 195 条；同等效力情形与催告送达的认定见上述诉讼时效规定（条号待核） |
| 届满后 | 义务人同意履行的，不得以时效届满为由抗辩；已自愿履行的，不得请求返还 | 民法典第 192 条 |
| 不主动适用 | 法院不得主动适用诉讼时效的规定 | 民法典第 193 条 |
| 一审提出 | 当事人在一审期间未提出时效抗辩、二审才提出的，一般不予支持（有新证据的除外） | 上述诉讼时效规定（条号待核） |
| 不适用时效 | 请求停止侵害、排除妨碍、消除危险；不动产物权和登记的动产物权的权利人请求返还财产；请求支付抚养费、赡养费或者扶养费等 | 民法典第 196 条 |
| 特别时效 | 国际货物买卖合同和技术进出口合同争议为四年；其他法律另有规定的（如海商、保险等）按特别法 | 民法典第 594 条；其他按纠纷类型检索 |
| 除斥期间 | 撤销权、解除权等存续期间不适用中止、中断和延长 | 民法典第 199 条（撤销权第 152 条、解除权第 564 条） |
| 保证期间 | 约定或法定的保证期间（未约定或约定不明为主债务履行期限届满之日起六个月）；保证期间不发生中止、中断和延长 | 民法典第 692 条 |
| 期间计算 | 按年、月、日计算的，开始的当日不计入；到期月的对应日为最后一日，没有对应日的为月末日；最后一日是法定休假日的，以休假日结束的次日为最后一日 | 民法典第 200—204 条（由 `calc.deadline` 执行，不自行加减） |

## 五、计算与分支的写法

- 每个届满日调用 `calc.deadline`：起算事实日（可只到月）+ 期间（例如 {unit: year, n: 3}）+ 规则 civil；把工具返回的逐步过程原样写进“计算过程”。
- 有多次中断的，以最后一次**有证据**的中断日重新起算；证据不足的中断，另列一条“若不计入该中断”的分支。
- 起算事实只到月、或工具返回区间的，届满日写区间并标“精度不足，待律师确认”；**不写单一具体日期**。
- 中止、延长、特别法期间等工具不处理的情形，届满日标“待律师计算”，写明所需事实。
