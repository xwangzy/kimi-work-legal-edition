# 民事起诉状：要素、来源与写法

> 起诉状应当记明的事项以民事诉讼法关于起诉状内容的规定为准（用 `law.search` 检索“民事诉讼法”并经 `citations.verify` 核验条号）；下表是按该规定与执业惯例整理的要素清单。

## 一、要素与来源
| 要素 | 内容 | 允许的来源 | 缺失时 |
|---|---|---|---|
| 原告（法人或其他组织） | 名称、住所、统一社会信用代码、法定代表人或主要负责人姓名与职务、联系方式 | 主体资格材料、律师确认的事实（代号原样） | 【待填】 |
| 原告（自然人） | 姓名、性别、出生日期、民族、住所、公民身份号码、联系方式 | 同上 | 【待填】 |
| 被告 | 名称或姓名、住所等能够特定被告的信息 | 同上 | 【待填】，并在核对清单中列为“影响立案” |
| 第三人（如有） | 同上 | 同上 | 【待填】 |
| 委托诉讼代理人 | 姓名、执业机构 | 律师在对话中给出 | 【待填】 |
| 诉讼请求 | 具体、明确、可执行的请求 | 律师确认的计算明细或已确认金额；律师选定的请求项目 | 【金额待测算确认】 |
| 事实与理由 | 按时间顺序的事实与请求依据 | 仅限律师确认的事实；已核验的条文 | 不写未确认事实 |
| 证据与证据来源 | 证据名称、来源、证明目的 | materials.list 与律师确认 | 列入核对清单 |
| 受诉法院 | 法院全称 | 律师确认 | 【待确认】 |
| 具状人与日期 | 签名或盖章、日期 | 由律师与当事人在提交前完成 | 留空 |

## 二、诉讼请求的写法
1. **一项一个请求**，按“给付本金 → 利息或违约金 → 实现债权费用 → 担保责任 → 诉讼费用”排列。
2. **金额**：写到元和角分，大写可省略；分段计息的不在请求中展开，写“以本金 X 元为基数，自某日起按……计算至实际清偿之日止（暂计至某日为 Y 元）”。
3. **互斥项**：同一期间的逾期利息与违约金、违约金与损失赔偿，按律师选定的口径只主张一项或写明择一关系，不重复计入。
4. **实现债权费用**：律师费、保全费、保全担保费、公证费等，只在合同明确约定由违约方承担时主张，并在事实与理由中引用该条款。
5. **担保责任**：写明“被告某对上述第 1–N 项债务承担连带清偿责任”或一般保证的表述，以保证合同约定和律师判断为准。
6. **诉讼费用**：写“本案诉讼费用由被告承担”。

## 三、事实与理由的写法
- 第一段：当事人之间的法律关系（合同名称、签订日期、主要约定），注明证据编号。
- 第二段：我方履行情况。
- 第三段：对方违约事实（时间、金额、经过）。
- 第四段：催告、对账、协商情况，以及与诉讼时效相关的中断事由。
- 第五段：请求的依据——合同条款与经核验的法律条文；未核验的只写“依照合同约定及法律规定”。
- 语言：陈述事实，不用“恶意”“欺诈”等定性词，除非律师确认并有证据支撑；不写对方未主张的抗辩，也不写我方的弱点分析。

## 四、证据目录的编排
- 按事实叙述的顺序编号，与事实与理由中的“（见证据 N）”一一对应。
- 同一组证据（如多张送货单）可合并为一项，备注写明张数与页码区间。
- 证明目的写“拟证明……”，一句话，不写证明力评价。
- 识别不全、复印件、外文材料在备注中提示（原件核对、翻译）。

## 五、提交前核对的要点提示
- 管辖：合同有仲裁条款的，法院可能不予受理——先核对有无有效仲裁约定；协议管辖是否有效；级别管辖按诉讼标的额与受诉地标准确定（具体标准由律师查当地规定）。
- 时效：核对最后一次催告、对方承认或部分履行的时间与证据。
- 一致性：诉讼请求、事实与理由、证据目录、计算明细中的金额与日期逐项一致。
- 份数：起诉状副本按被告人数提交；证据份数按法院要求。
- 保全：如需财产保全，另行准备申请书与担保材料（本方法不起草）。
