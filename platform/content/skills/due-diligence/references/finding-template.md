# 尽调发现的写法与内部报告结构

> 用法：due-diligence 阶段二。报告的价值在回答三个问题：这事有多严重、能不能解决、解决不了怎么办。只列问题不给方案，等于把活推回给客户。
> 方法骨架改写自 legal-agent-skills（MIT，Copyright (c) 2026 John He (Decikingship)，commit 83df6b13）`nonlit-dd-opinion`、`expert-dd-transaction`；改为内部工作稿，不出可签发的法律意见书。许可见 `content/skills/THIRD_PARTY_LICENSES/legal-agent-skills-LICENSE`。

## 一、每个发现的四要素

| 要素 | 写什么 | 不合格的写法 |
|---|---|---|
| 事实 | 查到了什么 + 材料定位（文件 · 页 · 条）+ 来源类型（文件显示 / 目标公司陈述 / 访谈陈述 / 律师导入的外部查询结果 / 推论） | “存在代持”（无出处、无来源类型） |
| 法律后果 | 可能承担的责任或面临的风险 + 经核验的依据；未核验的写“依据待核实” | “可能存在法律风险”（空泛） |
| 对交易的影响 | 金额敞口（公式、基数来源、期间、口径，标“草稿 · 待复核”）、时间表影响、对交易目的的影响；缺数据写“待取得数据：……” | “敞口约 800 万”（无公式与来源） |
| 处理方案 | 落到交易文件的条款类型，或交割前整改；解决不了的明确写出 | “建议关注”“建议完善” |

## 二、分级与处理方案的对应

| 等级 | 含义 | 常见处理方案（按我方立场调整方向） |
|---|---|---|
| 交易障碍 | 不解决则交易目的无法实现或存在根本性风险 | 交割先决条件（代持还原、担保解除、资质续期、必要的审批与同意）；无法解决的写“需客户重新评估” |
| 重大问题 | 影响估值、需要特别安排 | 价款调整、分期支付或共管、特别赔偿、披露函、交割前整改 |
| 一般问题 | 需要关注但不影响交易 | 陈述与保证覆盖、交割后整改承诺 |

- 分级理由写清楚，不为报告好看降级；等级是供律师讨论的初步判断。
- 出让方或目标公司立场时，方向相反：重点是披露函的范围、赔偿上限与免赔额、索赔期限、特别赔偿的触发条件——提示风险，不替客户定数额。
- 与目标公司约定的回购、业绩补偿：提示其履行受资本维持规则限制、效力与可履行性须另行研究；**条款有效不等于能拿到钱**，回购或补偿义务人的履行能力应在尽调中一并核查。

## 三、《尽调报告（内部稿）》结构

1. **首页说明**：交易类型与我方立场、核查基准日、资料范围（数据室索引截至日、访谈对象与日期、律师导入的外部查询渠道与查询日）、“内部工作稿 · 草稿 · 待律师复核 · 通用辅助 · 未经本所质量验收”、“本稿不构成法律意见书，不对标的商业价值或是否交易作判断”。
2. **核查受限事项**（放在前面）：未提供、无法核实、仅有复印件、识别不全、期间不完整、外部查询未做的事项，逐项写原因与可能的风险。
3. **发现汇总**：编号 / 发现 / 等级 / 对交易的影响 / 建议处理方案（一页内）。
4. **逐项分析**：按模块，每个发现写四要素与分级理由。
5. **交易文件条款建议**：条款类型 / 建议要点 / 对应发现 / 立场说明（完整条款起草转 `contract-draft`）。
6. **需客户决定的事项**：每项写选项与各自后果，不替客户选择。
7. **依据与核验状态**：法名 / 条号 / 核验状态 / 用于哪个发现。

## 四、措辞

- 用“在已提供资料范围内未发现……”，不用“经核查，目标公司不存在……”。
- 陈述类事实用“目标公司称……”“据访谈（对象·日期）……”，不写成“经核实”。
- 量化结果写“草稿测算”，附公式；不写“预计损失”“最终赔偿”。
