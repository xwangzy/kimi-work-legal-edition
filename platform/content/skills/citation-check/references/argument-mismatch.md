# 七类论证失配：识别与处置

> 用法：citation-check 第 3 节第 5 步逐句使用。“结论句”指承载法律判断的句子（效力、责任、权利义务、程序后果、金额口径）；纯事实陈述、过渡句不必要求引注，**避免过度标记**——假阳性太多，律师会放弃这张表。

## 一、两组：能按字面识别的 / 必须对照原文的

| # | 类型 | 表现 | 识别方式 | 需要条文原文 |
|---|---|---|---|---|
| 1 | 裸断言 | 结论后面没有任何依据（法条、合同条款、证据） | 字面 | 否 |
| 2 | 空泛援引 | “根据相关法律法规”“依法”“按照有关规定”——无依据伪装成有依据 | 字面 | 否 |
| 3 | 射程不足 | 条文支持 A，结论说的是更强或更宽的 B（扩张解释、以“可以”推“应当”） | 语义比对 | **是** |
| 4 | 条件遗漏 | 条文有前提或例外，结论直接适用，没有交代前提已满足 | 语义比对 | **是** |
| 5 | 方向相反 | 所引依据其实不利于该结论，或支持的是对方主张 | 语义比对 | **是** |
| 6 | 以偏概全 | 个别案例或个别地区做法 → “各地普遍认为”“司法实践一致认为” | 字面 + 样本 | 否 |
| 7 | 绝对化 | “必然”“一定支持”“绝对不可能”“毫无疑问”“显然” | 字面 | 否 |

第 3、4、5 类没有原文一律写“支持待判”，不得归类。

## 二、语义比对的五个问题（第 3—5 类）

把 `law.get_article` 取回的条文原文与结论句并列，逐项回答：
1. 这条依据**直接**支持这个结论，还是只支持一个相近但更弱的命题？（“可以请求减少”≠“必然减少”；“可以解除”≠“已经解除”）
2. 条文有没有**前提条件、但书或例外**？结论所依赖的事实是否满足了这些条件，文稿有没有交代？
3. **主体、对象、行为**是否对得上？（条文规定的是有限责任公司，结论用于股份有限公司；条文是“用人单位”的义务，结论用于劳务派遣用工单位）
4. **时间**对不对？事件时点适用的版本与所引版本是否一致？
5. **方向**对不对？依据是否其实指向相反结论，或只对对方有利？

## 三、每处失配的写法（三段式）

| 栏 | 写什么 | 示例（虚构） |
|---|---|---|
| 依据支持到哪一步 | 引用条文原文的关键词，说明它规定了什么 | 条文规定：约定的违约金过分高于造成的损失的，当事人**可以请求**法院或仲裁机构**适当减少** |
| 结论走到哪一步 | 逐字引结论句的关键部分 | 文稿称：“本案违约金**必然会被调减至**实际损失的 130%” |
| 缺什么 | 中间缺的环节 | 条文赋予的是请求权，是否调减、调减多少由裁判机构裁量；“过分高于”的判断标准另见司法解释（检索线索：合同编通则解释关于违约金调整的条文，以核验为准），也不是“调减目标”；另有绝对化表述 |
| 修改建议 | 把结论收回到依据能撑住的范围 | “违约方可以依据……请求适当减少违约金；是否调整及幅度由裁判机构结合实际损失等因素裁量（依据待核：司法解释相关条文）。” |

## 四、处置口径

| 类型 | 建议方向（均标“待律师确认”） |
|---|---|
| 裸断言 | 三选一：补具体依据 / 改为附条件表述（“若……则……”）/ 建议删除。不能放着不管 |
| 空泛援引 | 落实到具体法名与条号；找不到具体出处的，写“未检出具体依据，建议改为附条件表述或删除” |
| 射程不足 | 换一条射程够的依据，或把结论收回到条文规定的范围 |
| 条件遗漏 | 补写前提条件已满足的事实与证据；事实不具备的，改为附条件表述 |
| 方向相反 | 明确指出依据实际支持什么；**不替律师把结论改成相反立场**，改不改、怎么调整主张由律师决定 |
| 以偏概全 | 写明样本边界（“在本次检索范围内检出的 X 份……”）；本机无案例源时，建议删去“普遍”“一致”等概括 |
| 绝对化 | 改为附条件或依据性表述（“依据……可以主张……”），**不改成“较大可能”“大概率”等概率或胜诉判断**（工作准则第 7 条） |

## 五、不标记的情形（防误报）

- 事实陈述（“2024 年 3 月 1 日双方签订合同”）——事实的出处由证据目录负责，不在本表。
- 程序性过渡句（“下面分三点论述”）。
- 引用合同条款支持合同解释类结论的，依据是合同条款本身，不要求法条。
- 律师在文稿中已明确标注“初步意见”“待核”的推论，可记为“已自标待核”，不计入失配。
