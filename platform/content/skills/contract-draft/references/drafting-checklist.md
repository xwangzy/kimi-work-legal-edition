# 起草清单：通用结构、交易文件要点与法律红线

> 用法：contract-draft 第 3 节。类型与立场的具体要点用 `skills/contract-review/references/contract-types.md`（与审查同一套口径）；违约金、管辖、解除的审查要点见 `skills/contract-review/references/rubric.md`。依据是**检索线索**，写进起草说明前须核验。
> 交易文件部分的方法骨架改写自 legal-agent-skills（MIT，Copyright (c) 2026 John He (Decikingship)，commit 83df6b13）`nonlit-transaction-documents`。许可见 `content/skills/THIRD_PARTY_LICENSES/legal-agent-skills-LICENSE`。

## 一、通用结构与必备条款

| 条款 | 要写清什么 | 常见缺陷 | 检索线索 |
|---|---|---|---|
| 首部与鉴于 | 各方名称、统一社会信用代码或身份信息、住所、联系人；交易背景 | 签约主体与履约主体不一致未说明 | 民法典第 470 条 |
| 定义与解释 | 关键术语一次定义、全文一致；附件与正文的效力顺序 | 先用后定义；同一事物多种叫法 | — |
| 标的 | 范围、规格、数量、质量标准（引用的标准写全称与版本） | “按行业标准”“双方认可的样品”无封样 | 民法典第 510、511 条（约定不明的补充规则） |
| 价款与支付 | 金额（大小写一致）、币种、含税与否及税率、支付节点与条件、发票、收款账户变更规则 | 支付条件依赖不可验证的事实 | — |
| 交付与验收 | 地点、方式、期限、风险转移、验收标准、异议期与视为验收 | 无异议期或异议期过短未提示 | 民法典买卖合同检验期间条文（待核） |
| 期限 | 起止、续期、提前终止；“工作日 / 自然日”统一 | 起算点不明 | — |
| 违约责任 | 违约情形、违约金或损失计算方法、逾期付款利息、继续履行与解除的关系 | 违约金与定金并用；违约金只对一方 | 民法典第 577、584、585、588 条 |
| 解除 | 约定解除事由、催告与宽限、解除通知方式、解除后果（返还、结算、违约责任存续） | 只写“严重违约可解除”无判断标准 | 民法典第 562、563、565、566 条 |
| 保密、知识产权 | 范围、期限、例外；成果归属与许可（视类型） | 保密期限与合同期限混同 | — |
| 不可抗力 | 定义、通知与证明、后果 | 把商业风险写成不可抗力 | 民法典第 590 条 |
| 通知与送达 | 各方送达地址、电子方式、地址变更通知、视为送达规则（可同时用于争议程序的送达约定） | 无地址变更条款 | — |
| 争议解决 | 诉讼（与争议有实际联系的地点的法院）**或**仲裁（写全称的仲裁机构），二者选一 | 或裁或审；机构名称不准确；约定不能确定的“守约方所在地” | 民事诉讼法协议管辖条文（条号待核）；仲裁法（2025 修订，2026-03-01 施行）仲裁协议条文（条号待核） |
| 生效与其他 | 生效条件（签署、审批、先决条件）、份数、附件清单、完整协议 | 需审批合同未写报批义务 | 民法典第 502 条 |
| 签署页 | 各方名称与签署栏，与首部一致；日期留空 | 签署页主体与首部不一致 | — |

## 二、交易文件（股权转让、增资）五组核心条款

| 组 | 起草要点 | 立场提示 | 风险提示 |
|---|---|---|---|
| 估值调整与回购 | 义务人（创始股东 / 目标公司）、触发条件客观可验证、补偿方式与计算、回购价格、期限、义务人履行能力的保障（担保、股权质押） | 投资方要可执行；创始人要门槛高、责任有限、可抗辩事由 | 与目标公司约定的回购须履行减资程序、金钱补偿受资本维持规则限制——提示效力与可履行性须另行研究（检索线索：全国法院民商事审判工作会议纪要关于对赌协议的部分，非司法解释）；条款有效不等于能拿到钱 |
| 优先权利 | 优先认购、优先购买、共同出售、领售（拖售）、优先清算 | 创始人一方争取领售的触发门槛、最低价格保护与优先购买机会 | 与章程、既有投资人协议的叠加与冲突逐项核对 |
| 反稀释 | 加权平均或完全棘轮；例外情形（员工激励、并购发行、战略投资） | 创始人一方一般争取加权平均与充分例外 | 调整方式须与公司法关于增资与股权的规则相容，待核 |
| 陈述保证与赔偿 | 范围、时点（签约 / 交割）、知悉限定、披露函、赔偿上限与免赔额、索赔期限、特别赔偿（对应具体尽调发现） | 投资方 / 收购方要宽；出让方要窄并靠披露函防守 | 尽调发现不要含糊带过，用披露函加特别赔偿处理 |
| 交割先决条件 | 条件清单、责任方、满足的证明、最晚日期、未满足时延期 / 终止 / 豁免 | 条件尽量由对方可控且可验证 | 交易障碍类尽调发现转为先决条件 |

另核：公司法（2023 修订，2024-07-01 施行）下的出资期限与受让未届期出资股权的责任承接（第 47、88 条）；有限公司对外转让的优先购买权（第 84 条）；需要的股东会决议与表决比例；国资、外资、上市公司等审批或备案（须另行确认）。

## 二之一、股权转让（老股转让）必备要素（第 35 批）

| 要素 | 起草要点 | 受让方立场提示 |
|---|---|---|
| 标的与价款按转让方拆分 | 逐一列表：转让方、转让的出资额与比例、认缴 / 实缴、价款、收款账户；合计与总价一致；诚意金、定金只在实际收款的那一方的价款里抵扣 | 付款与违约都能对应到人 |
| 转让方之间的责任形态 | 陈述保证、交割义务、税费、违约与赔偿是连带还是按份（法律或约定没有规定连带的不当然连带，检索线索：民法典关于连带债务的条文） | 受让方写连带；持股平台由创始人控制的尤其要连带 |
| 价款支付与交割挂钩 | 分期节点与先决条件、变更登记、交割文件交付挂钩；尾款与陈述保证、特别赔偿索赔的暂扣与抵扣 | 尾款留足索赔期 |
| 税费 | 价款是否含税；自然人转让方的个人所得税由受让方代扣代缴（扣缴义务的规定以税务主管部门文件为准，条号待核）或约定转让方自行申报并交付完税凭证 | 写明代扣后视为已付 |
| 其他股东的权利 | 有限公司对外转让：其他股东的优先购买权（公司法第八十四条）书面放弃；既有投资协议、股东协议里的随售权（共同出售权）、优先购买权、领售权等逐项取得书面放弃或同意；同意转让的股东会决议 | 列为交割先决条件，口头表态不算 |
| 权属与负担 | 质押解除与出质注销、冻结解除；核心资产（知识产权、证照）权属转到目标公司 | 列为先决条件并设特别赔偿 |
| 交割 | 交割日定义（变更登记完成日或付款日，写清一个）；交割文件清单（股东名册、出资证明书、章程修正案、变更登记、印章证照与财务资料移交）；最晚交割日与未满足时的延期、豁免、解除及已付款返还计息 | 最晚日期后受让方有单方解除权 |
| 过渡期 | 经营限制清单、重大事项事先同意、损益归属与亏损补足 | 收益归交割后股东、亏损由转让方补足 |
| 控制权交易的交割后治理 | 受让控股权的：董事会（执行董事）与监事的委派、法定代表人与财务负责人的更换、章程修订、印章证照与账户控制的交接 | 与交割文件一并约定 |
| 未届期出资 | 受让未届期出资股权的缴纳义务承接与转让人的补充责任（公司法第八十八条，检索线索） | 已实缴的写明实缴并作陈述保证 |
| 配偶与内部授权 | 自然人转让方配偶同意函；合伙企业转让方的合伙人同意或内部决议 | 列为先决条件 |
| 先决条件能否实现 | 列为先决条件、却要转让方先付钱才能完成的事项（解除股权质押要先清偿所担保的借款、解除对外担保、补缴社保），写明资金来源：第一期价款按约定定向清偿至质权人或债权人、或进入共管账户后放款，配套解押材料的交付顺序 | 先决条件不能写成转让方做不到、交易自锁 |
| 个人所得税扣缴 | 自然人转让股权，受让方是扣缴义务人：写“受让方应当依法代扣代缴”（不是“有权”），写明扣缴时点（每期付款时按比例扣缴，或约定转让方交割前完税并交付完税凭证）与转让方提供计税资料的义务（检索线索：股权转让所得个人所得税管理办法，条号待核） | 代扣后视为已付；未扣缴的责任写清 |
| 连带责任的范围 | 转让方之间对哪些义务连带（陈述保证、交割义务、特别赔偿）照客户指示写；业绩补偿、违约金等由谁承担、是否连带单独写明，客户没要求的不扩张；目标公司交割后由受让方控股，一般不列为赔偿义务人（赔偿等于自己赔自己） | 连带范围与第几条义务一一对应 |
| 业绩补偿（如有） | 承诺期与指标口径（审计、扣非、合并口径）、逐年还是累计计算、补偿公式（净利润为负的年度怎么算写明）、补偿上限（通常以转让价款为限）、与一般赔偿的关系；**补偿计算期晚于尾款支付的要有保障**：尾款延至最后一期审计报告出具后支付、或股权质押、保证，暂扣范围写明包括业绩补偿；客户给的公式可能使补偿超过价款或计算期重叠的，在起草说明中提示 | 受让方可争取不受一般赔偿上限限制，但上限与公式要写清 |

## 二之二、增资（投资协议）必备要素（V10 第 36 批）

| 要素 | 起草要点 | 投资方立场提示 |
|---|---|---|
| 分期付款的后续各期条件 | 后续每一期除里程碑外，还要**重述条件**：陈述保证在付款日仍真实、无未补救的违约、无重大不利变化、此前到期的承诺已履行；里程碑写成可核验的标准（谁出具什么文件、以什么为准，如“竣工环境保护验收意见”“连续 30 日达产记录”） | 只写里程碑等于里程碑一到就必须付款（V10 真实走查 V1：二期 5,000 万元只挂环保验收与投产，起草说明却称“与安全环保挂钩”） |
| 出资不得抵扣 | 投资款 / 出资款须实际缴付，**不要约定以公司或创始人欠投资方的款项抵扣出资**（资本充实；抵扣可能被认定出资不实，破产中也不能主张抵销，检索线索：企业破产法司法解释关于出资债权抵销的条文，条号待核）；需要扣回的写成先付后追偿或从分红、回购款中扣 | 抵扣条款伤的是投资方自己 |
| 分期出资与注册资本拆分 | 两期如何对应注册资本与资本公积写明；比较“首期认足全部新增注册资本、后续各期计入资本公积”（不留已登记未实缴）与“按比例拆分”（后续不缴时须减资或转让）两种结构；留有已登记未实缴出资的，写明章程出资日期，并提示催缴失权（公司法第五十二条）与加速到期（第五十四条）对投资方的影响 | 优先首期认足注册资本，后续不缴的估值调整另行约定 |
| 先决条件的豁免 | 先决条件为投资方利益设定，写“未经投资方书面豁免”；**不要写成投资方自己也不得豁免**（客户事后想放宽时被自己的条款锁死）；对方不可豁免的写给对方 | 豁免权只归受益方 |
| 既有投资人的特别权利 | 既有投资协议的最惠待遇、优先认购、反稀释、领售等逐项比对本轮条件：会触发的写明风险结论（会不会被主张同等权利、对本轮清算与回购顺位的影响）、需要对方签的放弃 / 同意文件，以及对方**拒签时的退路**（先决条件不成就时解除、调整本轮权利、由创始人赔偿） | 只写“取得放弃函”不够 |
| 上市前特别权利的处理 | 申报上市前特别权利（回购、对赌、反稀释等）的中止安排与上市失败后的恢复（监管对特殊权利条款有清理要求，具体口径以届时规则为准） | 写明恢复条件，避免中止后无法恢复 |
| 创始人义务的落地 | 全职服务、竞业限制违反时的后果（触发回购、按约定比例赔偿或股权处置）；“重大违约”在定义条款里**一次定义、封闭列举**（不用“等”），全文凡用到处引用该定义，其他条款不另把一般违约直接定为重大违约（否则绕开回购、解除的门槛）；自然人创始人的配偶同意函（股权、回购与补偿义务涉及夫妻共同财产）列为交割文件 | 没有后果的义务等于提示（V10 真实走查 V7：19.1 用“等”开放列举，20.6 把违反第 20 条的任何情形都定为重大违约） |
| 条款清单的数字与日期 | 估值、价款、比例、期限、触发日期、**测量期间或时点**（“6 月 30 日前达到”不改成单日测算）逐项与条款清单对照；改动的（如“2030 年后”写成“2031 年 1 月 1 日”）在起草说明中写明理由 | 不悄悄改对方已接受的口径 |
| 比例口径的两种读法 | 条款清单的比例（投前 / 投后 / 完全稀释、期权池、持股上限）有两种读法时，两种读法各算一遍：股数或注册资本、谁让渡多少、投后实际比例；起草按**对我方有利且文义站得住**的读法写，另一种写进起草说明请客户确认；受益方要算出来判断，不凭印象 | V10 真实走查 V7：期权池“完全稀释后 12%”被读成交割前 12%，投后只剩 9.6%，起草说明还把对投资方有利的读法写成“创始人可能的主张” |
| 价格机制之间的联动 | 本轮任何可能低于本轮价格的机制（后续各期的调整价、估值调整、补偿性股权）都要代入本协议与既有协议的反稀释、期权池、例外条款：会不会触发、触发后谁向谁补偿多少、例外是否覆盖；每一期写明**每 1 元注册资本的价格与计算基数**（以本轮前还是本期前的注册资本为基数） | V10 真实走查 V7：第二期按 1.2 亿元调整后每元 40 元，低于第一期 53.33 元，触发本协议自己的第 16 条反稀释，股权表与例外条款都没处理 |

## 二之三、股权转让（收购）必备要素（V10 第 36 批）

| 要素 | 起草要点 | 受让方立场提示 |
|---|---|---|
| 解押与付款的资金路径 | 标的股权有质押、冻结的，写清解押资金怎么走（受让方按质权人出具的结清金额直付、共管账户、解押与过户同日办理），不能只写“先解押才付首期”——转让方可能没有钱先解押 | V10 真实走查 V10：第 4.1（6）项要求先解押再付首期，合同没有直付或共管写法 |
| 自然人转让方的个人所得税 | 股东变更登记前须提交完税证明（检索线索：个人所得税法第十五条第二款，以核验为准）；代扣代缴的时点要与“交割日＝登记完成日”的顺序衔接，并估算税款，提示受让方作为扣缴义务人的责任 | 写成“各期付款时代扣”会与先完税后登记冲突 |
| 业绩补偿 | 按客户给的公式代入典型情景（各年完成 75%、一年亏一年超）算出补偿额，与累计口径比较、与该补偿义务人实际所得对价比较；补偿基数是否含其他转让方的对价；承诺期内经营控制权变化（交割后原股东不再任执行董事）对可执行性的影响，在起草说明里写清 | 只照抄公式、只加一个上限不够（V10：两年各完成 75% 时逐年口径补 9,000 万元、累计口径 4,500 万元；上限 1.8 亿元超过补偿义务人所得 1.35 亿元） |
| 既有股东的优先购买与随售 | 随售权触发时，比例有两种读法的各算加购股数与价款；给受让方“有权但无义务”加购的选择；受让方稿件里不主动确认对方未放弃的权利继续有效；已列为披露事项的风险不得因此挡掉对应的特别赔偿 | V10：两种读法（15% 或 20%）没算，第 6.4 条反向确认对方其他权利继续有效 |

## 二之三、救济闭合与可执行性（V12，所有类型；起草完成后逐项过一遍）

独立律师评分（V12 真实走查 MES 定制开发合同 20/24）指出的扣分不在“条款有没有”，而在“出了事能不能拿到结果”。每份首稿按下表自查，做不到的写进《起草说明》第四部分由客户决定：

| 检查 | 要做到什么 | 常见缺口 |
|---|---|---|
| 每项对方义务的救济链 | 对方的每一项主要义务（交付、质量、服务响应、关键人员、保密、数据安全、配合与交接）都能走完“义务 → 违约认定标准 → 量化后果（违约金或计算方法） → 解除权 → 解除后果”这条链 | 质量、服务响应、人员更换只写“应整改 / 应赔偿”，没有违约金或计算方法，守约方只能举证损失 |
| 解除后的钱与物 | 因对方违约解除时：已付款项退还的范围与期限（可扣除的只有我方书面认可、可独立利用的成果对应价款）、计息、已交付成果与资料的归属和交接、违约金与赔偿并存 | 只写“可以解除”，退款怎么算留给诉讼 |
| 先履行与预付款 | 我方先付款或先履行的，写对方的履约保障（预付款保函、履约保函、分期与里程碑挂钩、共管账户、尾款或质保金暂扣），或在《起草说明》提示风险并列为待客户决定 | 首期大额预付款没有任何担保，也没提示 |
| 第三方或程序触发的权利 | 托管释放、保函索赔、视为验收、视为同意这类依赖某一事实或通知才发生的效果：触发条件客观可核验，写明谁发通知、发给谁、多久内可以提出异议、异议是否影响执行 | “其他导致无法获得支持的情形”这类主观兜底，托管机构无法据以释放 |
| 定义与归属一致 | 同一事物在定义条款、权利归属条款、许可条款里的范围一致（如“定制成果”与“既有组件及其修改”）；为本项目专门开发的修改、扩展、接口归我方的，不能同时落进对方许可的范围 | 定义说归我方，许可条款又把“组件的修改”列为对方许可给我方 |
| 视为条款的范围 | 视为验收 / 视为通过 / 视为确认写明适用于哪些节点、不适用于哪些节点（与付款条件挂钩的节点尤其要写），以及“视为”不免除的责任 | 只排除最终验收，付款节点上的“试运行通过”是否可视为通过没写 |
| 管辖的兜底 | 协议管辖写到具体法院的，加一句：该院依级别管辖、专门管辖（知识产权、技术合同等）无管辖权时由约定地点有管辖权的法院管辖；写明合同签订地（如以签订地为连接点）；律师给的法院表述不明确（如“某某法院所在地法院”）的，改写成明确的表述，并在《起草说明》说明 | 只写一家基层法院，案件属于知识产权专门管辖时约定落空 |

## 三、法律红线（起草时不得越过，越过的必须在起草说明中写明）

| 事项 | 红线 | 检索线索 |
|---|---|---|
| 违约金 | 可以约定，但约定的违约金过分高于造成的损失的，可被请求适当减少；判断“过分高于”比较的是**造成的损失**，不是合同总价，**不存在“按合同总价 30% 封顶”的规则**。建议同时约定损失计算方法或可预见损失范围，供将来举证 | 民法典第 585 条；合同编通则解释（法释〔2023〕13 号）关于违约金调整的条文（以核验为准） |
| 定金 | 不得超过主合同标的额的 20%，超过部分不产生定金效力；定金与违约金不能同时主张，择一 | 民法典第 586、588 条 |
| 免责条款 | 造成对方人身损害的免责、因故意或重大过失造成对方财产损失的免责无效 | 民法典第 506 条 |
| 格式条款 | 我方提供格式条款的，对免除或减轻我方责任等与对方有重大利害关系的条款须以合理方式提示说明，否则对方可主张不成为合同内容 | 民法典第 496、497 条 |
| 借款利率 | 民间借贷利率有司法保护上限（以合同成立时一年期贷款市场报价利率为基准的倍数），超出部分不受保护；金融机构借款另有规则 | 最高人民法院关于审理民间借贷案件适用法律若干问题的规定（2020 第二次修正）相关条文（待核） |
| 劳动合同（用人单位立场） | 必备条款齐全；试用期期限与次数法定；除服务期与竞业限制外不得约定由劳动者承担违约金；竞业限制期限不超过二年并约定补偿 | 劳动合同法第 17、19、22、23、24、25 条 |
| 争议解决 | 不写“或裁或审”；仲裁机构写全称；协议管辖选与争议有实际联系的地点，不违反级别与专属管辖 | 见第一节 |
| 强制性规定与审批 | 需要审批、登记或备案才能生效或对抗第三人的，写明报批义务与责任 | 民法典第 502 条 |

## 四、一致性检查清单（第 3 节第 4 步）

1. 定义：先定义后使用；同一术语全文含义一致；定义了但未使用的删除。
2. 金额：大小写一致；币种；含税口径；分期之和等于总价。
3. 日期与期限：起算点明确；工作日与自然日表述统一；与付款、交付节点相互衔接。
4. 互引：“见第 X 条”指向存在的条号，且内容对应。
5. 附件：正文提到的附件都在附件清单中，名称一致。
6. 主体：首部、正文、签署页的名称一致；代号原样。
7. 编号：条、款、项编号连续，无跳号或重号。
