# 公司法（2023 年修订，2024-07-01 施行）会议规则线索

> 条号与要点已在本方法编写时对照中国政府网刊载的修订文本核过（https://www.gov.cn/yaowen/liebiao/202312/content_6923395.htm）；写进交付件前仍须用 `citations.verify` 核验，法规库未收录的条号后标“【待律师核对】”。“章程可另行规定”的事项一律先看章程。

## 一、有限责任公司
| 事项 | 规则要点 | 条号 | 章程能否另行规定 |
|---|---|---|---|
| 股东会职权与书面一致同意 | 对职权事项股东以书面形式一致同意的，可以不召开会议直接作出决定，由全体股东在决定文件上签名或盖章 | 第五十九条第三款 | 职权可由章程增加 |
| 一人有限公司 | 不设股东会；股东作出决定应当采用书面形式，签名或盖章后置备于公司 | 第六十条 | — |
| 定期与临时会议 | 定期会议按章程规定召开；代表十分之一以上表决权的股东、三分之一以上董事或监事会提议召开临时会议的，应当召开 | 第六十二条 | 定期会议时间由章程定 |
| 召集与主持 | 董事会召集、董事长主持（依次副董事长、过半数董事推举的董事）；董事会不召集的由监事会召集主持，监事会也不召集的，代表十分之一以上表决权的股东可以自行召集和主持 | 第六十三条 | — |
| 通知 | 会议召开十五日前通知全体股东；会议记录由出席股东签名或盖章 | 第六十四条 | 可以（章程另有规定或全体股东另有约定的除外） |
| 表决权 | 按出资比例行使 | 第六十五条 | 可以 |
| 普通决议 | 经代表过半数表决权的股东通过 | 第六十六条第二款 | 议事方式与表决程序除法定外由章程规定 |
| 特别决议 | 修改章程、增减注册资本、合并、分立、解散、变更公司形式：经代表三分之二以上表决权的股东通过 | 第六十六条第三款 | 法定下限，章程只能更严（待核章程） |
| 董事会召集 | 董事长召集和主持（依次副董事长、过半数董事推举的董事） | 第七十二条 | — |
| 董事会议事 | 过半数董事出席方可举行；决议经全体董事过半数通过；一人一票；会议记录由出席董事签名 | 第七十三条 | 议事方式与表决程序除法定外由章程规定 |
| 不设董事会 | 规模较小或股东人数较少的可以不设董事会，设一名董事 | 第七十五条 | — |
| 审计委员会 | 可按章程在董事会中设审计委员会行使监事会职权，不设监事会或监事 | 第六十九条 | 依章程 |
| 不设监事会 | 规模较小或股东人数较少的可以设一名监事；经全体股东一致同意也可以不设监事 | 第八十三条 | — |

## 二、股份有限公司（非上市）
| 事项 | 规则要点 | 条号 |
|---|---|---|
| 股东会通知 | 会议召开二十日前通知各股东；临时股东会会议十五日前通知；持股百分之一以上股东可在会议召开十日前提出临时提案；公开发行股份的公司以公告方式通知；不得对通知中未列明的事项作出决议 | 第一百一十五条 |
| 股东会表决 | 每一股份一表决权（类别股除外），公司持有的本公司股份没有表决权；普通决议经出席会议的股东所持表决权过半数通过；特别决议经出席会议的股东所持表决权的三分之二以上通过 | 第一百一十六条 |
| 董事会会议 | 每年度至少召开两次，每次会议召开十日前通知全体董事和监事；代表十分之一以上表决权的股东、三分之一以上董事或监事会可以提议召开临时会议，董事长应自接到提议后十日内召集；临时会议可另定通知方式和时限 | 第一百二十三条 |
| 董事会议事 | 过半数董事出席方可举行；决议经全体董事过半数通过；一人一票；会议记录由出席董事签名 | 第一百二十四条 |
| 委托出席 | 董事本人出席；因故不能出席的，可书面委托其他董事代为出席，委托书载明授权范围 | 第一百二十五条第一款 |

## 三、通用规则与效力
| 事项 | 规则要点 | 条号 |
|---|---|---|
| 对外投资与担保 | 按章程由董事会或股东会决议；为公司股东或实际控制人提供担保的，应当经股东会决议，被担保股东或受实际控制人支配的股东不得参加表决，由出席会议的其他股东所持表决权的过半数通过 | 第十五条 |
| 电子通信 | 股东会、董事会、监事会召开会议和表决可以采用电子通信方式，章程另有规定的除外 | 第二十四条 |
| 决议无效 | 决议内容违反法律、行政法规的无效 | 第二十五条 |
| 决议可撤销 | 召集程序、表决方式违反法律、行政法规或章程，或决议内容违反章程的，股东可自决议作出之日起六十日内请求撤销；仅有轻微瑕疵且对决议未产生实质影响的除外；未被通知参会的股东自知道或应当知道之日起六十日内，自决议作出之日起一年内未行使的撤销权消灭 | 第二十六条 |
| 决议不成立 | 未召开会议作出决议；未对决议事项进行表决；出席人数或所持表决权数未达到法定或章程规定；同意人数或所持表决权数未达到法定或章程规定 | 第二十七条 |
| 撤销登记 | 决议被宣告无效、撤销或确认不成立的，公司应当申请撤销根据该决议已办理的登记 | 第二十八条第一款 |
| 关联董事 | 董事会对第一百八十二条至第一百八十四条规定的事项决议时，关联董事不得参与表决、表决权不计入总数；出席的无关联关系董事不足三人的，提交股东会审议 | 第一百八十五条 |

## 四、本表不覆盖（须另行研究或待核）
- 上市公司股东会、董事会、独立董事与信息披露规则；国有企业、外商投资企业的审批备案；行业主管部门审批。
- 决议作出后变更登记的期限与材料：以现行市场主体登记规定与登记机关要求为准（条号待核）。
- 期间计算的起止口径（“会议召开十五日前”是否含通知日与会议日）：由律师按章程与实务口径确认。
