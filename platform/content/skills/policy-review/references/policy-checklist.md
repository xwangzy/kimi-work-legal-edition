# 规章制度审查清单

> 条号与要点已在本方法编写时对照官方或政府网站转载文本核过（劳动合同法：国家税务总局法规库转载；劳动争议解释（一）：最高人民法院网站；劳动法：广东省人民政府等转载的 2018 年修正本；工资支付暂行规定：重庆市人力资源和社会保障局转载）。写进交付件前仍须用 `citations.verify` 核验；法规库未收录的条号后标“待核”。地方规定一律以律师提供的文件为准。

## 一、内容审查要点
| 主题 | 查什么 | 依据线索 |
|---|---|---|
| 制度的效力前提 | 直接涉及劳动者切身利益的制度，内容不违反法律、行政法规及政策规定、经民主程序制定并已公示的，才可以作为确定双方权利义务的依据 | 劳动争议解释（一）（法释〔2020〕26 号）第五十条第一款 |
| 与合同冲突 | 制度与集体合同或劳动合同约定不一致，劳动者请求优先适用合同约定的，法院应予支持 | 同解释第五十条第二款 |
| 违法制度的后果 | 直接涉及切身利益的制度违反法律、法规的，劳动行政部门责令改正、给予警告；给劳动者造成损害的承担赔偿责任 | 劳动合同法第八十条 |
| 劳动者单方解除 | 规章制度违反法律、法规的规定，损害劳动者权益的，劳动者可以解除劳动合同，并可主张经济补偿 | 劳动合同法第三十八条第一款第（四）项、第四十六条第（一）项 |
| 违纪解除条款 | “严重违反规章制度”的情形是否列明、是否合理、是否有分级；解除时是否事先将理由通知工会 | 劳动合同法第三十九条第（二）项、第四十三条 |
| 违约金 | 除服务期（培训费用为限）与竞业限制外，不得约定由劳动者承担违约金 | 劳动合同法第二十五条、第二十二条、第二十三条 |
| 竞业限制 | 适用人员、期限（解除或终止后不超过二年）、按月给予经济补偿 | 劳动合同法第二十三条、第二十四条 |
| 押金与证件 | 不得扣押身份证和其他证件，不得要求劳动者提供担保或以其他名义收取财物 | 劳动合同法第九条 |
| 加班 | 不得强迫或变相强迫加班；延长工作时间的上限（一般每日不超过一小时，特殊原因每日不超过三小时、每月不超过三十六小时）；加班工资不低于百分之一百五十、休息日不能补休的百分之二百、法定休假日百分之三百 | 劳动合同法第三十一条；劳动法第四十一条、第四十四条 |
| 扣减工资 | 因劳动者本人原因造成经济损失的赔偿可从工资中扣除，每月扣除部分不得超过当月工资的百分之二十，扣除后低于当地月最低工资标准的按最低工资标准支付 | 《工资支付暂行规定》（劳部发〔1994〕489 号）第十六条；当地最低工资标准待律师提供 |
| 罚款与经济处罚 | 制度中的罚款、扣发工资等经济处罚，法律依据与地方口径不一 | 列入“地方口径待核”，不凭记忆下结论 |
| 工时制度 | 综合计算工时、不定时工作制是否经审批 | 审批依据与地方口径待核 |
| 调岗调薪、休假、绩效 | 是否有合理性标准、是否与劳动合同约定一致、是否可执行 | 逐条判断；依据须检索核验 |
| 表述 | 用语是否明确可执行（“情节严重”“多次”“重大损失”是否量化）、前后口径是否一致、是否引用已废止的规定 | 一致性检查 |

## 二、民主程序与公示或告知
| 要求 | 依据 | 常见可证明材料 | 常见缺口 |
|---|---|---|---|
| 直接涉及切身利益的制度或重大事项，制定、修改或决定时应当经职工代表大会或者全体职工讨论，提出方案和意见 | 劳动合同法第四条第二款 | 征求意见通知、讨论记录、意见汇总 | 只有管理层审议记录 |
| 与工会或者职工代表平等协商确定 | 同上 | 与工会或职工代表的协商记录、协商结果 | 未设工会也未推选职工代表 |
| 实施过程中工会或职工认为不适当的，有权提出并通过协商修改完善 | 劳动合同法第四条第三款 | 意见反馈与处理记录 | — |
| 公示或者告知劳动者 | 劳动合同法第四条第四款 | 员工签收（纸质或电子）、培训签到与考试、内网发布与阅读记录、公告栏照片 | 只有发布记录、无法证明员工知悉 |
