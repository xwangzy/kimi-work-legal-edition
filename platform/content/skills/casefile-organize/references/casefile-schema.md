# 案卷整理：分类、列定义与事实写法

## 一、材料类别（案卷目录“类别”列，按此顺序编排卷内序号）
| 代码 | 类别 | 常见材料 |
|---|---|---|
| A | 主体资格 | 营业执照、身份证明（代号）、法定代表人身份证明、授权委托书、工商登记信息 |
| B | 合同与协议 | 主合同、补充协议、订单、报价单、框架协议、附件、章程 |
| C | 履行凭证 | 送货单、签收单、验收单、出入库单、工作成果交付记录、工程量确认 |
| D | 财务凭证 | 银行回单、发票、收据、对账单、往来账明细、催款记录 |
| E | 往来沟通 | 函件、通知、电子邮件、即时通讯记录、会议纪要、录音文字稿 |
| F | 争议与程序 | 律师函、催告函、起诉状、答辩状、裁定书、判决书、仲裁文书、送达回证 |
| G | 保全、公证与鉴定 | 公证书、电子证据存证、鉴定意见、评估报告、财产线索 |
| H | 其他 | 无法归入以上类别的材料（备注说明） |

一份材料包含多类内容时，按主要用途归类，并在备注写明其他内容。

## 二、《案卷总目录》列定义
| 列 | 写法 |
|---|---|
| 卷内序号 | 类别代码 + 两位序号，如 B-01 |
| 材料名称 | 原文件名；必要时在括号内补充简称 |
| 类别 | 见上表 |
| 提供方 | 我方 / 对方 / 第三方 / 待确认（无法判断时不要猜） |
| 形成日期 | 材料载明的日期；无日期写“未载明” |
| 页数 | 取自 materials.list；无页数信息写“—” |
| 识别质量 | ok / ocr / partial / unreadable（partial 写明未识别页数） |
| 内容摘要 | 不超过 60 字，只写材料内容，不写评价 |
| 初步可证明事项 | 写“拟证明……”，标注“初步，待律师判断” |
| 关联事实编号 | 对应 facts.submit 返回的事实编号，多个用顿号分隔 |
| 快照序号 | materials.list 的 snapshot_index；未随本任务提供的写“—” |
| 备注 | 是否原件待核、是否有签章、是否存在涂改等可见情况 |

## 三、事实写法
1. **一事一行**：一个行为或一个事件一条，避免“甲方于某日交货并于某日付款”这种合并写法。
2. **主体用材料中的称谓或代号**：如“〔组织·XXXX〕向〔组织·YYYY〕交付第一批货物”，不改写、不猜真名。
3. **日期精度**：材料写到日的写到日；只写到月或年的就写到月或年；“约”“左右”的提交为 to_confirm。
4. **金额**：amount_yuan 填阿拉伯数字（元）；外币或非金额数量写在 statement 中，不换算。
5. **逐字引文**：quote 取材料中能支撑该事实的那一句，逐字照抄，包括代号与标点；不得拼接两处文字。
6. **类别判断**：
   | 情形 | kind |
   |---|---|
   | 材料直接写明（如回单显示某日转账某金额） | claimed |
   | 当事人单方陈述（起诉状、函件、聊天中的说法） | claimed（statement 写“某方称……”） |
   | 由多份材料推出（如“签收单晚于约定交货日，推论迟延交货”） | inferred（写明推理依据） |
   | 材料之间矛盾、识别不清、日期金额不确定 | to_confirm |
7. **不得出现的写法**：“经查明”“事实上”“显然”“已证实”。

## 四、《事实时间线》排序与分列
- 按日期升序；同日按材料形成顺序；日期只到月的排在该月末尾，日期未知的放表尾。
- 四类事实分列：同一行只在其所属的一列写陈述，其余三列留空；律师已确认的事实写在“律师确认”列（来自 facts.list 中 lawyer_status = confirmed 的行）。
- 定位状态列取自 facts.submit / facts.list 返回的 anchor_status（located / ambiguous / not_found）。

## 五、缺口的常见类型
- 有付款陈述而无付款凭证；有交付陈述而无签收或验收记录。
- 合同缺签署页、缺附件、缺补充协议所指向的主合同。
- 关键期间没有任何沟通记录（例如约定交付日前后）。
- 主体信息不全（无法确认对方的准确名称或住所，影响起诉与送达）。
- 涉及诉讼时效、保证期间、解除权期限的关键日期缺少证据（提示律师关注期限）。
- 扫描件识别不全、录音无文字稿、外文材料无译文。
