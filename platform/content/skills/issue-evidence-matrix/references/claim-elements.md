# 常见请求权与抗辩的要件拆分（通用框架）

> 本表是拆分要件的起点，不是法律结论。每个请求权基础都要用 `law.search` / `law.get_version` 定位并经 `citations.verify` 核验；“检索线索”只指出该到哪部法律、哪一章去找，条号以核验结果为准。
> 举证责任一栏写“一般”分配，具体由律师结合案情判断。

## 一、买卖合同价款给付（卖方诉买方）
| 要件 | 一般举证方 | 常见证据 |
|---|---|---|
| 买卖合同关系成立并生效 | 卖方 | 合同、订单、报价确认、交易习惯（历次交易记录） |
| 卖方已按约交付标的物 | 卖方 | 送货单、签收单、物流记录、验收单、对账单 |
| 价款数额与付款期限 | 卖方 | 合同价款条款、对账单、发票 |
| 付款期限届满而买方未付或未付清 | 卖方主张未付；买方对已付款举证 | 银行流水、对账单、催款函 |
| 逾期付款损失（违约金或资金占用损失）的约定或计算依据 | 卖方 | 违约金条款；无约定时的计算口径由律师选择（→ amount-calc） |
检索线索：民法典合同编买卖合同章（价款支付）、违约责任章。

## 二、民间借贷还本付息（出借人诉借款人）
| 要件 | 一般举证方 | 常见证据 |
|---|---|---|
| 借贷合意 | 出借人 | 借款合同、借条、聊天记录中的借款意思表示 |
| 款项实际交付 | 出借人 | 银行转账凭证（备注用途）；现金交付需结合金额、交付情况等补强 |
| 借款期限与还款约定 | 出借人 | 合同、借条 |
| 利息约定及合法性 | 出借人 | 利率条款；需核对合同成立时的利率保护上限（检索线索：民间借贷司法解释利率条文） |
| 到期未还 | 借款人对已还款举证 | 还款记录、对账、催收记录 |
注意：被告以“转账系偿还其他债务”等抗辩时，举证责任可能转移，提示律师关注（依据待核实）。

## 三、保证责任（债权人诉保证人）
| 要件 | 一般举证方 | 常见证据 |
|---|---|---|
| 主债权成立且到期未清偿 | 债权人 | 主合同、履行与欠款证据 |
| 保证合同成立（含保证人签章、公司担保的决议） | 债权人 | 保证合同或保证条款、担保函、股东会或董事会决议 |
| 保证方式（一般 / 连带） | 债权人 | 保证条款；未约定或约定不明的推定为一般保证（检索线索：民法典保证合同章） |
| 在保证期间内向保证人主张了权利（连带保证）或对债务人提起诉讼、仲裁（一般保证） | 债权人 | 催告函及送达凭证、起诉材料 |
| 保证范围 | 债权人 | 保证条款 |
常见抗辩：保证期间已届满、主合同变更未经保证人同意、公司担保未经决议、一般保证的先诉抗辩。

## 四、违约金或损害赔偿
| 要件 | 一般举证方 | 常见证据 |
|---|---|---|
| 有效合同及违约金或赔偿约定 | 守约方 | 合同条款 |
| 对方违约行为 | 守约方 | 履行记录、催告、对方回复 |
| （赔偿损失时）损失及其数额 | 守约方 | 替代交易凭证、费用票据、利润测算依据 |
| （赔偿损失时）违约与损失的因果关系、可预见性 | 守约方 | 合同目的条款、往来沟通中对用途的说明 |
常见抗辩：违约金过分高于损失请求调整（违约方对“过分高于”提出主张，守约方对损失情况也应准备证据，依据待核实）；守约方未采取适当措施致损失扩大；守约方也有过错；不可抗力。
检索线索：民法典违约责任章；最高人民法院关于适用民法典合同编通则若干问题的解释（违约金调整）。

## 五、确认合同解除及解除后的返还、赔偿
| 要件 | 一般举证方 | 常见证据 |
|---|---|---|
| 解除权的发生（约定解除事由成就或法定解除情形） | 主张解除方 | 合同解除条款、违约事实证据、催告函（迟延履行经催告后仍未履行的情形） |
| 解除权在期限内行使 | 主张解除方 | 解除通知的时间、知道解除事由的时间 |
| 解除通知到达对方 | 主张解除方 | 送达凭证（EMS 详情单与妥投记录、约定邮箱发送记录、公证） |
| 返还与赔偿的范围 | 主张方 | 已付款凭证、已交付物清单、损失证据 |
检索线索：民法典合同的权利义务终止章（解除）；合同编通则解释中关于通知解除的条文。

## 六、服务费或技术服务费支付（服务方诉委托方）
| 要件 | 一般举证方 | 常见证据 |
|---|---|---|
| 服务合同成立 | 服务方 | 合同、工作说明书、确认邮件 |
| 已按约提供服务或交付成果 | 服务方 | 交付记录、验收单、工作日志、系统上线记录、委托方确认 |
| 付款条件成就（验收、里程碑） | 服务方 | 验收文件；默示验收条款及其触发事实 |
| 未付金额 | 委托方对已付款举证 | 发票、对账、催款记录 |
常见抗辩：未验收或验收不合格、服务未达约定标准（SLA）、任意解除及结算。

## 七、股权转让款支付或股权变更登记
| 要件 | 一般举证方 | 常见证据 |
|---|---|---|
| 股权转让协议成立并生效（含审批类生效条件） | 主张方 | 协议、审批文件 |
| 对外转让时其他股东优先购买权的处理 | 视争点而定 | 通知书、放弃声明、股东会决议（检索线索：公司法（2023 年修订）股权转让条文） |
| 我方已履行（出让方已配合交割 / 受让方已付款） | 主张方 | 变更登记材料、交割确认、付款凭证 |
| 对方未履行 | 主张方 | 催告函、对方回复 |
常见抗辩：先决条件未成就、陈述与保证违反、出资瑕疵、对方先违约。

## 八、通用抗辩清单（每个矩阵至少过一遍）
| 抗辩 | 需关注的事实 | 检索线索 |
|---|---|---|
| 诉讼时效届满 | 权利受损及义务人可知之日、中断事由（催告、承认、起诉）及证据 | 民法典总则编诉讼时效章 |
| 同时履行 / 先履行抗辩 | 合同约定的履行顺序、我方履行情况 | 民法典合同编合同的履行章 |
| 质量异议 | 检验期、异议时间与方式 | 民法典买卖合同章检验条文 |
| 已清偿或抵销 | 付款凭证、抵销通知 | 民法典合同编清偿与抵销条文 |
| 合同无效或可撤销 | 主体资格、意思表示、强制性规定 | 民法典总则编民事法律行为章 |
| 不可抗力或情势变更 | 事件、通知、影响程度 | 民法典合同编相关条文 |
