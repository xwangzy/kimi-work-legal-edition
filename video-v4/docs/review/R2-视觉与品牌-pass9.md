## 3. 落版结论（4K，S-partner 第 440 帧）

- **结构**：印章 320 px 与图标 320 px 等大；× 在中轴上；两侧间距均为 148 px（1080 为 74 px）；名称、落款、细线的几何与 pass7 一致。
- **名称对等（本轮修复）**：“中软国际”最深色为 #1F1F1F，墨量 0.39；官方 KIMI 字标为 #000，墨量 0.51。中文笔画密度本来就和拉丁大写不同，这个差距在正常范围内，看上去两边分量相当。
- **时间线**：约 104.5 s 收字标 → 105.5 s 印章落下 → 106 s 画出 × → 106.5 s 出现名称 → 107 s 落款 → 静止约 5.5 s → 112.5–113.7 s 淡出。

**结论：4.7。** 对等、对称、两家都有名字、素材是未改动的官方资产、落印有仪式、停留充分。这是全片最好的画面，明显超过 V1。

## 4. 需要客户或品牌方决定的事项（片内无法替代）

1. **Kimi 品牌方确认落版版式。** “左中软、右 Kimi”顺序，以及“方标 + 下方名称”的竖排组合，都不是 Kimi 官方 Partnership 模板里的现成版式（官方模板为 Kimi 在左、横排）。每个元素都是官方原样资产，但版式需要 Kimi 书面认可。这是对外发布前的合规手续，不影响评分。
2. **对外主标志选哪一个。** “Kimi Work + 法律版角标”还是“Kimi Work + 法律行业发行版”，由客户定一个作为封面和片尾的主标志，另一个只用在界面里。片内现在的用法可以接受。
