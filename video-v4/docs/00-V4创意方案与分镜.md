# Kimi Work 法律行业发行版 · 宣传片 V4 — 版本复盘、创意方案与分镜

> 本文是 V4 的设计依据。时间码按 60 fps 记作 `秒`；节拍网格 100 BPM（1 拍 = 36 帧 = 0.6 秒，1 小节 = 144 帧 = 2.4 秒），所有切点、点击与音效落在网格上，唯一出处是 `src/timeline.ts`。最终以成片为准，渲染后的逐镜头复核见 `docs/03-逐镜头评审与验收.md`。

## 一、V1 / V2 / V3 复盘

| | V1（10-16，96 秒） | V2（10-24，96 秒） | V3（11-25，113 秒） |
|---|---|---|---|
| 界面来源 | 手写 JSX 按产品样式重建 | 真实 DOM 快照（第 26 批） | 真实 DOM 快照（第 64 批） |
| 开场 | **夜色里一页页实体纸张**（合同、法条、判决、纪要）在景深中掠过 → 十二个工具窗口分散 → 汇于一处 | 同 V1 | 宋体法条文字在夜色中分层漂移 → 蓝点 |
| 字幕 | **左侧两行大字（主句 + 灰色副句），窗口向右让位并带透视** | 同 V1，副句变长 | 左下角小字幕，底部柔光托字 |
| 产品呈现 | **窗口在暖白摄影棚中以透视悬浮，留白充分** | 局部特写增多、焦点虚化 | 全屏快照为主，信息密度高 |
| 落版 | 中软 × KIMI，小尺寸并排 | 同 V1 | Kimi × 中软（Kimi 在前） |

**V1 真正有价值、V4 必须继承的四件事**
1. **实体纸张的触感**：法律工作的“重量”用纸来讲，比抽象光效高级，也最贴近律师的日常。
2. **两行大字的版式**：主句粗、副句灰，左对齐，留白大——像发布会的主视觉，而不是视频字幕。
3. **悬浮窗口 + 透视让位**：产品在摄影棚光里“被展示”，而不是被录屏。
4. **克制的配色**：暖白、近黑，唯一的强调色是 Kimi 标识里那颗蓝点。

**V1 仍未达到理想状态的地方（V4 要解决的）**
- 运镜单一：几乎都是静态透视 + 轻推，缺少焦点转移、微距与空间穿梭；转场以淡入淡出为主。
- 产品登场缺少仪式感：白卡片 → 字标 → 首页，过程平铺。
- 中段功能并列：一个功能一句标题，像逐页翻 PPT；“一个工作空间”“保密”两段是缩略图网格和三张小卡，信息小、气势弱。
- 界面是手写重建，与真实产品有差异；AI 输出是演示文字。
- 落版：两个标识直接并排，尺寸偏小、停留短，缺少品牌仪式。
- 配乐是临时合成，情绪起伏和画面高潮对不齐。

**V2、V3 的可取之处（V4 保留）**：真实 DOM 快照渲染管线（样式取运行中界面的 CSSOM，不覆盖产品字体）；蓝点母题与“暖白从蓝点展开”；字幕逐条对照产品文案；节拍网格驱动的配乐与音效。
**V2、V3 的问题（V4 避免）**：V3 字幕小、画面满，失去 V1 的大气；全屏快照让观众“看界面”而不是“看价值”；V3 开场的纯文字漂移不如 V1 的实体纸张有质感。

## 二、V4 创意核心

**一句话概念：从一页纸开始，到一份由律师签发的成果结束。**

全片只跟一件事：一份《股权转让协议》。它在开场是夜色里成百上千页纸中的一页；进入产品后，被交代任务、被记录授权、被换成代号、被逐条审查、被核对引用、被律师逐条判断、被生成修订稿；最后从屏幕里“抬起来”，重新变回一页纸——这一次，是律师签发的成果。纸 → 界面 → 纸，形成闭环，也让所有功能串成一个故事，而不是功能清单。

**视觉母题：蓝点。** Kimi 标识右上角的蓝点 = AI 的注意力。它在开场从纸堆里亮起，汇成标识；在执行中呼吸（产品里等待时呼吸的也是它）；在片尾再次亮起，展开为主题与落版。全片只用这一个“特效”。

**五幕结构**：痛点（纸的重量）→ 登场（蓝点成标识、界面分层展开）→ 能力（一件真实的审合同，从交代到签发）→ 价值（为保密义务而设计；AI 延伸律师的专业能力）→ 收束（主题、产品名、联合品牌落版）。

| 产品呈现 | 窗口悬浮在摄影棚里，带真实投影与一道玻璃高光；标题出现时窗口向右让位并带 6–10° 偏航；特写时用“同一快照两层渲染”做浅景深，焦点区清晰、其余虚化压暗 |
| 运镜 | 推、拉、横移、环绕（偏航 ±12° 以内）、焦点转移、微距；每个镜头只有一个运动意图；缓动统一用 expo-out（进入）与 inOut（推拉） |
| 转场 | 按意义选：匹配剪辑（字标→首页字标、条款→工作台条款、修订稿→纸张）、遮罩（光从蓝点展开）、空间穿梭（穿过纸堆）、界面形变（卡片收拢成已处理）；同一种转场不连续使用两次 |

## 六、30 秒社媒版（终稿）

12.5 小节、1800 帧，剪辑表在 `src/cut30.ts`：夜色里的协议 + 命题句 + 蓝点 3.4 s → 蓝点成标识、Kimi Work 法律版 2.4 s → 一句话交代任务 4.0 s → 发出前换成代号（停住）3.5 s → 17 项 / 8 项 2 s → AI 提出意见、律师作出判断 + 修订写在纸上 4.8 s → 确认签发、签发人、浸入夜色 1.3 s → 主题句与英文（完整停住约 1.7 s）2.7 s → 蓝点展开 0.8 s → 产品名 + 中软国际 × Kimi 联袂打造 5 s。配乐按同一剪辑点单独编配（`SCORE=cut30`）。

## 七、真实性原则

- 界面全部来自第 69 批（`e56b568a`，客户端 0.9.0）真实运行时的 DOM 快照，不手写界面。
- 案例为虚构、脱敏的演示案例（公司名用甲乙丙丁戊己，姓名、证件号、电话为编造）。
- **审查意见、意见书与问答由真实 Kimi 模型（经本机法律模型网关 → 中软 MaaS → kimi-k3.1-pro）在真实产品工作流中生成**，不是脚本文字；代号替换、引用核验、独立复核、修订稿与签发前核对都是产品的真实处理结果。
- 片中只出现产品已实现的能力；字幕说法逐条对照产品文案。
