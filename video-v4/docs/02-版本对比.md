# V1 / V2 / V3 / V4 横向对比

> 对比基于实际成片（V1 `video/archive/v1/kimi-work-legal-film.mp4`、V2 `video/archive/v2/kimi-work-legal-film-v2.mp4`、V3 `video/out/kimi-work-legal-film.mp4`、V4 `out/final/`），不是基于方案。

| 维度 | V1（10-16） | V2（10-24） | V3（11-25） | V4（11-26） |
|---|---|---|---|---|
| 规格 | 1080p30，96 s | 1080p30，96 s | 1080p30，113 s | **2160p60（4K），114 s；另 30 秒版** |
| 界面来源 | 手写重建 | 真实 DOM 快照（第 26 批） | 真实 DOM 快照（第 64 批） | **真实 DOM 快照（第 69 批，客户端 0.9.0）** |
| AI 输出 | 演示文字 | 演示文字 | 脚本化模型 | **真实 Kimi 模型（kimi-k3.1-pro）在真实工作流中生成**：17 项审查意见、提问卡、独立复核、修订稿、起诉状、问答 |
| 开场 | 夜色实体纸张 → 窗口散落 → 汇于一处 | 同 V1 | 宋体文字漂移 | **第 7.1 条微距 → 纸的纵深 → 命题 → 蓝点**（V1 纸张意象 + 景深与运镜升级） |
| 叙事 | 功能逐条 | 功能逐条 | 功能逐条（14 场） | **一条第 7.1 条贯穿全片**：纸 → 蓝点落在条款上 → 律师接受 → 修订写在纸上 → 签发后的纸抬离屏幕 → 夜色里同一页纸（已修订）；三个乐章 交代 / 过程 / 判断 |
| 英雄镜头 | 无 | 无 | 无 | 界面分层生长、代号替换（真实代号）、蓝点落在第 7.1 条、修订写在纸上、纸抬离屏幕、联合落版“落印” |
| 字幕版式 | 左侧两行大字 | 同 V1 | 左下小字 | **继承 V1 两行大字**，加章节标签；动作段用下三分之一；证据镜头用大数字；命题与理念居中 |
| 运镜 | 静态透视 + 轻推 | 增加焦点虚化 | 关键帧推拉 | 速度连续的样条运镜、对数缩放、方向运动模糊、景深焦点、分层 3D |
| 转场 | 淡入淡出为主 | 同左 | 匹配剪辑 + 淡变 | 匹配剪辑、蓝点展开/收拢、屏幕→纸、界面状态溶解、穿越虚化 |
| 明暗 | 白 ↔ 黑多次 | 同左 | 白 ↔ 黑多次 | 只翻两次，都经过蓝点；末段 25 秒连续夜色 |
| 落版 | 中软 × KIMI 并排 | 同 V1 | Kimi × 中软（模板顺序） | **中软国际（左）× Kimi（右）以“×”为中轴对称**，两枚方形标识按光学重量匹配；印章“落印”；细线夹“联袂打造”；停留约 4.7 秒后淡出 |
| 配乐 | 合成临时配乐 | 同左 | 合成临时配乐 | 合成配乐重编：三乐章、空拍、主落点对准产品名展开、品牌声音标识；响度归一化 −16 LUFS |
| 字体 | 苹方（系统） | 改苹方 | 产品字体栈 | 片中排版用 Noto Sans/Serif SC、Inter（OFL，可商用）；产品界面保持产品字体栈 |

**V4 继承了 V1 的**：实体纸张的触感、左侧两行大字、悬浮窗口与透视让位、暖白 + 近黑 + 一颗蓝点的克制配色。
**V4 超越 V1 的**：真实界面与真实模型输出；一条贯穿全片的叙事线（第 7.1 条）与五个英雄镜头；4K60 与运镜、转场的工艺；对称的联合落版与仪式感；三乐章配乐。
**评审指出、V4 仍需客户决定的**：行动号召（入口未定）、9:16 竖版、中软国际横版组合标识（若有，可替换印章，使落版左右更对等）、客户指定文案的取舍。
